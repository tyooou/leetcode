### Problem Statement:

Given an array of positive integers `nums`, return _an array _`answer`_ that consists of the digits of each integer in _`nums`_ after separating them in **the same order** they appear in _`nums`.

To separate the digits of an integer is to get all the digits it has in the same order.

	- For example, for the integer `10921`, the separation of its digits is `[1,0,9,2,1]`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [13,25,83,77]
> ```
>
> **Output:**
>
> ```python
> [1,3,2,5,8,3,7,7]
> ```
>
> **Explanation:**
>
> ```python
> - The separation of 13 is [1,3].
> - The separation of 25 is [2,5].
> - The separation of 83 is [8,3].
> - The separation of 77 is [7,7].
> answer = [1,3,2,5,8,3,7,7]. Note that answer contains the separations in the same order.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [7,1,3,9]
> ```
>
> **Output:**
>
> ```python
> [7,1,3,9]
> ```
>
> **Explanation:**
>
> ```python
> The separation of each integer in nums is itself.
> answer = [7,1,3,9].
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 1000`
>
> 	- `1 <= nums[i] <= 10^5`

>     def separateDigits(self, nums: List[int]) -> List[int]:
>         res = []
>         s = []
>         for number in nums:
>             while number:
>                 s.append(number % 10)
>                 number //= 10
>             while s:
>                 res.append(s.pop())
>         return res
