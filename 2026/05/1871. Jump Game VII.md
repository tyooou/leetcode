### Problem Statement:

You are given a **0-indexed** binary string `s` and two integers `minJump` and `maxJump`. In the beginning, you are standing at index `0`, which is equal to `'0'`. You can move from index `i` to index `j` if the following conditions are fulfilled:

	- `i + minJump <= j <= min(i + maxJump, s.length - 1)`, and

	- `s[j] == '0'`.

Return `true`_ if you can reach index _`s.length - 1`_ in _`s`_, or _`false`_ otherwise._

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "011010", minJump = 2, maxJump = 3
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> In the first step, move from index 0 to index 3.
> In the second step, move from index 3 to index 5.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "01101110", minJump = 2, maxJump = 3
> ```
>
> **Output:**
>
> ```python
> false
> ```

> [!warning]- Constraints
> - `2 <= s.length <= 10^5`
>
> 	- `s[i]` is either `'0'` or `'1'`.
>
> 	- `s[0] == '0'`
>
> 	- `1 <= minJump <= maxJump < s.length`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `166 ms` | `20.5 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
>         n = len(s)
>
>         if int(s[-1]): return False
>
>         dp = [False] * n
>         dp[0] = True
>         reach, maxR = 0, maxJump
>
>         for i in range(minJump, n):
>             if i > maxR: return False # short-circuit
>
>             reach += dp[i - minJump] # add to reach (True)
>
>             if i > maxJump: # start subtract
>                 reach -= dp[i - maxJump - 1] # if dp[x] = True, subtract 1
>
>             if reach and not int(s[i]):
>                 dp[i] = True
>                 maxR = i + maxJump # short-circuit
>
>         return reach > 0
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
