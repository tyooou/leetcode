### Problem Statement:

Given the `head` of a linked list, rotate the list to the right by `k` places.

> [!example]- Example 1
> **Input:**
>
> ```python
> head = [1,2,3,4,5], k = 2
> ```
>
> **Output:**
>
> ```python
> [4,5,1,2,3]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> head = [0,1,2], k = 4
> ```
>
> **Output:**
>
> ```python
> [2,0,1]
> ```

> [!warning]- Constraints
> - The number of nodes in the list is in the range `[0, 500]`.
>
> 	- `-100 <= Node.val <= 100`
>
> 	- `0 <= k <= 2 * 10^9`
