### Problem Statement:

Given two integer arrays `nums1` and `nums2`, sorted in non-decreasing order, return _the **minimum integer common** to both arrays_. If there is no common integer amongst `nums1` and `nums2`, return `-1`.

Note that an integer is said to be **common** to `nums1` and `nums2` if both arrays have **at least one** occurrence of that integer.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums1 = [1,2,3], nums2 = [2,4]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The smallest element common to both arrays is 2, so we return 2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums1 = [1,2,3,6], nums2 = [2,3,4,5]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> There are two common elements in the array 2 and 3 out of which 2 is the smallest, so 2 is returned.
> ```

> [!warning]- Constraints
> - `1 <= nums1.length, nums2.length <= 10^5`
>
> 	- `1 <= nums1[i], nums2[j] <= 10^9`
>
> 	- Both `nums1` and `nums2` are sorted in **non-decreasing** order.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4 ms` | `37.6 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def getCommon(self, nums1: List[int], nums2: List[int]) -> int:
>         m, n = len(nums1), len(nums2)
>
>         i, j = 0, 0
>         while i < m and j < n:
>             a, b = nums1[i], nums2[j]
>             if a == b:
>                 return a
>             elif a > b:
>                 j += 1
>             else:
>                 i += 1
>
>         return -1
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
