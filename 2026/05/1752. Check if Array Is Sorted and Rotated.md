### Problem Statement:

Given an array `nums`, return `true`_ if the array was originally sorted in non-decreasing order, then rotated **some** number of positions (including zero)_. Otherwise, return `false`.

There may be **duplicates** in the original array.

**Note:** An array `A` rotated by `x` positions results in an array `B` of the same length such that `B[i] == A[(i+x) % A.length]` for every valid index `i`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [3,4,5,1,2]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> [1,2,3,4,5] is the original sorted array.
> You can rotate the array by x = 2 positions to begin on the element of value 3: [3,4,5,1,2].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [2,1,3,4]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> There is no sorted array once rotated that can make nums.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [1,2,3]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> [1,2,3] is the original sorted array.
> You can rotate the array by x = 0 positions (i.e. no rotation) to make nums.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 100`
>
> 	- `1 <= nums[i] <= 100`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.2 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def check(self, nums: List[int]) -> bool:
>
>         skip = True
>         n = len(nums)
>         for i in range(1, n):
>             curr, prev = nums[i], nums[i - 1]
>             if prev <= curr:
>                 continue
>             elif skip:
>                 skip = False
>                 continue
>             else:
>                 return False
>         return True if skip or (nums[-1] <= nums[0]) else False
>
>
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
