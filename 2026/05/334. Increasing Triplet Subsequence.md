### Problem Statement:

Given an integer array `nums`, return `true`_ if there exists a triple of indices _`(i, j, k)`_ such that _`i < j < k`_ and _`nums[i] < nums[j] < nums[k]`. If no such indices exists, return `false`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,4,5]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> Any triplet where i < j < k is valid.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [5,4,3,2,1]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> No triplet exists.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [2,1,5,0,4,6]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> One of the valid triplet is (1, 4, 5), because nums[1] == 1 < nums[4] == 4 < nums[5] == 6.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 5 * 10^5`
>
> 	- `-2^31 <= nums[i] <= 2^31 - 1`
>
>
>
> **Follow up:** Could you implement a solution that runs in `O(n)` time complexity and `O(1)` space complexity?

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `16 ms` | `38.9 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def increasingTriplet(self, nums: List[int]) -> bool:
>         a, b = float('inf'), float('inf')
>
>         for n in nums:
>             if n <= a: a = n
>             elif n <= b: b = n
>             else: return True
>         return False
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
