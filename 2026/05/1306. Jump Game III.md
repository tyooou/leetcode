### Problem Statement:

Given an array of non-negative integers `arr`, you are initially positioned at `start` index of the array. When you are at index `i`, you can jump to `i + arr[i]` or `i - arr[i]`, check if you can reach **any** index with value 0.

Notice that you can not jump outside of the array at any time.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [4,2,3,0,3,1,2], start = 5
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> All possible ways to reach at index 3 with value 0 are:
> index 5 -> index 4 -> index 1 -> index 3
> index 5 -> index 6 -> index 4 -> index 1 -> index 3
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [4,2,3,0,3,1,2], start = 0
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> One possible way to reach at index 3 with value 0 is:
> index 0 -> index 4 -> index 1 -> index 3
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> arr = [3,0,2,1,2], start = 2
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> There is no way to reach at index 1 with value 0.
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 5 * 10^4`
>
> 	- `0 <= arr[i] < arr.length`
>
> 	- `0 <= start < arr.length`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `7 ms` | `40.4 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def canReach(self, arr: List[int], start: int) -> bool:
>         n = len(arr)
>         visited = [False] * n
>
>         def search(i):
>             if i < 0 or i >= n or visited[i]:
>                 return False
>             elif arr[i] == 0:
>                 return True
>
>             visited[i] = True
>             upper = i + arr[i]
>             lower = i - arr[i]
>
>             return search(upper) or search(lower)
>
>         return search(start)
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
