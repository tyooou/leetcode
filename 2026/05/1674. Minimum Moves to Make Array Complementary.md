### Problem Statement:

You are given an integer array `nums` of **even** length `n` and an integer `limit`. In one move, you can replace any integer from `nums` with another integer between `1` and `limit`, inclusive.

The array `nums` is **complementary** if for all indices `i` (**0-indexed**), `nums[i] + nums[n - 1 - i]` equals the same number. For example, the array `[1,2,3,4]` is complementary because for all indices `i`, `nums[i] + nums[n - 1 - i] = 5`.

Return the _**minimum** number of moves required to make _`nums`_ **complementary**_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,4,3], limit = 4
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> In 1 move, you can change nums to [1,2,2,3] (underlined elements are changed).
> nums[0] + nums[3] = 1 + 3 = 4.
> nums[1] + nums[2] = 2 + 2 = 4.
> nums[2] + nums[1] = 2 + 2 = 4.
> nums[3] + nums[0] = 3 + 1 = 4.
> Therefore, nums[i] + nums[n-1-i] = 4 for every i, so nums is complementary.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,2,2,1], limit = 2
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> In 2 moves, you can change nums to [2,2,2,2]. You cannot change any number to 3 since 3 > limit.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [1,2,1,2], limit = 2
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> nums is already complementary.
> ```

> [!warning]- Constraints
> - `n == nums.length`
>
> 	- `2 <= n <= 10^5`
>
> 	- `1 <= nums[i] <= limit <= 10^5`
>
> 	- `n` is even.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `859 ms` | `31.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def minMoves(self, nums: List[int], limit: int) -> int:
>         n = len(nums)
>         sum_count = Counter()
>         min_arr = []
>         max_arr = []
>
>         for i in range(n // 2):
>             a = min(nums[i], nums[n - 1 - i])
>             b = max(nums[i], nums[n - 1 - i])
>
>             sum_count[a + b] += 1
>             min_arr.append(a)
>             max_arr.append(b)
>
>         min_arr.sort()
>         max_arr.sort()
>
>         min_ops = n
>
>         for c in range(2, 2 * limit + 1):
>             add_left = n // 2 - bisect_left(min_arr, c)
>             add_right = bisect_left(max_arr, c - limit)
>
>             current_ops = n // 2 + add_left + add_right - sum_count[c]
>             min_ops = min(min_ops, current_ops)
>
>         return min_ops
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
