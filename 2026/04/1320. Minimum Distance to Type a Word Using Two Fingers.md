### Problem Statement:

You have a keyboard layout as shown above in the **X-Y** plane, where each English uppercase letter is located at some coordinate.

	- For example, the letter `'A'` is located at coordinate `(0, 0)`, the letter `'B'` is located at coordinate `(0, 1)`, the letter `'P'` is located at coordinate `(2, 3)` and the letter `'Z'` is located at coordinate `(4, 1)`.

Given the string `word`, return _the minimum total **distance** to type such string using only two fingers_.

The **distance** between coordinates `(x_1, y_1)` and `(x_2, y_2)` is `|x_1 - x_2| + |y_1 - y_2|`.

**Note** that the initial positions of your two fingers are considered free so do not count towards your total distance, also your two fingers do not have to start at the first letter or the first two letters.

> [!example]- Example 1
> **Input:**
>
> ```python
> word = "CAKE"
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> Using two fingers, one optimal way to type "CAKE" is:
> Finger 1 on letter 'C' -> cost = 0
> Finger 1 on letter 'A' -> cost = Distance from letter 'C' to letter 'A' = 2
> Finger 2 on letter 'K' -> cost = 0
> Finger 2 on letter 'E' -> cost = Distance from letter 'K' to letter 'E' = 1
> Total distance = 3
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> word = "HAPPY"
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> Using two fingers, one optimal way to type "HAPPY" is:
> Finger 1 on letter 'H' -> cost = 0
> Finger 1 on letter 'A' -> cost = Distance from letter 'H' to letter 'A' = 2
> Finger 2 on letter 'P' -> cost = 0
> Finger 2 on letter 'P' -> cost = Distance from letter 'P' to letter 'P' = 0
> Finger 1 on letter 'Y' -> cost = Distance from letter 'A' to letter 'Y' = 4
> Total distance = 6
> ```

> [!warning]- Constraints
> - `2 <= word.length <= 300`
>
> 	- `word` consists of uppercase English letters.

### Hints:

> [!success]- Hint 1
> Use dynamic programming.

> [!success]- Hint 2
> dp[i][j][k]: smallest movements when you have one finger on i-th char and the other one on j-th char already having written k first characters from word.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `43 ms` | `19.5 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def minimumDistance(self, word: str) -> int:
>         w = len(word)
>         dp = [[0] * 26] + [[2 ** 30] * 26 for _ in range(w - 1)]
>
>         def dist(p, q):
>             x1, y1 = p // 6, p % 6
>             x2, y2 = q // 6, q % 6
>             return abs(x1 - x2) + abs(y1 - y2)
>
>         for i in range(1, w):
>             curr, prev = ord(word[i]) - 65, ord(word[i -1]) - 65
>             d = dist(prev, curr)
>             for j in range(26):
>                 dp[i][j] = min(dp[i][j], dp[i - 1][j] + d)
>                 if prev == j:
>                     for k in range(26):
>                         d0 = dist(k, curr)
>                         dp[i][j] = min(dp[i][j], dp[i - 1][k] + d0)
>
>         ans = min(dp[w - 1])
>         return ans
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
