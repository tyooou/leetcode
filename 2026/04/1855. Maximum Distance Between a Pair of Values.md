### Problem Statement:

You are given two **non-increasing 0-indexed **integer arrays `nums1`​​​​​​ and `nums2`​​​​​​.

A pair of indices `(i, j)`, where `0 <= i < nums1.length` and `0 <= j < nums2.length`, is **valid** if both `i <= j` and `nums1[i] <= nums2[j]`. The **distance** of the pair is `j - i`​​​​.

Return _the **maximum distance** of any **valid** pair _`(i, j)`_. If there are no valid pairs, return _`0`.

An array `arr` is **non-increasing** if `arr[i-1] >= arr[i]` for every `1 <= i < arr.length`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums1 = [55,30,5,4,2], nums2 = [100,20,10,10,5]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The valid pairs are (0,0), (2,2), (2,3), (2,4), (3,3), (3,4), and (4,4).
> The maximum distance is 2 with pair (2,4).
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums1 = [2,2,2], nums2 = [10,10,1]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The valid pairs are (0,0), (0,1), and (1,1).
> The maximum distance is 1 with pair (0,1).
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums1 = [30,29,19,5], nums2 = [25,25,25,25,25]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The valid pairs are (2,2), (2,3), (2,4), (3,3), and (3,4).
> The maximum distance is 2 with pair (2,4).
> ```

> [!warning]- Constraints
> - `1 <= nums1.length, nums2.length <= 10^5`
>
> 	- `1 <= nums1[i], nums2[j] <= 10^5`
>
> 	- Both `nums1` and `nums2` are **non-increasing**.

### Hints:

> [!success]- Hint 1
> Since both arrays are sorted in a non-increasing way, this means that for each value in the first array, we can find the farthest value larger than or equal to it using binary search.

> [!success]- Hint 2
> There is another solution using a two pointers approach. Since the first array is non-increasing, the farthest `j` such that `nums2[j] ≥ nums1[i]` is at least as far as the farthest `j` such that `nums2[j] ≥ nums1[i-1]`
