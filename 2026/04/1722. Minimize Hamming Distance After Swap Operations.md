### Problem Statement:

You are given two integer arrays, `source` and `target`, both of length `n`. You are also given an array `allowedSwaps` where each `allowedSwaps[i] = [a_i, b_i]` indicates that you are allowed to swap the elements at index `a_i` and index `b_i` **(0-indexed)** of array `source`. Note that you can swap elements at a specific pair of indices **multiple** times and in **any** order.

The **Hamming distance** of two arrays of the same length, `source` and `target`, is the number of positions where the elements are different. Formally, it is the number of indices `i` for `0 <= i <= n-1` where `source[i] != target[i]` **(0-indexed)**.

Return _the **minimum Hamming distance** of _`source`_ and _`target`_ after performing **any** amount of swap operations on array _`source`_._

> [!example]- Example 1
> **Input:**
>
> ```python
> source = [1,2,3,4], target = [2,1,4,5], allowedSwaps = [[0,1],[2,3]]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> source can be transformed the following way:
> - Swap indices 0 and 1: source = [2,1,3,4]
> - Swap indices 2 and 3: source = [2,1,4,3]
> The Hamming distance of source and target is 1 as they differ in 1 position: index 3.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> source = [1,2,3,4], target = [1,3,2,4], allowedSwaps = []
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> There are no allowed swaps.
> The Hamming distance of source and target is 2 as they differ in 2 positions: index 1 and index 2.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> source = [5,1,2,4,3], target = [1,5,4,2,3], allowedSwaps = [[0,4],[4,2],[1,3],[1,4]]
> ```
>
> **Output:**
>
> ```python
> 0
> ```

> [!warning]- Constraints
> - `n == source.length == target.length`
>
> 	- `1 <= n <= 10^5`
>
> 	- `1 <= source[i], target[i] <= 10^5`
>
> 	- `0 <= allowedSwaps.length <= 10^5`
>
> 	- `allowedSwaps[i].length == 2`
>
> 	- `0 <= a_i, b_i <= n - 1`
>
> 	- `a_i != b_i`

### Hints:

> [!success]- Hint 1
> The source array can be imagined as a graph where each index is a node and each allowedSwaps[i] is an edge.

> [!success]- Hint 2
> Nodes within the same component can be freely swapped with each other.

> [!success]- Hint 3
> For each component, find the number of common elements. The elements that are not in common will contribute to the total Hamming distance.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `259 ms` | `58.2 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def minimumHammingDistance(self, source: list[int], target: list[int], allowedSwaps: list[list[int]]) -> int:
>         n = len(source)
>         parent = list(range(n))
>
>         def find(x):
>             if parent[x] != x:
>                 parent[x] = find(parent[x])
>             return parent[x]
>
>         def unite(a, b):
>             parent[find(a)] = find(b)
>
>         for a, b in allowedSwaps:
>             unite(a, b)
>
>         groups = defaultdict(list)
>         for i in range(n):
>             groups[find(i)].append(source[i])
>         groups = {root: Counter(vals) for root, vals in groups.items()}
>
>         hamming_dist = 0
>         for i in range(n):
>             root = find(i)
>             freq = groups[root]
>             if freq[target[i]] > 0:
>                 freq[target[i]] -= 1  # matched, consume this source value
>             else:
>                 hamming_dist += 1     # no match found in this component
>
>         return hamming_dist
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
