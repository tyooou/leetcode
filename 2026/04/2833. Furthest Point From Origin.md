### Problem Statement:

You are given a string `moves` of length `n` consisting only of characters `'L'`, `'R'`, and `'_'`. The string represents your movement on a number line starting from the origin `0`.

In the `i^th` move, you can choose one of the following directions:

	- move to the left if `moves[i] = 'L'` or `moves[i] = '_'`

	- move to the right if `moves[i] = 'R'` or `moves[i] = '_'`

Return _the **distance from the origin** of the **furthest** point you can get to after _`n`_ moves_.

> [!example]- Example 1
> **Input:**
>
> ```python
> moves = "L_RL__R"
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The furthest point we can reach from the origin 0 is point -3 through the following sequence of moves "LLRLLLR".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> moves = "_R__LL_"
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> The furthest point we can reach from the origin 0 is point -5 through the following sequence of moves "LRLLLLL".
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> moves = "_______"
> ```
>
> **Output:**
>
> ```python
> 7
> ```
>
> **Explanation:**
>
> ```python
> The furthest point we can reach from the origin 0 is point 7 through the following sequence of moves "RRRRRRR".
> ```

> [!warning]- Constraints
> - `1 <= moves.length == n <= 50`
>
> 	- `moves` consists only of characters `'L'`, `'R'` and `'_'`.

### Hints:

> [!success]- Hint 1
> In an optimal answer, all occurrences of `'_’` will be replaced with the **same** character.

> [!success]- Hint 2
> Replace all characters of `'_’` with the character that occurs the most.

> ```python
> class Solution:
>     def furthestDistanceFromOrigin(self, moves: str) -> int:
>         p = 0
>         e = 0
>         for m in moves:
>             if m == 'L':
>                 p += 1
>             elif m == 'R':
>                 p -= 1
>             else:
>                 e += 1
>         return abs(p) + e
>
> ```
