### Problem Statement:

You are given an `m x n` grid where each cell contains one of the values 0, 1, or 2. You are also given an integer `k`.

You start from the top-left corner `(0, 0)` and want to reach the bottom-right corner `(m - 1, n - 1)` by moving only **right** or **down**.

Each cell contributes a specific score and incurs an associated cost, according to their cell values:

	- 0: adds 0 to your score and costs 0.

	- 1: adds 1 to your score and costs 1.

	- 2: adds 2 to your score and costs 1. ​​​​​​​

Return the **maximum** score achievable without exceeding a total cost of `k`, or -1 if no valid path exists.

**Note:** If you reach the last cell but the total cost exceeds `k`, the path is invalid.

> [!example]- Example 1
> **Input:** grid = [[0, 1],[2, 0]], k = 1
>
> **Output:** 2
>
> **Explanation:**​​​​​​​
>
> The optimal path is:
>
> 			Cell
> 			grid[i][j]
> 			Score
> 			Total
>
> 			Score
> 			Cost
> 			Total
>
> 			Cost
>
> 			(0, 0)
> 			0
> 			0
> 			0
> 			0
> 			0
>
> 			(1, 0)
> 			2
> 			2
> 			2
> 			1
> 			1
>
> 			(1, 1)
> 			0
> 			0
> 			2
> 			0
> 			1
>
> Thus, the maximum possible score is 2.

> [!example]- Example 2
> **Input:** grid = [[0, 1],[1, 2]], k = 1
>
> **Output:** -1
>
> **Explanation:**
>
> There is no path that reaches cell `(1, 1)`​​​​​​​ without exceeding cost k. Thus, the answer is -1.

> [!warning]- Constraints
> - `1 <= m, n <= 200`
>
> 	- `0 <= k <= 10^3​​​​​​​`
>
> 	- `^​​​​​​​grid[0][0] == 0`
>
> 	- `0 <= grid[i][j] <= 2`

### Hints:

> [!success]- Hint 1
> Use dynamic programming.

> [!success]- Hint 2
> Let `dp[i][j][c]` = max score at cell `(i,j)` with total cost exactly `c` (0 <= `c` <= `k`).

> [!success]- Hint 3
> Update `dp[i][j][c]` from `(i-1,j)` and `(i,j-1)` using `cost = (grid[i][j] == 0 ? 0 : 1)` and `score = grid[i][j]`.

> [!success]- Hint 4
> Answer = `max(dp[m-1][n-1][c])` for `c=0..k`, or `-1` if none.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `7368 ms` | `36.6 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def maxPathScore(self, grid: List[List[int]], k: int) -> int:
>         m, n = len(grid), len(grid[0])
>         inf = float("-inf")
>
>         # dp array of inf
>         dp = [[[inf] * (k + 1) for _ in range(n)] for _ in range(m)]
>         dp[0][0][0] = 0
>
>         for i in range(m):
>             for j in range(n):
>                 for c in range(k + 1): # cannot exceed k
>                     if dp[i][j][c] == inf: # impossible path
>                         continue
>
>                     if i + 1 < m: # check down movement
>                         val = grid[i + 1][j]
>                         cost = 0 if val == 0 else 1
>                         if c + cost <= k:
>                             dp[i + 1][j][c + cost] = max(
>                                 dp[i + 1][j][c + cost], dp[i][j][c] + val
>                             ) # maximum of existing vs new
>                     if j + 1 < n: # check right movement
>                         val = grid[i][j + 1]
>                         cost = 0 if val == 0 else 1
>                         if c + cost <= k:
>                             dp[i][j + 1][c + cost] = max(
>                                 dp[i][j + 1][c + cost], dp[i][j][c] + val
>                             ) # maximum of existing vs new
>
>         ans = max(dp[m - 1][n - 1])
>         return -1 if ans < 0 else ans
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
