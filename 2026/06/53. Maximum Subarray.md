### Problem Statement:

Given an integer array `nums`, find the subarray with the largest sum, and return _its sum_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [-2,1,-3,4,-1,2,1,-5,4]
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The subarray [4,-1,2,1] has the largest sum 6.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The subarray [1] has the largest sum 1.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [5,4,-1,7,8]
> ```
>
> **Output:**
>
> ```python
> 23
> ```
>
> **Explanation:**
>
> ```python
> The subarray [5,4,-1,7,8] has the largest sum 23.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `-10^4 <= nums[i] <= 10^4`
>
>
>
> **Follow up:** If you have figured out the `O(n)` solution, try coding another solution using the **divide and conquer** approach, which is more subtle.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `31 ms` | `31.5 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxSubArray(self, nums: List[int]) -> int:
>         res = nums[0]
>         total = 0
>
>         for n in nums:
>             if total < 0:
>                 total = 0
>             total += n
>             res = max(res, total)
>
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
