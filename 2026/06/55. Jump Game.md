### Problem Statement:

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true`_ if you can reach the last index, or _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [2,3,1,1,4]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> Jump 1 step from index 0 to 1, then 3 steps to the last index.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [3,2,1,0,4]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> You will always arrive at index 3 no matter what. Its maximum jump length is 0, which makes it impossible to reach the last index.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^4`
>
> 	- `0 <= nums[i] <= 10^5`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4503 ms` | `20.4 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def canJump(self, nums: List[int]) -> bool:
>         n = len(nums)
>         dp = [False] * n
>         dp[0] = True
>         reach = 0
>
>         if n == 1:
>             return True
>
>         for i in range(n):
>             if dp[i]:
>                 for j in range(1, nums[i] + 1):
>                     if i + j < n - 1:
>                         dp[i + j] = True
>                         reach = max(i + j, reach)
>                     else: return True
>             elif i > reach:
>                 return False
>         return False
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
