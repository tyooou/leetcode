### Problem Statement:

You are given a string array `words` and a **binary** array `groups` both of length `n`.

A subsequence of `words` is **alternating** if for any two _consecutive_ strings in the sequence, their corresponding elements at the _same_ indices in `groups` are **different** (that is, there _cannot_ be consecutive 0 or 1).

Your task is to select the **longest alternating** subsequence from `words`.

Return _the selected subsequence. If there are multiple answers, return **any** of them._

**Note:** The elements in `words` are distinct.

> [!example]- Example 1
> **Input:** words = ["e","a","b"], groups = [0,0,1]
>
> **Output:** ["e","b"]
>
> **Explanation:** A subsequence that can be selected is `["e","b"]` because `groups[0] != groups[2]`. Another subsequence that can be selected is `["a","b"]` because `groups[1] != groups[2]`. It can be demonstrated that the length of the longest subsequence of indices that satisfies the condition is `2`.

> [!example]- Example 2
> **Input:** words = ["a","b","c","d"], groups = [1,0,1,1]
>
> **Output:** ["a","b","c"]
>
> **Explanation:** A subsequence that can be selected is `["a","b","c"]` because `groups[0] != groups[1]` and `groups[1] != groups[2]`. Another subsequence that can be selected is `["a","b","d"]` because `groups[0] != groups[1]` and `groups[1] != groups[3]`. It can be shown that the length of the longest subsequence of indices that satisfies the condition is `3`.

> [!warning]- Constraints
> - `1 <= n == words.length == groups.length <= 100`
>
> 	- `1 <= words[i].length <= 10`
>
> 	- `groups[i]` is either `0` or `1.`
>
> 	- `words` consists of **distinct** strings.
>
> 	- `words[i]` consists of lowercase English letters.

### Hints:

> [!success]- Hint 1
> This problem can be solved greedily.

> [!success]- Hint 2
> Begin by constructing the answer starting with the first number in `groups`.

> [!success]- Hint 3
> For each index `i` in the range `[1, n - 1]`, add `i` to the answer if `groups[i] != groups[i - 1]`.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def getLongestSubsequence(self, words: List[str], groups: List[int]) -> List[str]:
>         return [words[0]] + [words[i] for i in range(1, len(groups)) if groups[i] != groups[i - 1]]
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
