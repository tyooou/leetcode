### Problem Statement:

There is a biker going on a road trip. The road trip consists of `n + 1` points at various altitudes. The biker starts his trip on point `0` with altitude equal `0`.

You are given an integer array `gain` of length `n` where `gain[i]` is the **net gain in altitude** between points `i`​​​​​​ and `i + 1` for all (`0 <= i < n)`. Return _the **highest altitude** of a point._

> [!example]- Example 1
> **Input:**
>
> ```python
> gain = [-5,1,5,0,-7]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The altitudes are [0,-5,-4,1,1,-6]. The highest is 1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> gain = [-4,-3,-2,-1,4,3,2]
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> The altitudes are [0,-4,-7,-9,-10,-6,-3,-1]. The highest is 0.
> ```

> [!warning]- Constraints
> - `n == gain.length`
>
> - `1 <= n <= 100`
>
> - `-100 <= gain[i] <= 100`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def largestAltitude(self, gain: List[int]) -> int:
>         curr_altitude, max_altitude = 0, 0
>         for g in gain:
>             curr_altitude += g
>             max_altitude = max(curr_altitude, max_altitude)
>         return max_altitude
>
> ```

> [!success]- Reasoning
> 1. Track a running altitude starting at 0, adding each `gain` value in sequence.
> 2. Update a running max after each step.
> 3. Return the max altitude reached across the whole trip.
>
> **Key insight:** this is just a prefix-sum max — no need to materialize the full altitude array.
