### Problem Statement:

You are given a string `s` consisting of lowercase English letters and the special characters: `*`, `#`, and `%`.

Build a new string `result` by processing `s` according to the following rules from left to right:

- If the letter is a **lowercase** English letter append it to `result`.

- A `'*'` **removes** the last character from `result`, if it exists.

- A `'#'` **duplicates** the current `result` and **appends** it to itself.

- A `'%'` **reverses** the current `result`.

Return the final string `result` after processing all characters in `s`.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "a#b%*"
> ```
>
> **Output:**
>
> ```python
> "ba"
> ```
>
> **Explanation:**
>
> ```python
> `i`
> 			`s[i]`
> 			Operation
> 			Current `result`
>
> 			0
> 			`'a'`
> 			Append `'a'`
> 			`"a"`
>
> 			1
> 			`'#'`
> 			Duplicate `result`
> 			`"aa"`
>
> 			2
> 			`'b'`
> 			Append `'b'`
> 			`"aab"`
>
> 			3
> 			`'%'`
> 			Reverse `result`
> 			`"baa"`
>
> 			4
> 			`'*'`
> 			Remove the last character
> 			`"ba"`
>
> Thus, the final `result` is `"ba"`.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "z*#"
> ```
>
> **Output:**
>
> ```python
> ""
> ```
>
> **Explanation:**
>
> ```python
> `i`
> 			`s[i]`
> 			Operation
> 			Current `result`
>
> 			0
> 			`'z'`
> 			Append `'z'`
> 			`"z"`
>
> 			1
> 			`'*'`
> 			Remove the last character
> 			`""`
>
> 			2
> 			`'#'`
> 			Duplicate the string
> 			`""`
>
> Thus, the final `result` is `""`.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 20`
>
> - `s` consists of only lowercase English letters and special characters `*`, `#`, and `%`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(2^n)` | `O(2^n)` |
>
> ```python
> class Solution:
>     def processStr(self, s: str) -> str:
>         ans = ''
>         for c in s:
>             match c:
>                 case '*':
>                     ans = ans[:-1]
>                 case '#':
>                     ans += ans
>                 case '%':
>                     ans = ans[::-1]
>                 case _:
>                     ans += c
>         return ans
> ```

> [!success]- Reasoning
> 1. Walk `s` left to right, using a `match` statement to dispatch on each special character.
> 2. `'*'` pops the last char via slicing, `'#'` duplicates via self-concatenation, `'%'` reverses via `[::-1]`.
> 3. Ordinary letters get appended directly to `ans`.
>
> **Key insight:** Python's string slicing (`ans[:-1]`, `ans+ans`, `ans[::-1]`) implements every operation directly with no manual buffer needed.
