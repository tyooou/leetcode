### Problem Statement:

You are given the `head` of a linked list. **Delete** the **middle node**, and return _the_ `head` _of the modified linked list_.

The **middle node** of a linked list of size `n` is the `⌊n / 2⌋^th` node from the **start** using **0-based indexing**, where `⌊x⌋` denotes the largest integer less than or equal to `x`.

- For `n` = `1`, `2`, `3`, `4`, and `5`, the middle nodes are `0`, `1`, `1`, `2`, and `2`, respectively.

> [!example]- Example 1
> **Input:**
>
> ```python
> head = [1,3,4,7,1,2,6]
> ```
>
> **Output:**
>
> ```python
> [1,3,4,1,2,6]
> ```
>
> **Explanation:**
>
> ```python
> The above figure represents the given linked list. The indices of the nodes are written below.
> Since n = 7, node 3 with value 7 is the middle node, which is marked in red.
> We return the new list after removing this node.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> head = [1,2,3,4]
> ```
>
> **Output:**
>
> ```python
> [1,2,4]
> ```
>
> **Explanation:**
>
> ```python
> The above figure represents the given linked list.
> For n = 4, node 2 with value 3 is the middle node, which is marked in red.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> head = [2,1]
> ```
>
> **Output:**
>
> ```python
> [2]
> ```
>
> **Explanation:**
>
> ```python
> The above figure represents the given linked list.
> For n = 2, node 1 with value 1 is the middle node, which is marked in red.
> Node 0 with value 2 is the only node remaining after removing node 1.
> ```

> [!warning]- Constraints
> - The number of nodes in the list is in the range `[1, 10^5]`.
>
> - `1 <= Node.val <= 10^5`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n)` | `O(1)` |
>
> ```python
> # Definition for singly-linked list.
> # class ListNode:
> #     def __init__(self, val=0, next=None):
> #         self.val = val
> #         self.next = next
> class Solution:
>     def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         slow = fast = head
>         prev = None
>
>         if not head.next:
>             return None
>
>         while fast and fast.next:
>             prev = slow
>             fast = fast.next.next
>             slow = slow.next
>
>         if prev: prev.next = slow.next if slow else None
>         return head
> ```

> [!success]- Reasoning
> 1. Special-case a single-node list: return `None` immediately since deleting the only node empties the list.
> 2. Use fast/slow pointers (fast moves 2 steps, slow 1) to reach the middle in a single pass, tracking `prev` as the node before `slow`.
> 3. Once `fast` runs off the end, unlink `slow` by pointing `prev.next` past it.
>
> **Key insight:** fast/slow pointers locate the middle node in one pass without needing the list length upfront.
