### Problem Statement:

Given two integer arrays `arr1` and `arr2`, and the integer `d`, _return the distance value between the two arrays_.

The distance value is defined as the number of elements `arr1[i]` such that there is not any element `arr2[j]` where `|arr1[i]-arr2[j]| <= d`.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> For arr1[0]=4 we have:
> |4-10|=6 > d=2
> |4-9|=5 > d=2
> |4-1|=3 > d=2
> |4-8|=4 > d=2
> For arr1[1]=5 we have:
> |5-10|=5 > d=2
> |5-9|=4 > d=2
> |5-1|=4 > d=2
> |5-8|=3 > d=2
> For arr1[2]=8 we have:
> **|8-10|=2 <= d=2**
> **|8-9|=1 <= d=2**
> |8-1|=7 > d=2
> **|8-8|=0 <= d=2**
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3
> ```
>
> **Output:**
>
> ```python
> 2
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6
> ```
>
> **Output:**
>
> ```python
> 1
> ```

> [!warning]- Constraints
> - `1 <= arr1.length, arr2.length <= 500`
>
> 	- `-1000 <= arr1[i], arr2[j] <= 1000`
>
> 	- `0 <= d <= 100`

### Hints:

> [!success]- Hint 1
> Sort 'arr2' and use binary search to get the closest element for each 'arr1[i]', it gives a time complexity of O(nlogn).

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `24 ms` | `19.3 MB` | `O(n*m)` | `O(1)` |
>
> ```python
> class Solution:
>     def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
>         t = len(arr2)
>         ans = 0
>         for x in arr1:
>             c = 0
>             while c < t and abs(x - arr2[c]) > d:
>                 c += 1
>             if c == t:
>                 ans += 1
>         return ans
>
>
> ```

> [!success]- Reasoning
> 1. Iterate through each element in arr1
> 2. For each arr1[i], scan through arr2 to find ANY element within distance d
> 3. Use a counter to check if the scan reaches the end (no match found)
> 4. Increment answer count only when no matching element exists in arr2
> 
> **Key insight:** Brute force linear search through arr2 for each arr1 element.
