### Problem Statement:

You are given a string `s` that consists of lower case English letters and brackets.

Reverse the strings in each pair of matching parentheses, starting from the innermost one.

Your result should **not** contain any brackets.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "(abcd)"
> ```
>
> **Output:**
>
> ```python
> "dcba"
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "(u(love)i)"
> ```
>
> **Output:**
>
> ```python
> "iloveu"
> ```
>
> **Explanation:**
>
> ```python
> The substring "love" is reversed first, then the whole string is reversed.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "(ed(et(oc))el)"
> ```
>
> **Output:**
>
> ```python
> "leetcode"
> ```
>
> **Explanation:**
>
> ```python
> First, we reverse the substring "oc", then "etco", and finally, the whole string.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 2000`
>
> 	- `s` only contains lower case English characters and parentheses.
>
> 	- It is guaranteed that all parentheses are balanced.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def reverseParentheses(self, s: str) -> str:
>         n = len(s)
>         link = [0] * n
>         stk = res = []
>
>         for i, c in enumerate(s):
>             if c == '(':
>                 stk.append(i)
>             elif c == ')':
>                 j = stk.pop()
>                 link[i] = j
>                 link[j] = i
>
>         dr, i = 1, 0
>         while i < n:
>             if s[i] >= 'a':
>                 res.append(s[i])
>             else:
>                 i = link[i]
>                 dr = -dr
>
>             i += dr
>
>         return ''.join(res)
> ```

> [!success]- Reasoning
> 1. Build a link map connecting each `(` with its matching `)` using a stack
> 2. Traverse the string left-to-right (initially), collecting non-parenthesis characters
> 3. When encountering a parenthesis, jump to its matched pair and reverse direction
> 4. Repeat until the entire string is traversed with direction reversals handling nested reversals
>
> **Key insight:** Use parenthesis-linking with direction reversal to implicitly handle nested reversal in one pass.
