### Problem Statement:

You are given a circle represented as `(radius, xCenter, yCenter)` and an axis-aligned rectangle represented as `(x1, y1, x2, y2)`, where `(x1, y1)` are the coordinates of the bottom-left corner, and `(x2, y2)` are the coordinates of the top-right corner of the rectangle.

Return `true`_ if the circle and rectangle are overlapped otherwise return _`false`. In other words, check if there is **any** point `(x_i, y_i)` that belongs to the circle and the rectangle at the same time.

> [!example]- Example 1
> **Input:**
>
> ```python
> radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> Circle and rectangle share the point (1,0).
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1
> ```
>
> **Output:**
>
> ```python
> false
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> radius = 1, xCenter = 0, yCenter = 0, x1 = -1, y1 = 0, x2 = 0, y2 = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```

> [!warning]- Constraints
> - `1 <= radius <= 2000`
>
> 	- `-10^4 <= xCenter, yCenter <= 10^4`
>
> 	- `-10^4 <= x1 < x2 <= 10^4`
>
> 	- `-10^4 <= y1 < y2 <= 10^4`

---

### Hints:

> [!success]- Hint 1
> Locate the closest point of the square to the circle, you can then find the distance from this point to the center of the circle and check if this is less than or equal to the radius.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.4 MB` | `O(1)` | `O(1)` |
>
> ```python
> class Solution:
>     def checkOverlap(self, radius: int, xCenter: int, yCenter: int, x1: int, y1: int, x2: int, y2: int) -> bool:
>         x = max(x1, min(xCenter, x2)) - xCenter
>         y = max(y1, min(yCenter, y2)) - yCenter
>
>         return x * x + y * y <= radius * radius
> ```

> [!success]- Reasoning
> 1. Find closest point on rectangle to circle center by clamping center coordinates.
> 2. Clamp x-coordinate between rectangle bounds x1 and x2.
> 3. Clamp y-coordinate between rectangle bounds y1 and y2.
> 4. Calculate squared distance from clamped point to circle center.
> 5. Compare squared distance with squared radius to determine overlap.
>
> **Key insight:** Closest point projection avoids floating-point by using squared distance comparison.
