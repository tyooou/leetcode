### Problem Statement:

Given a **valid parentheses string** `s`, return the **nesting depth** of_ _`s`. The nesting depth is the **maximum** number of nested parentheses.

> [!example]- Example 1
> **Input:** s = "(1+(2*3)+((8)/4))+1"
>
> **Output:** 3
>
> **Explanation:**
>
> Digit 8 is inside of 3 nested parentheses in the string.

> [!example]- Example 2
> **Input:** s = "(1)+((2))+(((3)))"
>
> **Output:** 3
>
> **Explanation:**
>
> Digit 3 is inside of 3 nested parentheses in the string.

> [!example]- Example 3
> **Input:** s = "()(())((()()))"
>
> **Output:** 3

> [!warning]- Constraints
> - `1 <= s.length <= 100`
>
> 	- `s` consists of digits `0-9` and characters `'+'`, `'-'`, `'*'`, `'/'`, `'('`, and `')'`.
>
> 	- It is guaranteed that parentheses expression `s` is a VPS.

---

### Hints:

> [!success]- Hint 1
> The depth of any character in the VPS is the ( number of left brackets before it ) - ( number of right brackets before it )

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.2 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def maxDepth(self, s: str) -> int:
>         a, ans = [], 0
>         for c in s:
>             if c == "(":
>                 a.append(c)
>                 ans = max(ans, len(a))
>             elif c == ")":
>                 a.pop()
>         return ans
> ```

> [!success]- Reasoning
> 1. Initialize empty stack to track current nesting level and max depth counter.
> 2. Iterate through each character; when '(' encountered, push to stack and update max depth.
> 3. When ')' encountered, pop from stack to reduce current depth.
> 4. Ignore non-bracket characters (digits, operators).
> 5. Return the maximum depth observed during traversal.
>
> **Key insight:** Stack depth represents current nesting level; maximum size is the answer.
