### Problem Statement:

You are given a string `s` and a **positive** integer `k`.

Select a set of **non-overlapping** substrings from the string `s` that satisfy the following conditions:

	- The **length** of each substring is **at least** `k`.

	- Each substring is a **palindrome**.

Return _the **maximum** number of substrings in an optimal selection_.

A **substring** is a contiguous sequence of characters within a string.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "abaccdbbd", k = 3
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> We can select the substrings underlined in s = "**aba**cc**dbbd**". Both "aba" and "dbbd" are palindromes and have a length of at least k = 3.
> It can be shown that we cannot find a selection with more than two valid substrings.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "adbcda", k = 2
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> There is no palindrome substring of length at least 2 in the string.
> ```

> [!warning]- Constraints
> - `1 <= k <= s.length <= 2000`
>
> 	- `s` consists of lowercase English letters.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(n*k)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxPalindromes(self, s: str, k: int) -> int:
>         def check(l: int, r: int) -> bool:
>             while l < r:
>                 if s[l] != s[r]:
>                     return False
>                 l += 1
>                 r -= 1
>             return True
>
>         n = len(s)
>         ans = 0
>         start = 0
>
>         for r in range(k - 1, n):
>             l = r - k + 1
>             if l >= start and check(l, r):
>                 ans += 1
>                 start = r + 1
>                 continue
>
>             l = r - k
>             if l >= start and check(l, r):
>                 ans += 1
>                 start = r + 1
>
>         return ans
> ```

> [!success]- Reasoning
> 1. Use a greedy left-to-right scan: maintain a `start` pointer marking the earliest position available for the next palindrome.
> 2. For each position r, check if a palindrome of exactly length k ends at r (substring [r-k+1, r]); if found, greedily take it.
> 3. If no length-k palindrome exists at r, check for length k+1 palindrome (substring [r-k, r]) to maximize coverage.
> 4. When a valid palindrome is found, increment count and move start past its end to ensure non-overlapping selections.
>
> **Key insight:** Greedy selection of the shortest valid palindromes maximizes the count of non-overlapping palindromes.
