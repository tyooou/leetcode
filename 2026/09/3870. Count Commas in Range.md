### Problem Statement:

You are given an integer `n`.

Return the **total** number of commas used when writing all integers from `[1, n]` (inclusive) in **standard** number formatting.

In **standard** formatting:

	- A comma is inserted after **every three** digits from the right.

	- Numbers with **fewer** than 4 digits contain no commas.

> [!example]- Example 1
> **Input:** n = 1002
>
> **Output:** 3
>
> **Explanation:**
>
> The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma, giving a total of 3.

> [!example]- Example 2
> **Input:** n = 998
>
> **Output:** 0
>
> **Explanation:**
>
> All numbers from 1 to 998 have fewer than four digits. Therefore, no commas are used.

> [!warning]- Constraints
> - `1 <= n <= 10^5`

---

### Hints:

> [!success]- Hint 1
> Numbers in the range `[1000, 100000]` have one comma.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.4 MB` | `O(1)` | `O(1)` |
>
> ```python
> class Solution:
>     def countCommas(self, n: int) -> int:
>         return n - 999 if n > 999 else 0
> ```

> [!success]- Reasoning
> 1. Numbers 1–999 have fewer than 4 digits, so no commas appear.
> 2. Starting from 1000, every number in the range [1000, n] contains exactly one comma (the thousands separator).
> 3. The count of such numbers is (n - 999).
> 4. This count directly gives the total number of commas needed.
>
> **Key insight:** In standard formatting within the constraint n ≤ 100,000, each number ≥ 1000 has exactly one comma.
