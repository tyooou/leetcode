### Problem Statement:

A parentheses string is a **non-empty** string consisting only of `'('` and `')'`. It is **valid** if **any** of the following conditions is **true**:

	- It is `()`.

	- It can be written as `AB` (`A` concatenated with `B`), where `A` and `B` are valid parentheses strings.

	- It can be written as `(A)`, where `A` is a valid parentheses string.

You are given an `m x n` matrix of parentheses `grid`. A **valid parentheses string path** in the grid is a path satisfying **all** of the following conditions:

	- The path starts from the upper left cell `(0, 0)`.

	- The path ends at the bottom-right cell `(m - 1, n - 1)`.

	- The path only ever moves **down** or **right**.

	- The resulting parentheses string formed by the path is **valid**.

Return `true` _if there exists a **valid parentheses string path** in the grid._ Otherwise, return `false`.

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [["(","(","("],[")","(",")"],["(","(",")"],["(","(",")"]]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The above diagram shows two possible paths that form valid parentheses strings.
> The first path shown results in the valid parentheses string "()(())".
> The second path shown results in the valid parentheses string "((()))".
> Note that there may be other valid parentheses string paths.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[")",")"],["(","("]]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The two possible paths form the parentheses strings "))(" and ")((". Since neither of them are valid parentheses strings, we return false.
> ```

> [!warning]- Constraints
> - `m == grid.length`
>
> 	- `n == grid[i].length`
>
> 	- `1 <= m, n <= 100`
>
> 	- `grid[i][j]` is either `'('` or `')'`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `22 ms` | `21 MB` | `O(m*n)` | `O(m*n)` |
>
> ```python
> class Solution:
>     def hasValidPath(self, grid: list[list[str]]) -> bool:
>         n = len(grid)
>         m = len(grid[0])
>         path_len = n + m - 1
>
>         if path_len % 2 == 1:
>             return False
>         if grid[0][0] != "(" or grid[n - 1][m - 1] != ")":
>             return False
>
>         dp = [[0] * m for _ in range(n)]
>
>         dp[0][0] = 1 << 1
>
>         for i in range(n):
>             for j in range(m):
>                 change = 1 if grid[i][j] == "(" else -1
>
>                 if i > 0:
>                     if change == 1:
>                         dp[i][j] |= dp[i - 1][j] << 1
>                     else:
>                         dp[i][j] |= dp[i - 1][j] >> 1
>
>                 if j > 0:
>                     if change == 1:
>                         dp[i][j] |= dp[i][j - 1] << 1
>                     else:
>                         dp[i][j] |= dp[i][j - 1] >> 1
>
>         return bool(dp[n - 1][m - 1] & 1)
> ```

> [!success]- Reasoning
> 1. Early exit: path must be even length and start with `(`, end with `)`
> 2. Use bitmask DP where each bit represents a reachable bracket balance state (open count)
> 3. For each cell, compute reachable states from previous cells by shifting: left shift for `(`, right shift for `)`
> 4. Check if final position has balance = 1 (all brackets matched) via bitwise AND with 1
>
> **Key insight:** Bitwise DP tracks all valid bracket balance states simultaneously at each grid position.
