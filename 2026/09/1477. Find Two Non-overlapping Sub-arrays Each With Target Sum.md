### Problem Statement:

You are given an array of integers `arr` and an integer `target`.

You have to find **two non-overlapping sub-arrays** of `arr` each with a sum equal `target`. There can be multiple answers so you have to find an answer where the sum of the lengths of the two sub-arrays is **minimum**.

Return _the minimum sum of the lengths_ of the two required sub-arrays, or return `-1` if you cannot find such two sub-arrays.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [3,2,2,4,3], target = 3
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Only two sub-arrays have sum = 3 ([3] and [3]). The sum of their lengths is 2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [7,3,4,7], target = 7
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Although we have three non-overlapping sub-arrays of sum = 7 ([7], [3,4] and [7]), but we will choose the first and third sub-arrays as the sum of their lengths is 2.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> arr = [4,3,2,6,2,3,4], target = 6
> ```
>
> **Output:**
>
> ```python
> -1
> ```
>
> **Explanation:**
>
> ```python
> We have only one sub-array of sum = 6.
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 10^5`
>
> 	- `1 <= arr[i] <= 1000`
>
> 	- `1 <= target <= 10^8`

### Hints:

> [!success]- Hint 1
> Let's create two arrays prefix and suffix where prefix[i] is the minimum length of sub-array ends before i and has sum = k, suffix[i] is the minimum length of sub-array starting at or after i and has sum = k.

> [!success]- Hint 2
> The answer we are searching for is min(prefix[i] + suffix[i]) for all values of i from 0 to n-1 where n == arr.length.

> [!success]- Hint 3
> If you are still stuck with how to build prefix and suffix, you can store for each index i the length of the sub-array starts at i and has sum = k or infinity otherwise, and you can use it to build both prefix and suffix.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `107 ms` | `31.1 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def minSumOfLengths(self, arr: list[int], target: int) -> int:
>         n = len(arr)
>         INF = float('inf')
>         best_ending_by = [INF] * (n + 1)
>
>         l = 0
>         curr = 0
>         ans = INF
>
>         for r in range(n):
>             curr += arr[r]
>             while curr > target:
>                 curr -= arr[l]
>                 l += 1
>
>             best_ending_by[r + 1] = best_ending_by[r]
>
>             if curr == target:
>                 length = r - l + 1
>                 if best_ending_by[l] < INF:
>                     ans = min(ans, best_ending_by[l] + length)
>                 best_ending_by[r + 1] = min(best_ending_by[r], length)
>
>         return ans if ans < INF else -1
> ```

> [!success]- Reasoning
> 1. Use sliding window to find subarrays with sum equal to target.
> 2. Maintain `best_ending_by[i]` tracking minimum length subarray ending at or before position i.
> 3. When current window sums to target, check if valid subarray exists before this window.
> 4. If yes, update answer with sum of both subarray lengths; update best length.
> 5. Window slides right to left when sum exceeds target, ensuring all subarrays found.
>
> **Key insight:** Track best-so-far lengths to find second subarray in single pass with no overlap.
