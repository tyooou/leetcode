### Problem Statement:

Given `n` points on a 1-D plane, where the `i^th` point (from `0` to `n-1`) is at `x = i`, find the number of ways we can draw **exactly** `k` **non-overlapping** line segments such that each segment covers two or more points. The endpoints of each segment must have **integral coordinates**. The `k` line segments **do not** have to cover all `n` points, and they are **allowed** to share endpoints.

Return _the number of ways we can draw _`k`_ non-overlapping line segments__._ Since this number can be huge, return it **modulo** `10^9 + 7`.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 4, k = 2
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> The two line segments are shown in red and blue.
> The image above shows the 5 different ways {(0,2),(2,3)}, {(0,1),(1,3)}, {(0,1),(2,3)}, {(1,2),(2,3)}, {(0,1),(1,2)}.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 3, k = 1
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The 3 ways are {(0,1)}, {(0,2)}, {(1,2)}.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 30, k = 7
> ```
>
> **Output:**
>
> ```python
> 796297179
> ```
>
> **Explanation:**
>
> ```python
> The total number of possible ways to draw 7 line segments is 3796297200. Taking this number modulo 10^9 + 7 gives us 796297179.
> ```

> [!warning]- Constraints
> - `2 <= n <= 1000`
>
> 	- `1 <= k <= n-1`

### Hints:

> [!success]- Hint 1
> Try to use dynamic programming where the current index and remaining number of line segments to form can describe any intermediate state.

> [!success]- Hint 2
> To make the computation of each state in constant time, we could add another flag to the state that indicates whether or not we are in the middle of placing a line (placed start point but no endpoint).

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `475 ms` | `19.4 MB` | `O(n*k)` | `O(n)` |
>
> ```python
> class Solution:
>     def numberOfSets(self, n: int, k: int) -> int:
>         mod = 10 ** 9 + 7
>         dp = [1] * n
>         prefix_sums = [0] * (n + 1)
>         for j in range(n):
>             prefix_sums[j + 1] = (prefix_sums[j] + dp[j]) % mod
>         for _ in range(k):
>             dp[0] = 0
>             for j in range(1, n):
>                 dp[j] = (dp[j - 1] + prefix_sums[j]) % mod
>             for j in range(n):
>                 prefix_sums[j + 1] = (prefix_sums[j] + dp[j]) % mod
>         return dp[n - 1]
>
> ```

> [!success]- Reasoning
> 1. Initialize DP array with combinatorial base case where 1 segment can be placed in n ways.
> 2. Build prefix sum array to enable O(1) DP state transitions.
> 3. Iterate k times, each iteration computes ways to form i segments using cumulative sums.
> 4. For each segment, state represents combinations of non-overlapping placements up to that index.
> 5. Return final DP value at position n-1 after k iterations.
>
> **Key insight:** Prefix sums transform O(n) per DP state into O(1), enabling efficient multi-segment counting.
