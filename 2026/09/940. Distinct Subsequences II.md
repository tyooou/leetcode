### Problem Statement:

Given a string s, return _the number of **distinct non-empty subsequences** of_ `s`. Since the answer may be very large, return it **modulo** `10^9 + 7`.

A **subsequence** of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (i.e., `"ace"` is a subsequence of `"abcde"` while `"aec"` is not.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "abc"
> ```
>
> **Output:**
>
> ```python
> 7
> ```
>
> **Explanation:**
>
> ```python
> The 7 distinct subsequences are "a", "b", "c", "ab", "ac", "bc", and "abc".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "aba"
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The 6 distinct subsequences are "a", "b", "ab", "aa", "ba", and "aba".
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "aaa"
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The 3 distinct subsequences are "a", "aa" and "aaa".
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 2000`
>
> 	- `s` consists of lowercase English letters.

>
> ```python
> class Solution:
>     def distinctSubseqII(self, s: str) -> int:
>         mod = 10 ** 9 + 7
>         dp = [0] * (len(s) + 1)
>         dp[0] = 1
>         last_seen = {}
>
>         for i in range(1, len(s) + 1):
>             char = s[i - 1]
>             dp[i] = (2 * dp[i - 1]) % mod
>             if char in last_seen:
>                 dp[i] = (dp[i] - dp[last_seen[char] - 1]) % mod
>             last_seen[char] = i
>
>         return (dp[len(s)] - 1 + mod) % mod
> ```
