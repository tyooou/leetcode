### Problem Statement:

You are given an integer `n`.

Return the **total** number of commas used when writing all integers from `[1, n]` (inclusive) in **standard** number formatting.

In **standard** formatting:

	- A comma is inserted after **every three** digits from the right.

	- Numbers with **fewer** than 4 digits contain no commas.

> [!example]- Example 1
> **Input:** n = 1002
>
> **Output:** 3
>
> **Explanation:**
>
> The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma, giving a total of 3.

> [!example]- Example 2
> **Input:** n = 998
>
> **Output:** 0
>
> **Explanation:**
>
> **​​​​​​​**All numbers from 1 to 998 have fewer than four digits. Therefore, no commas are used.

> [!warning]- Constraints
> - `1 <= n <= 10^15`

---

### Hints:

> [!success]- Hint 1
> Count the numbers in each comma group (1-3 digits, 4-6 digits, 7-9 digits, ...) and multiply by how many commas each number in that group has.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def countCommas(self, n: int) -> int:
>         ans = 0
>         i = 0
>         prev = 0
>         while prev < n:
>             i += 1
>             curr = min(n, 10 ** (3 * i) - 1)
>             ans += (curr - prev) * (i - 1)
>             prev = curr
>         return ans
> ```

> [!success]- Reasoning
> 1. Partition numbers by digit count: 1–3 digits (no commas), 4–6 digits (1 comma each), 7–9 digits (2 commas each), etc.
> 2. For each group, calculate the range of numbers [prev, curr] and count how many commas each contributes based on digit group.
> 3. Iterate through digit groups, updating the cumulative total; stop when the current group includes n.
> 4. Return total comma count across all processed numbers from 1 to n.
>
> **Key insight:** Group numbers by comma count, not individual iteration; math replaces brute force.
