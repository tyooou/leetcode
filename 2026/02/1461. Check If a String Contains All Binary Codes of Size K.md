### Problem Statement:

Given a binary string `s` and an integer `k`, return `true` _if every binary code of length_ `k` _is a substring of_ `s`. Otherwise, return `false`.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "00110110", k = 2
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The binary codes of length 2 are "00", "01", "10" and "11". They can be all found as substrings at indices 0, 1, 3 and 2 respectively.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "0110", k = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The binary codes of length 1 are "0" and "1", it is clear that both exist as a substring.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "0110", k = 2
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The binary code "00" is of length 2 and does not exist in the array.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 5 * 10^5`
>
> 	- `s[i]` is either `'0'` or `'1'`.
>
> 	- `1 <= k <= 20`

---

### Hints:

> [!success]- Hint 1
> We need only to check all sub-strings of length k.

> [!success]- Hint 2
> The number of distinct sub-strings should be exactly 2^k.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `346 ms` | `44.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def hasAllCodes(self, s: str, k: int) -> bool:
>         sLen = len(s)
>         bSubStrs = set()
>
>         for i in range(0, sLen - (k - 1)):
>             bStr = s[i:(i + k)]
>             bSubStrs.add(int(bStr, 2))
>
>         print(bSubStrs)
>
>         return pow(2, k) == len(bSubStrs)
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
