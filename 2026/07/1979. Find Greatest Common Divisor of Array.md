### Problem Statement:

Given an integer array `nums`, return** **_the **greatest common divisor** of the smallest number and largest number in _`nums`.

The **greatest common divisor** of two numbers is the largest positive integer that evenly divides both numbers.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [2,5,6,9,10]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The smallest number in nums is 2.
> The largest number in nums is 10.
> The greatest common divisor of 2 and 10 is 2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [7,5,6,8,3]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The smallest number in nums is 3.
> The largest number in nums is 8.
> The greatest common divisor of 3 and 8 is 1.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [3,3]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The smallest number in nums is 3.
> The largest number in nums is 3.
> The greatest common divisor of 3 and 3 is 3.
> ```

> [!warning]- Constraints
> - `2 <= nums.length <= 1000`
>
> - `1 <= nums[i] <= 1000`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def findGCD(self, nums: List[int]) -> int:
>         return math.gcd(max(nums), min(nums))
> ```

> [!success]- Reasoning
> 1. Find `min(nums)` and `max(nums)` directly.
> 2. Return `math.gcd(max, min)` using the built-in.
>
> **Key insight:** the GCD of the array's extremes only depends on those two values — nothing in between matters.
