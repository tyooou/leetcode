### Problem Statement:

You are given a **0-indexed** array of integers `nums`.

A prefix `nums[0..i]` is **sequential** if, for all `1 <= j <= i`, `nums[j] = nums[j - 1] + 1`. In particular, the prefix consisting only of `nums[0]` is **sequential**.

Return _the **smallest** integer_ `x` _missing from_ `nums` _such that_ `x` _is greater than or equal to the sum of the **longest** sequential prefix._

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,2,5]
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The longest sequential prefix of nums is [1,2,3] with a sum of 6. 6 is not in the array, therefore 6 is the smallest missing integer greater than or equal to the sum of the longest sequential prefix.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [3,4,5,1,12,14,13]
> ```
>
> **Output:**
>
> ```python
> 15
> ```
>
> **Explanation:**
>
> ```python
> The longest sequential prefix of nums is [3,4,5] with a sum of 12. 12, 13, and 14 belong to the array while 15 does not. Therefore 15 is the smallest missing integer greater than or equal to the sum of the longest sequential prefix.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 50`
>
> 	- `1 <= nums[i] <= 50`

---

### Hints:

> [!success]- Hint 1
> To find the longest sequential prefix, iterate from left to right. For a fixed `i`, if `nums[i] != nums[i - 1] + 1` then the longest sequential prefix ends at `i - 1`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.2 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def missingInteger(self, nums: List[int]) -> int:
>         total = nums[0]
>
>         for a, b in pairwise(nums):
>             if b == a + 1:
>                 total += b
>             else:
>                 break
>
>         num_set = set(nums)
>
>         while total in num_set:
>             total += 1
>
>         return total
>
>
>
> ```

> [!success]- Reasoning
> 1. Iterate through consecutive pairs using `pairwise()` to find the longest sequential prefix.
> 2. Accumulate the sum while each element equals the previous plus one; break on the first gap.
> 3. Convert the array to a set for O(1) membership lookups.
> 4. Starting from the prefix sum, increment until we find a number not in the set.
>
> **Key insight:** find the prefix sum, then step through consecutive integers until hitting a missing one.
