### Problem Statement:

You are given a **0-indexed** array of **distinct** integers `nums`.

There is an element in `nums` that has the **lowest** value and an element that has the **highest** value. We call them the **minimum** and **maximum** respectively. Your goal is to remove **both** these elements from the array.

A **deletion** is defined as either removing an element from the **front** of the array or removing an element from the **back** of the array.

Return _the **minimum** number of deletions it would take to remove **both** the minimum and maximum element from the array._

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [2,**10**,7,5,4,**1**,8,6]
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> The minimum element in the array is nums[5], which is 1.
> The maximum element in the array is nums[1], which is 10.
> We can remove both the minimum and maximum by removing 2 elements from the front and 3 elements from the back.
> This results in 2 + 3 = 5 deletions, which is the minimum number possible.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [0,**-4**,**19**,1,8,-2,-3,5]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The minimum element in the array is nums[1], which is -4.
> The maximum element in the array is nums[2], which is 19.
> We can remove both the minimum and maximum by removing 3 elements from the front.
> This results in only 3 deletions, which is the minimum number possible.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [**101**]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> There is only one element in the array, which makes it both the minimum and maximum element.
> We can remove it with 1 deletion.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `-10^5 <= nums[i] <= 10^5`
>
> 	- The integers in `nums` are **distinct**.

### Hints:

> [!success]- Hint 1
> There can only be three scenarios for deletions such that both minimum and maximum elements are removed:

> [!success]- Hint 2
> Scenario 1: Both elements are removed by only deleting from the front.

> [!success]- Hint 3
> Scenario 2: Both elements are removed by only deleting from the back.

> [!success]- Hint 4
> Scenario 3: Delete from the front to remove one of the elements, and delete from the back to remove the other element.

> [!success]- Hint 5
> Compare which of the three scenarios results in the minimum number of moves.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `16 ms` | `33.6 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def minimumDeletions(self, nums: List[int]) -> int:
>         n, x, y = len(nums), nums.index(max(nums)), nums.index(min(nums))
>         print(x, y)
>         if x < y: y, x = x, y
>         return min(x + 1, n - y, n - x + y + 1)
> ```

> [!success]- Reasoning
> 1. Find the indices of the maximum and minimum elements in a single pass.
> 2. Reorder indices so the larger index is always `x`, ensuring we evaluate all deletion strategies correctly.
> 3. Compare three strategies: remove both from front (`x+1`), remove both from back (`n-y`), or remove one from each end (`n-x+y+1`).
> 4. Return the minimum deletions across the three scenarios.
>
> **Key insight:** greedy choice between three strategies (front-only, back-only, split from both ends) gives the minimum deletions.
