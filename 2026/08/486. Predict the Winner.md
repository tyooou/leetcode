### Problem Statement:

You are given an integer array `nums`. Two players are playing a game with this array: player 1 and player 2.

Player 1 and player 2 take turns, with player 1 starting first. Both players start the game with a score of `0`. At each turn, the player takes one of the numbers from either end of the array (i.e., `nums[0]` or `nums[nums.length - 1]`) which reduces the size of the array by `1`. The player adds the chosen number to their score. The game ends when there are no more elements in the array.

Return `true` if Player 1 can win the game. If the scores of both players are equal, then player 1 is still the winner, and you should also return `true`. You may assume that both players are playing optimally.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,5,2]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> Initially, player 1 can choose between 1 and 2.
> If he chooses 2 (or 1), then player 2 can choose from 1 (or 2) and 5. If player 2 chooses 5, then player 1 will be left with 1 (or 2).
> So, final score of player 1 is 1 + 2 = 3, and player 2 is 5.
> Hence, player 1 will never be the winner and you need to return false.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,5,233,7]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> Player 1 first chooses 1. Then player 2 has to choose between 5 and 7. No matter which number player 2 choose, player 1 can choose 233.
> Finally, player 1 has more score (234) than player 2 (12), so you need to return True representing player1 can win.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 20`
>
> - `0 <= nums[i] <= 10^7`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n^2)` | `O(n)` |
>
> ```python
> class Solution:
>     def predictTheWinner(self, nums: List[int]) -> bool:
>         n = len(nums)
>
>         dp = list(nums)
>         for i in range(n - 2, -1, -1):
>             for j in range(i + 1, n):
>                 dp[j] = max(nums[i] - dp[j], nums[j] - dp[j - 1])
>
>         return dp[-1] >= 0
> ```

> [!success]- Reasoning
> 1. Track score *difference* (current player's score minus opponent's) for each subarray instead of tracking both players' absolute scores.
> 2. Compress the classic O(n^2) 2D interval DP into a 1D array `dp`, reused across increasing interval lengths by iterating `i` backwards.
> 3. For interval `[i, j]`, the best difference is `max(nums[i] - dp[j], nums[j] - dp[j-1])` — taking the left or right end and subtracting the opponent's best response on the remaining interval.
> 4. Player 1 wins or ties iff the final difference `dp[-1] >= 0`.
>
> **Key insight:** tracking the score *difference* instead of both scores collapses the two-player game into a single 1D DP.
