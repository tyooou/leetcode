### Problem Statement:

Alice and Bob continue their games with stones. There is a row of n stones, and each stone has an associated value. You are given an integer array `stones`, where `stones[i]` is the **value** of the `i^th` stone.

Alice and Bob take turns, with **Alice** starting first. On each turn, the player may remove any stone from `stones`. The player who removes a stone **loses** if the **sum** of the values of **all removed stones** is divisible by `3`. Bob will win automatically if there are no remaining stones (even if it is Alice's turn).

Assuming both players play **optimally**, return `true` _if Alice wins and_ `false` _if Bob wins_.

> [!example]- Example 1
> **Input:**
>
> ```python
> stones = [2,1]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The game will be played as follows:
> - Turn 1: Alice can remove either stone.
> - Turn 2: Bob removes the remaining stone.
> The sum of the removed stones is 1 + 2 = 3 and is divisible by 3. Therefore, Bob loses and Alice wins the game.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> stones = [2]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> Alice will remove the only stone, and the sum of the values on the removed stones is 2.
> Since all the stones are removed and the sum of values is not divisible by 3, Bob wins the game.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> stones = [5,1,2,4,3]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> Bob will always win. One possible way for Bob to win is shown below:
> - Turn 1: Alice can remove the second stone with value 1. Sum of removed stones = 1.
> - Turn 2: Bob removes the fifth stone with value 3. Sum of removed stones = 1 + 3 = 4.
> - Turn 3: Alices removes the fourth stone with value 4. Sum of removed stones = 1 + 3 + 4 = 8.
> - Turn 4: Bob removes the third stone with value 2. Sum of removed stones = 1 + 3 + 4 + 2 = 10.
> - Turn 5: Alice removes the first stone with value 5. Sum of removed stones = 1 + 3 + 4 + 2 + 5 = 15.
> Alice loses the game because the sum of the removed stones (15) is divisible by 3. Bob wins the game.
> ```

> [!warning]- Constraints
> - `1 <= stones.length <= 10^5`
>
> 	- `1 <= stones[i] <= 10^4`

### Hints:

> [!success]- Hint 1
> There are limited outcomes given the current sum and the stones remaining.

> [!success]- Hint 2
> Can we greedily simulate starting with taking a stone with remainder 1 or 2 divided by 3?

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `55 ms` | `30.7 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def stoneGameIX(self, stones: List[int]) -> bool:
>         a = b = c = 0
>         for val in stones:
>             if (typ := val % 3) == 0:
>                 a += 1
>             elif typ == 1:
>                 b += 1
>             else:
>                 c += 1
>         if a % 2 == 0:
>             return b >= 1 and c >= 1
>         return b - c > 2 or c - b > 2
> ```

> [!success]- Reasoning
> 1. Partition stones by remainder when divided by 3: count `a` (remainder 0), `b` (remainder 1), `c` (remainder 2).
> 2. Observe that winner depends only on these counts and parities, not actual stone values—this follows from Nim-like game analysis.
> 3. If `a` is even, Alice wins iff both `b >= 1` and `c >= 1` (each group provides strategic options).
> 4. If `a` is odd, Alice wins iff `|b - c| > 2` (asymmetry allows her to force a win).
>
> **Key insight:** Modulo-3 arithmetic distills a complex two-player game into a simple parity check.
