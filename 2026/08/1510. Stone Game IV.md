### Problem Statement:

Alice and Bob take turns playing a game, with Alice starting first.

Initially, there are `n` stones in a pile. On each player's turn, that player makes a _move_ consisting of removing **any** non-zero **square number** of stones in the pile.

Also, if a player cannot make a move, he/she loses the game.

Given a positive integer `n`, return `true` if and only if Alice wins the game otherwise return `false`, assuming both players play optimally.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> Alice can remove 1 stone winning the game because Bob doesn't have any moves.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 2
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> Alice can only remove 1 stone, after that Bob removes the last one winning the game (2 -> 1 -> 0).
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 4
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> n is already a perfect square, Alice can win with one move, removing 4 stones (4 -> 0).
> ```

> [!warning]- Constraints
> - `1 <= n <= 10^5`

---

### Hints:

> [!success]- Hint 1
> Use dynamic programming to keep track of winning and losing states. Given some number of stones, Alice can win if she can force Bob onto a losing state.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `600 ms` | `19.8 MB` | `O(n√n)` | `O(n)` |
>
> ```python
> class Solution:
>     def winnerSquareGame(self, n: int) -> bool:
>         dp = [False] * (n + 1)
>
>         for i in range(1, n + 1):
>             k = 1
>             while k * k <= i:
>                 if not dp[i - k * k]:
>                     dp[i] = True
>                     break
>                 k += 1
>
>         return dp[n]
>
> ```

> [!success]- Reasoning
> 1. Define `dp[i]` = true if the current player wins with i stones left.
> 2. For each position i, try all perfect-square moves (1², 2², 3², ...).
> 3. If any move lands on a losing state for the opponent (`not dp[i - k²]`), mark i as winning.
> 4. Base case: dp[0] = false (no moves means current player loses).
>
> **Key insight:** any position where you can force opponent to a losing state is a win—standard game-theory DP.
