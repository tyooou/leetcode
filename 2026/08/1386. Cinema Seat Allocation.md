### Problem Statement:

A cinema has `n` rows of seats, numbered from 1 to `n`. Each row has 10 seats, numbered from 1 to 10.

You are given a 2D integer array reservedSeats, where reservedSeats[i] = [row_i, seat_i] means that seat seat_i in row row_i is already reserved.

A four-person group must be assigned to four seats in the **same** row. The group can be seated in one of the following seat blocks:

	- seats 2, 3, 4, 5

	- seats 4, 5, 6, 7

	- seats 6, 7, 8, 9

A block can be used only if **none** of its seats are reserved. Each seat can be assigned to **at most **one group.

Return an integer denoting the **maximum** number of four-person groups that can be assigned.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 3, reservedSeats = [[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]]
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> The figure above shows an optimal allocation of four groups. Seats marked in blue are already reserved, and each set of four contiguous seats marked in orange is assigned to one group.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 2, reservedSeats = [[2,1],[1,8],[2,6]]
> ```
>
> **Output:**
>
> ```python
> 2
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 4, reservedSeats = [[4,3],[1,4],[4,6],[1,7]]
> ```
>
> **Output:**
>
> ```python
> 4
> ```

> [!warning]- Constraints
> - `1 <= n <= 10^9`
>
> 	- `1 <= reservedSeats.length <= min(10 * n, 10^4)`
>
> 	- `reservedSeats[i] == [row_i, seat_i]`
>
> 	- `1 <= row_i <= n`
>
> 	- `1 <= seat_i <= 10`
>
> 	- All `reservedSeats[i]` are distinct.
