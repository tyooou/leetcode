### Problem Statement:

Alice and Bob continue their games with piles of stones. There are a number of piles **arranged in a row**, and each pile has a positive integer number of stones `piles[i]`. The objective of the game is to end with the most stones.

Alice and Bob take turns, with Alice starting first.

On each player's turn, that player can take **all the stones** in the **first** `X` remaining piles, where `1 <= X <= 2M`. Then, we set `M = max(M, X)`. Initially, M = 1.

The game continues until all the stones have been taken.

Assuming Alice and Bob play optimally, return the maximum number of stones Alice can get.

> [!example]- Example 1
> **Input:** piles = [2,7,9,4,4]
>
> **Output:** 10
>
> **Explanation:**
>
> 	- If Alice takes one pile at the beginning, Bob takes two piles, then Alice takes 2 piles again. Alice can get `2 + 4 + 4 = 10` stones in total.
>
> 	- If Alice takes two piles at the beginning, then Bob can take all three piles left. In this case, Alice get `2 + 7 = 9` stones in total.
>
> So we return 10 since it's larger.

> [!example]- Example 2
> **Input:** piles = [1,2,3,4,5,100]
>
> **Output:** 104

> [!warning]- Constraints
> - `1 <= piles.length <= 100`
>
> 	- `1 <= piles[i] <= 10^4`

### Hints:

> [!success]- Hint 1
> Use dynamic programming: the states are (i, m) for the answer of piles[i:] and that given m.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `779 ms` | `19.7 MB` | `O(n^3)` | `O(n^2)` |
>
> ```python
> class Solution:
>     def stoneGameII(self, piles: List[int]) -> int:
>         p = len(piles)
>         dp = [[0 for _ in range(p + 1)] for _ in range(p + 1)]
>         sfx = [0 for _ in range(p + 1)]
>
>         for i in range(p - 1, -1, -1):
>             sfx[i] = sfx[i + 1] + piles[i]
>
>         for i in range(p + 1):
>             dp[i][p] = sfx[i]
>
>         for i in range(p - 1, -1, -1):
>             for mx in range(p - 1, 0, -1):
>                 for j in range(1, min(2 * mx, p - i) + 1):
>                     dp[i][mx] = max(dp[i][mx], sfx[i] - dp[i + j][max(mx, j)])
>
>         return dp[0][1]
> ```

> [!success]- Reasoning
> 1. Build a suffix sum array to get the total stones from any index to the end.
> 2. Use DP where `dp[i][mx]` = max stones Alice can take from piles[i:] with current M = mx.
> 3. For each state, try all moves (1 to 2*mx piles), compute opponent's best response, and take max difference.
> 4. The opponent's M updates to max(M, move_count), tracking the expanding take limit.
>
> **Key insight:** each state's result is the remaining sum minus opponent's optimal play—a classic minimax with M-bounded moves.
