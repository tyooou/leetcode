### Problem Statement:

You are given an integer array `nums` and an integer `k`.

The **frequency** of an element `x` is the number of times it occurs in an array.

An array is called **good** if the frequency of each element in this array is **less than or equal** to `k`.

Return _the length of the **longest** **good** subarray of_ `nums`_._

A **subarray** is a contiguous non-empty sequence of elements within an array.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,1,2,3,1,2], k = 2
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The longest possible good subarray is [1,2,3,1,2,3] since the values 1, 2, and 3 occur at most twice in this subarray. Note that the subarrays [2,3,1,2,3,1] and [3,1,2,3,1,2] are also good.
> It can be shown that there are no good subarrays with length more than 6.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,2,1,2,1,2,1,2], k = 1
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The longest possible good subarray is [1,2] since the values 1 and 2 occur at most once in this subarray. Note that the subarray [2,1] is also good.
> It can be shown that there are no good subarrays with length more than 2.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [5,5,5,5,5,5,5], k = 4
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> The longest possible good subarray is [5,5,5,5] since the value 5 occurs 4 times in this subarray.
> It can be shown that there are no good subarrays with length more than 4.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `1 <= nums[i] <= 10^9`
>
> 	- `1 <= k <= nums.length`

### Hints:

> [!success]- Hint 1
> For each index `i`, find the rightmost index `j >= i` such that the frequency of each element in the subarray `[i, j]` is at most `k`.

> [!success]- Hint 2
> We can use 2 pointers / sliding window to achieve it.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `228 ms` | `35.1 MB` | `O(n)` | `O(min(n, distinct values))` |
>
> ```python
> class Solution:
>     def maxSubarrayLength(self, nums: List[int], k: int) -> int:
>         n = len(nums)
>         l = 0
>         ans = 1
>
>         curr_dict = defaultdict(int)
>
>         for r, x in enumerate(nums):
>             curr_dict[x] += 1
>             if curr_dict[x] > k:
>                 while nums[l] != x:
>                     curr_dict[nums[l]] -= 1
>                     l += 1
>                 curr_dict[nums[l]] -= 1
>                 l += 1
>             ans = max(r - l + 1, ans)
>         return ans
>
>
> ```

> [!success]- Reasoning
> 1. Use a sliding window with left and right pointers to maintain a valid subarray where all elements appear ≤ k times.
> 2. Expand the window by incrementing the right pointer and tracking frequencies in a hash map.
> 3. When an element's frequency exceeds k, shrink from the left until the frequency condition is restored.
> 4. Track the maximum window size throughout all valid states.
>
> **Key insight:** two-pointer sliding window ensures each element is visited at most twice, yielding linear time complexity.
