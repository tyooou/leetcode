### Problem Statement:

You are given a **0-indexed** string `s`. You are also given a **0-indexed** string `queryCharacters` of length `k` and a **0-indexed** array of integer **indices** `queryIndices` of length `k`, both of which are used to describe `k` queries.

The `i^th` query updates the character in `s` at index `queryIndices[i]` to the character `queryCharacters[i]`.

Return _an array_ `lengths` _of length _`k`_ where_ `lengths[i]` _is the **length** of the **longest substring** of _`s`_ consisting of **only one repeating** character **after** the_ `i^th` _query\_\_ is performed._

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "babacc", queryCharacters = "bcb", queryIndices = [1,3,3]
> ```
>
> **Output:**
>
> ```python
> [3,3,4]
> ```
>
> **Explanation:**
>
> ```python
> - 1^st query updates s = "b**b**bacc". The longest substring consisting of one repeating character is "bbb" with length 3.
> - 2^nd query updates s = "bbb**c**cc".
>   The longest substring consisting of one repeating character can be "bbb" or "ccc" with length 3.
> - 3^rd query updates s = "bbb**b**cc". The longest substring consisting of one repeating character is "bbbb" with length 4.
> Thus, we return [3,3,4].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "abyzz", queryCharacters = "aa", queryIndices = [2,1]
> ```
>
> **Output:**
>
> ```python
> [2,3]
> ```
>
> **Explanation:**
>
> ```python
> - 1^st query updates s = "ab**a**zz". The longest substring consisting of one repeating character is "zz" with length 2.
> - 2^nd query updates s = "a**a**azz". The longest substring consisting of one repeating character is "aaa" with length 3.
> Thus, we return [2,3].
> ```

> [!warning]- Constraints
>
> - `1 <= s.length <= 10^5`
>   - `s` consists of lowercase English letters.
>   - `k == queryCharacters.length == queryIndices.length`
>   - `1 <= k <= 10^5`
>   - `queryCharacters` consists of lowercase English letters.
>   - `0 <= queryIndices[i] < s.length`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `1995 ms` | `41.4 MB` | `O(q log q)` | `O(n + q)` |
>
> ```python
> class Solution:
>     def longestRepeating(self, s: str, queryCharacters: str, queryIndices: List[int]) -> List[int]:
>         chars = list(s)
>         n = len(chars)
>         groups = defaultdict(SortedList)
>         length_count = Counter()
>         distinct_lengths = SortedList()
>
>         def add_len(x):
>             if length_count[x] == 0:
>                 distinct_lengths.add(x)
>             length_count[x] += 1
>
>         def remove_len(x):
>             length_count[x] -= 1
>             if length_count[x] == 0:
>                 distinct_lengths.remove(x)
>
>         def add_char(c, i):
>             group = groups[c]
>             idx = group.bisect_left((i,))
>             l, r = i, i
>             if idx > 0 and group[idx - 1][1] >= i - 1:
>                 idx -= 1
>                 pl, pr = group[idx]
>                 remove_len(pr - pl + 1)
>                 l = pl
>                 del group[idx]
>             if idx < len(group) and group[idx][0] <= i + 1:
>                 pl, pr = group[idx]
>                 remove_len(pr - pl + 1)
>                 r = pr
>                 del group[idx]
>             add_len(r - l + 1)
>             group.add((l, r))
>
>         def delete_char(c, i):
>             group = groups[c]
>             idx = group.bisect_left((i,))
>             if idx > 0 and group[idx - 1][1] >= i:
>                 idx -= 1
>             l, r = group[idx]
>             remove_len(r - l + 1)
>             del group[idx]
>             if l < i:
>                 group.add((l, i - 1))
>                 add_len(i - l)
>             if r > i:
>                 group.add((i + 1, r))
>                 add_len(r - i)
>
>         curr_c, l = chars[0], 0
>         for i in range(1, n + 1):
>             if i == n or chars[i] != curr_c:
>                 groups[curr_c].add((l, i - 1))
>                 add_len(i - l)
>                 if i < n:
>                     curr_c, l = chars[i], i
>
>         ans = []
>         for new_c, i in zip(queryCharacters, queryIndices):
>             old_c = chars[i]
>             if old_c != new_c:
>                 delete_char(old_c, i)
>                 chars[i] = new_c
>                 add_char(new_c, i)
>             ans.append(distinct_lengths[-1])
>
>         return ans
> ```

> [!success]- Reasoning
> 1. Preprocess the original string into groups of consecutive same characters, storing each group as an interval `(left, right)`.
> 2. For each query, delete the old character at the index and add the new character, merging adjacent groups if they now match.
> 3. Maintain a sorted list of all current lengths to quickly track the maximum.
> 4. Use efficient interval merging with binary search to handle adjacent-group lookups in logarithmic time.
>
> **Key insight:** store character groups as mergeable intervals instead of a raw string, allowing O(log q) updates via binary search and merge detection.
