### Problem Statement:

Given a string containing just the characters `'('` and `')'`, return _the length of the longest valid (well-formed) parentheses __substring_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "(()"
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The longest valid parentheses substring is "()".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = ")()())"
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> The longest valid parentheses substring is "()()".
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = ""
> ```
>
> **Output:**
>
> ```python
> 0
> ```

> [!warning]- Constraints
> - `0 <= s.length <= 3 * 10^4`
>
> 	- `s[i]` is `'('`, or `')'`.

>
> ```python
> class Solution:
>     def longestValidParentheses(self, s: str) -> int:
>         res, stack = 0, [-1]
>
>         for i, c in enumerate(s):
>             if c == '(':
>                 stack.append(i)
>             else:
>                 stack.pop()
>                 if not stack:
>                     stack.append(i)
>                 else:
>                     res = max(res, i - stack[-1])
>         return res
> ```
