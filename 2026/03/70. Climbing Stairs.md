### Problem Statement:

You are climbing a staircase. It takes `n` steps to reach the top.

Each time you can either climb `1` or `2` steps. In how many distinct ways can you climb to the top?

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 2
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> There are two ways to climb to the top.
> 1. 1 step + 1 step
> 2. 2 steps
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 3
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> There are three ways to climb to the top.
> 1. 1 step + 1 step + 1 step
> 2. 1 step + 2 steps
> 3. 2 steps + 1 step
> ```

> [!warning]- Constraints
> - `1 <= n <= 45`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.1 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def climbStairs(self, n: int) -> int:
>         res = [0] * (n + 1)
>         res[0], res[1] = 1, 1
>
>         for i in range(2, n + 1):
>             res[i] += res[i - 1]
>             res[i] += res[i - 2]
>
>         return res[-1]
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
