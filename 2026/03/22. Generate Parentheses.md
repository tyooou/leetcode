### Problem Statement:

Given `n` pairs of parentheses, write a function to _generate all combinations of well-formed parentheses_.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 3
> ```
>
> **Output:**
>
> ```python
> ["((()))","(()())","(())()","()(())","()()()"]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 1
> ```
>
> **Output:**
>
> ```python
> ["()"]
> ```

> [!warning]- Constraints
> - `1 <= n <= 8`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def generateParenthesis(self, n: int) -> List[str]:
>         def dfs(left, right, s):
>             if len(s) == n * 2:
>                 res.append(s)
>                 return
>
>             if left < n:
>                 dfs(left + 1, right, s + '(')
>
>             if right < left:
>                 dfs(left, right + 1, s + ')')
>
>         res = []
>         dfs(0, 0, '')
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
