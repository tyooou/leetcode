### Problem Statement:

The string `"PAYPALISHIRING"` is written in a zigzag pattern on a given number of rows like this: (you may want to display this pattern in a fixed font for better legibility)

P   A   H   N
A P L S I I G
Y   I   R

And then read line by line: `"PAHNAPLSIIGYIR"`

Write the code that will take a string and make this conversion given a number of rows:

string convert(string s, int numRows);

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "PAYPALISHIRING", numRows = 3
> ```
>
> **Output:**
>
> ```python
> "PAHNAPLSIIGYIR"
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "PAYPALISHIRING", numRows = 4
> ```
>
> **Output:**
>
> ```python
> "PINALSIGYAHRPI"
> ```
>
> **Explanation:**
>
> ```python
> P     I    N
> A   L S  I G
> Y A   H R
> P     I
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "A", numRows = 1
> ```
>
> **Output:**
>
> ```python
> "A"
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 1000`
>
> 	- `s` consists of English letters (lower-case and upper-case), `','` and `'.'`.
>
> 	- `1 <= numRows <= 1000`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |

> | `7 ms` | `19.4 MB` | `*(fill in)*` | `*(fill in)*` |
>
> ```python
> class Solution:
>     def convert(self, s: str, numRows: int) -> str:
>         buckets = (numRows * 2) - 2
>         res = ["" for _ in range(buckets)]
>
>         if numRows == 1:
>             return s
>
>         for i, c in enumerate(s):
>             idx = i % buckets
>             if idx >= numRows:
>                 idx = buckets - idx
>             res[idx] += c
>
>
>         return "".join(res)
>
>
>
>
>
> ```
