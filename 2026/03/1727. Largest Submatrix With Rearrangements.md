### Problem Statement:

You are given a binary matrix `matrix` of size `m x n`, and you are allowed to rearrange the **columns** of the `matrix` in any order.

Return _the area of the largest submatrix within _`matrix`_ where **every** element of the submatrix is _`1`_ after reordering the columns optimally._

> [!example]- Example 1
> **Input:**
>
> ```python
> matrix = [[0,0,1],[1,1,1],[1,0,1]]
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> You can rearrange the columns as shown above.
> The largest submatrix of 1s, in bold, has an area of 4.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> matrix = [[1,0,1,0,1]]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> You can rearrange the columns as shown above.
> The largest submatrix of 1s, in bold, has an area of 3.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> matrix = [[1,1,0],[1,0,1]]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Notice that you must rearrange entire columns, and there is no way to make a submatrix of 1s larger than an area of 2.
> ```

> [!warning]- Constraints
> - `m == matrix.length`
>
> 	- `n == matrix[i].length`
>
> 	- `1 <= m * n <= 10^5`
>
> 	- `matrix[i][j]` is either `0` or `1`.

> class Solution:
>     def largestSubmatrix(self, mat: List[List[int]]) -> int:
>         m, n = len(mat), len(mat[0])
>         res = 0
>
>         for i in range(1, m):
>             for j in range(n):
>                 if mat[i][j] == 1:
>                     mat[i][j] += mat[i - 1][j]
>
>         for i in range(m):
>             mat[i].sort(reverse=True)
>             for j in range(n):
>                 res = max(res, mat[i][j] * (j + 1))
>
>         return res
> ```
