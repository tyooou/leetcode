### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(rowIndex^2)` | `O(rowIndex)` |
>
> ```python
> class Solution:
> 	def getRow(self, rowIndex: int) -> List[int]:
> 		# Initialise empty row.
> 		pRow = [1] * (rowIndex + 1)
>
> 		# Dynamically find out final row.
> 		for i in range(1, rowIndex):
> 			# Work backwards so new values don't effect future results.
> 			for j in range(i, 0, -1):
> 				pRow[j] = pRow[j - 1] + pRow[j]
>
> 		return pRow
> ```

> [!success]- Reasoning
> 1. Initialize a single row of length `rowIndex + 1`, all 1s.
> 2. For each layer from 1 to rowIndex - 1, update the row in place working right to left, so cells aren't overwritten before they're read.
> 3. Reusing one array instead of a full 2D triangle keeps space down to O(rowIndex).
>
> **Key insight:** updating an array right-to-left in place lets each row reuse the previous row's values before they get overwritten.
