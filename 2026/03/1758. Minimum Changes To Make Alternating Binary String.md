### Problem Statement:

You are given a string `s` consisting only of the characters `'0'` and `'1'`. In one operation, you can change any `'0'` to `'1'` or vice versa.

The string is called alternating if no two adjacent characters are equal. For example, the string `"010"` is alternating, while the string `"0100"` is not.

Return _the **minimum** number of operations needed to make_ `s` _alternating_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "0100"
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> If you change the last character to '1', s will be "0101", which is alternating.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "10"
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> s is already alternating.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "1111"
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> You need two operations to reach "0101" or "1010".
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 10^4`
>
> 	- `s[i]` is either `'0'` or `'1'`.

> ```python
> class Solution:
>     def minOperations(self, s: str) -> int:
>         sLen = len(s)
>         zeroStart = sum(s[i] == str(i % 2) for i in range(sLen))
>         onesStart = sum(s[i] != str(i % 2) for i in range(sLen))
>         return min(zeroStart, onesStart)
>
