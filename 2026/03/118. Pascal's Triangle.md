### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n^2)` | `O(n^2)` |
>
> ```python
> class Solution:
> 	def generate(self, numRows: int) -> List[List[int]]:
>
> 		# Generate empty triangle. Default value to 1.
> 		pTriangle = [[1] * i for i in range(1, numRows + 1)]
>
> 		# pLayer is the row index of the triangle layer. Start at index 2.
> 		for pLayer in range(2, numRows):
> 			# rIdx is the element index of the row.
> 			# Stop before last element as we need the next element.
> 			for rIdx in range(0, pLayer - 1):
> 				# The resulting value at index X is the the previous layer's
> 				# values at index X - 1 and index X summed.
> 				pTriangle[pLayer][rIdx + 1] = \
> 					pTriangle[pLayer - 1][rIdx] + \
> 					pTriangle[pLayer - 1][rIdx + 1]
>
> 		return pTriangle
> ```

> [!success]- Reasoning
> 1. Initialize the triangle with every row prefilled as all 1s, which handles the first/last element of each row for free.
> 2. For each row from index 2 onward, compute only the interior values as the sum of two adjacent values in the previous row.
> 3. Loop bounds intentionally skip the first and last positions since they're already 1.
>
> **Key insight:** edges of every row are always 1, so only interior cells need the `pTriangle[i][j] = prev[j-1] + prev[j]` recurrence.
