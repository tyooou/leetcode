### Problem Statement:

The **complement** of an integer is the integer you get when you flip all the `0`'s to `1`'s and all the `1`'s to `0`'s in its binary representation.

	- For example, The integer `5` is `"101"` in binary and its **complement** is `"010"` which is the integer `2`.

Given an integer `n`, return _its complement_.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 5
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> 5 is "101" in binary, with complement "010" in binary, which is 2 in base-10.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 7
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> 7 is "111" in binary, with complement "000" in binary, which is 0 in base-10.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 10
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> 10 is "1010" in binary, with complement "0101" in binary, which is 5 in base-10.
> ```

> [!warning]- Constraints
> - `0 <= n < 10^9`
>
>
>
> **Note:** This question is the same as 476: https://leetcode.com/problems/number-complement/

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.1 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def bitwiseComplement(self, n: int) -> int:
>         bitLen = n.bit_length() if n != 0 else 1
>         return n ^ (1 << bitLen) - 1
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
