### Problem Statement:

Given the `head` of a linked list, remove the `n^th` node from the end of the list and return its head.

> [!example]- Example 1
> **Input:**
>
> ```python
> head = [1,2,3,4,5], n = 2
> ```
>
> **Output:**
>
> ```python
> [1,2,3,5]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> head = [1], n = 1
> ```
>
> **Output:**
>
> ```python
> []
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> head = [1,2], n = 1
> ```
>
> **Output:**
>
> ```python
> [1]
> ```

> [!warning]- Constraints
> - The number of nodes in the list is `sz`.
>
> 	- `1 <= sz <= 30`
>
> 	- `0 <= Node.val <= 100`
>
> 	- `1 <= n <= sz`
>
>
>
> **Follow up:** Could you do this in one pass?
