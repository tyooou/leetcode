### Problem Statement:

You are given a **0-indexed** `m x n` integer matrix `grid`. The width of a column is the maximum **length **of its integers.

	- For example, if `grid = [[-10], [3], [12]]`, the width of the only column is `3` since `-10` is of length `3`.

Return _an integer array_ `ans` _of size_ `n` _where_ `ans[i]` _is the width of the_ `i^th` _column_.

The **length** of an integer `x` with `len` digits is equal to `len` if `x` is non-negative, and `len + 1` otherwise.

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [[1],[22],[333]]
> ```
>
> **Output:**
>
> ```python
> [3]
> ```
>
> **Explanation:**
>
> ```python
> In the 0^th column, 333 is of length 3.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[-15,1,3],[15,7,12],[5,6,-2]]
> ```
>
> **Output:**
>
> ```python
> [3,1,2]
> ```
>
> **Explanation:**
>
> ```python
> In the 0^th column, only -15 is of length 3.
> In the 1^st column, all integers are of length 1.
> In the 2^nd column, both 12 and -2 are of length 2.
> ```

> [!warning]- Constraints
> - `m == grid.length`
>
> 	- `n == grid[i].length`
>
> 	- `1 <= m, n <= 100 `
>
> 	- `-10^9 <= grid[r][c] <= 10^9`

> class Solution:
>     def findColumnWidth(self, grid: List[List[int]]) -> List[int]:
>         def getWidth(a: int) -> int:
>             return len(str(a))
>
>         m, n = len(grid), len(grid[0])
>         res = [0] * n
>
>         for i in range(n):
>             for j in range(m):
>                 w = getWidth(grid[j][i])
>                 res[i] = max(res[i], w)
>         return res
>
>
> ```
