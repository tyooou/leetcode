### Problem Statement:

You are given two strings `s1` and `s2`, both of length `n`, consisting of **lowercase** English letters.

You can apply the following operation on **any** of the two strings **any** number of times:

	- Choose any two indices `i` and `j` such that `i < j` and the difference `j - i` is **even**, then **swap** the two characters at those indices in the string.

Return `true`_ if you can make the strings _`s1`_ and _`s2`_ equal, and _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s1 = "abcdba", s2 = "cabdab"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> We can apply the following operations on s1:
> - Choose the indices i = 0, j = 2. The resulting string is s1 = "cbadba".
> - Choose the indices i = 2, j = 4. The resulting string is s1 = "cbbdaa".
> - Choose the indices i = 1, j = 5. The resulting string is s1 = "cabdab" = s2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s1 = "abe", s2 = "bea"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> It is not possible to make the two strings equal.
> ```

> [!warning]- Constraints
> - `n == s1.length == s2.length`
>
> 	- `1 <= n <= 10^5`
>
> 	- `s1` and `s2` consist only of lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Characters in two positions can be swapped if and only if the two positions have the same parity.

> [!success]- Hint 2
> To be able to make the two strings equal, the characters at even and odd positions in the strings should be the same.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `191 ms` | `21.2 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def checkStrings(self, s1: str, s2: str) -> bool:
>         n = len(s1)
>
>         a = b = c = d = ""
>
>         for i in range(n):
>             if i % 2:
>                 a += s1[i]
>                 b += s2[i]
>             else:
>                 c += s1[i]
>                 d += s2[i]
>
>         return sorted(a) == sorted(b) and sorted(c) == sorted(d)
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
