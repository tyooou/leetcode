### Problem Statement:

You are given an `m x n` matrix `grid` of positive integers. Your task is to determine if it is possible to make **either one horizontal or one vertical cut** on the grid such that:

	- Each of the two resulting sections formed by the cut is **non-empty**.

	- The sum of the elements in both sections is **equal**.

Return `true` if such a partition exists; otherwise return `false`.

> [!example]- Example 1
> **Input:** grid = [[1,4],[2,3]]
>
> **Output:** true
>
> **Explanation:**
>
> A horizontal cut between row 0 and row 1 results in two non-empty sections, each with a sum of 5. Thus, the answer is `true`.

> [!example]- Example 2
> **Input:** grid = [[1,3],[2,4]]
>
> **Output:** false
>
> **Explanation:**
>
> No horizontal or vertical cut results in two non-empty sections with equal sums. Thus, the answer is `false`.

> [!warning]- Constraints
> - `1 <= m == grid.length <= 10^5`
>
> 	- `1 <= n == grid[i].length <= 10^5`
>
> 	- `2 <= m * n <= 10^5`
>
> 	- `1 <= grid[i][j] <= 10^5`

---

### Hints:

> [!success]- Hint 1
> There are two types of cuts: a `horizontal` cut or a `vertical` cut.

> [!success]- Hint 2
> For a `horizontal` cut at row `r` (0 <= r <m - 1), split `grid` into rows 0...r vs. r+1...m-1 and compare their sums.

> [!success]- Hint 3
> For a `vertical` cut at column `c` (0 <= c < n - 1), split `grid` into columns 0...c vs. c+1...n-1 and compare their sums.

> [!success]- Hint 4
> Brute‑force all possible `r` and `c` cuts; if any yields equal section sums, return `true`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `80 ms` | `41.4 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def canPartitionGrid(self, grid: List[List[int]]) -> bool:
>         m, n = len(grid), len(grid[0])
>         total = sum(sum(row) for row in grid)
>
>         if total % 2:
>             return False
>
>         target = total // 2
>         s = 0
>
>         for i in range(m - 1):
>             s += sum(grid[i])
>             if s == target:
>                 return True
>
>         s = 0
>
>         for j in range(n - 1):
>             for i in range(m):
>                 s += grid[i][j]
>             if s == target:
>                 return True
>
>         return False
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
