### Problem Statement:

Given an unsorted array of integers `nums`, return _the length of the longest **continuous increasing subsequence** (i.e. subarray)_. The subsequence must be **strictly** increasing.

A **continuous increasing subsequence** is defined by two indices `l` and `r` (`l < r`) such that it is `[nums[l], nums[l + 1], ..., nums[r - 1], nums[r]]` and for each `l <= i < r`, `nums[i] < nums[i + 1]`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,3,5,4,7]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The longest continuous increasing subsequence is [1,3,5] with length 3.
> Even though [1,3,5,7] is an increasing subsequence, it is not continuous as elements 5 and 7 are separated by element
> 4.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [2,2,2,2,2]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The longest continuous increasing subsequence is [2] with length 1. Note that it must be strictly
> increasing.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^4`
>
> 	- `-10^9 <= nums[i] <= 10^9`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `20.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def findLengthOfLCIS(self, nums: List[int]) -> int:
>         n = len(nums)
>
>         if not nums:
>             return 0
>
>         mCount, count = 0, 1
>         for i in range(n - 1):
>             if nums[i] < nums[i + 1]:
>                 count += 1
>             else:
>                 mCount = max(mCount, count)
>                 count = 1
>
>         return max(mCount, count)
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
