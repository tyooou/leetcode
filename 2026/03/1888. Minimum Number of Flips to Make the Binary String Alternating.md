### Problem Statement:

You are given a binary string `s`. You are allowed to perform two types of operations on the string in any sequence:

	- **Type-1: Remove** the character at the start of the string `s` and **append** it to the end of the string.

	- **Type-2: Pick** any character in `s` and **flip** its value, i.e., if its value is `'0'` it becomes `'1'` and vice-versa.

Return _the **minimum** number of **type-2** operations you need to perform_ _such that _`s` _becomes **alternating**._

The string is called **alternating** if no two adjacent characters are equal.

	- For example, the strings `"010"` and `"1010"` are alternating, while the string `"0100"` is not.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "111000"
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> : Use the first operation two times to make s = "100011".
> Then, use the second operation on the third and sixth elements to make s = "101010".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "010"
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> : The string is already alternating.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "1110"
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> : Use the second operation on the second element to make s = "1010".
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 10^5`
>
> 	- `s[i]` is either `'0'` or `'1'`.

> ```python
> class Solution:
>     def minFlips(self, s: str) -> int:
>         sLen, ops = len(s), [0, 0]
>         for i in range(sLen):
>             # s[i] either 0 or 1, last bit differ by 1
>             # same as index parity so we combine
>             ops[(ord(s[i]) ^ i) & 1] += 1
>
>         res = sLen
>
>         for i in range(sLen):
>             c = ord(s[i])
>             ops[(c ^ i) & 1] -= 1
>             ops[(c ^ (sLen + i)) & 1] += 1
>             res = min(res, min(ops))
>
>         return res
>
> ```
