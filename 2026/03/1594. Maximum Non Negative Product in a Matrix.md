### Problem Statement:

You are given a `m x n` matrix `grid`. Initially, you are located at the top-left corner `(0, 0)`, and in each step, you can only **move right or down** in the matrix.

Among all possible paths starting from the top-left corner `(0, 0)` and ending in the bottom-right corner `(m - 1, n - 1)`, find the path with the **maximum non-negative product**. The product of a path is the product of all integers in the grid cells visited along the path.

Return the _maximum non-negative product **modulo** _`10^9 + 7`. _If the maximum product is **negative**, return _`-1`.

Notice that the modulo is performed after getting the maximum product.

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [[-1,-2,-3],[-2,-3,-3],[-3,-3,-2]]
> ```
>
> **Output:**
>
> ```python
> -1
> ```
>
> **Explanation:**
>
> ```python
> It is not possible to get non-negative product in the path from (0, 0) to (2, 2), so return -1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[1,-2,1],[1,-2,1],[3,-4,1]]
> ```
>
> **Output:**
>
> ```python
> 8
> ```
>
> **Explanation:**
>
> ```python
> Maximum non-negative product is shown (1 * 1 * -2 * -4 * 1 = 8).
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> grid = [[1,3],[0,-4]]
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> Maximum non-negative product is shown (1 * 0 * -4 = 0).
> ```

> [!warning]- Constraints
> - `m == grid.length`
>
> 	- `n == grid[i].length`
>
> 	- `1 <= m, n <= 15`
>
> 	- `-4 <= grid[i][j] <= 4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4 ms` | `21.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxProductPath(self, grid: List[List[int]]) -> int:
>         m, n = len(grid), len(grid[0])
>
>         @lru_cache(None)
>         def fn(i, j):
>             """Return maximum & minimum products ending at (i, j)."""
>             if i == 0 and j == 0: return grid[0][0], grid[0][0]
>             if i < 0 or j < 0: return -inf, inf
>             if grid[i][j] == 0: return 0, 0
>             mx1, mn1 = fn(i - 1, j) # from top
>             mx2, mn2 = fn(i, j - 1) # from left
>             mx, mn = max(mx1, mx2) * grid[i][j], min(mn1, mn2) * grid[i][j]
>             return (mx, mn) if grid[i][j] > 0 else (mn, mx)
>
>         mx, _ = fn(m - 1, n - 1)
>         return -1 if mx < 0 else mx % 1_000_000_007
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
