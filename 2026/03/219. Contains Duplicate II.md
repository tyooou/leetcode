### Problem Statement:

Given an integer array `nums` and an integer `k`, return `true` _if there are two **distinct indices** _`i`_ and _`j`_ in the array such that _`nums[i] == nums[j]`_ and _`abs(i - j) <= k`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,1], k = 3
> ```
>
> **Output:**
>
> ```python
> true
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,0,1,1], k = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [1,2,3,1,2,3], k = 2
> ```
>
> **Output:**
>
> ```python
> false
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `-10^9 <= nums[i] <= 10^9`
>
> 	- `0 <= k <= 10^5`

> class Solution:
>     def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
>         n, k = len(nums), k + 1
>         c = Counter(nums[:k])
>
>         for val in c.values():
>             if (val >= 2):
>                 return True
>
>         for i in range(0, n - k):
>             c[nums[i]] -= 1
>             if c[nums[i + k]] == 1:
>                 return True
>             else:
>                 c[nums[i + k]] += 1
>
>         return False
>

> ```
