### Problem Statement:

Given an integer array `nums` where the elements are sorted in **ascending order**, convert _it to a _**_height-balanced_** _binary search tree_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [-10,-3,0,5,9]
> ```
>
> **Output:**
>
> ```python
> [0,-3,9,-10,null,5]
> ```
>
> **Explanation:**
>
> ```python
> [0,-10,5,null,-3,null,9] is also accepted:
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,3]
> ```
>
> **Output:**
>
> ```python
> [3,1]
> ```
>
> **Explanation:**
>
> ```python
> [1,null,3] and [3,1] are both height-balanced BSTs.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^4`
>
> 	- `-10^4 <= nums[i] <= 10^4`
>
> 	- `nums` is sorted in a **strictly increasing** order.

> class Solution:
>     def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
>
>         def split(l, r) -> Optional(TreeNode):
>             if l > r:
>                 return None
>
>             m = (l + r) // 2
>             node = TreeNode(nums[m])
>
>             node.left = split(l, m - 1)
>             node.right = split(m + 1, r)
>             return node
>
>         return split(0, len(nums) - 1)
>
> ```
