### Problem Statement:

Given an `m x n` `matrix`, return _`true` if the matrix is Toeplitz. Otherwise, return `false`._

A matrix is **Toeplitz** if every diagonal from top-left to bottom-right has the same elements.

> [!example]- Example 1
> **Input:**
>
> ```python
> matrix = [[1,2,3,4],[5,1,2,3],[9,5,1,2]]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> In the above grid, the diagonals are:
> "[9]", "[5, 5]", "[1, 1, 1]", "[2, 2, 2]", "[3, 3]", "[4]".
> In each diagonal all elements are the same, so the answer is True.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> matrix = [[1,2],[2,2]]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The diagonal "[1, 2]" has different elements.
> ```

> [!warning]- Constraints
> - `m == matrix.length`
>
> 	- `n == matrix[i].length`
>
> 	- `1 <= m, n <= 20`
>
> 	- `0 <= matrix[i][j] <= 99`

> [!info]- Follow up
> - What if the `matrix` is stored on disk, and the memory is limited such that you can only load at most one row of the matrix into the memory at once?
>
> 	- What if the `matrix` is so large that you can only load up a partial row into the memory at once?

>
> ```python
> class Solution:
>     def isToeplitzMatrix(self, mat: List[List[int]]) -> bool:
>         m, n = len(mat), len(mat[0])
>
>         def checkDiagonal(a: int, b: int) -> bool:
>             i, j = a + 1, b + 1
>             while i < m and j < n:
>                 if mat[i][j] != mat[a][b]:
>                     return False
>                 i, j = i + 1, j + 1
>             return True
>
>         for i in range(m):
>             if not checkDiagonal(i, 0): return False
>
>         for j in range(n):
>             if not checkDiagonal(0, j): return False
>
>         return True
>
>
>
> ```
