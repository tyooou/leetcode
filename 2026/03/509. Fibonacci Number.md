### Problem Statement:

The **Fibonacci numbers**, commonly denoted `F(n)` form a sequence, called the **Fibonacci sequence**, such that each number is the sum of the two preceding ones, starting from `0` and `1`. That is,

F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n > 1.

Given `n`, calculate `F(n)`.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 2
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> F(2) = F(1) + F(0) = 1 + 0 = 1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 3
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> F(3) = F(2) + F(1) = 1 + 1 = 2.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 4
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> F(4) = F(3) + F(2) = 2 + 1 = 3.
> ```

> [!warning]- Constraints
> - `0 <= n <= 30`

>             a = b
>             b = temp
