### Problem Statement:

Given three integers `a`, `b`, and `n`, return _the **maximum value** of_ `(a XOR x) * (b XOR x)` _where_ `0 <= x < 2^n`.

Since the answer may be too large, return it **modulo** `10^9 + 7`.

**Note** that `XOR` is the bitwise XOR operation.

> [!example]- Example 1
> **Input:**
>
> ```python
> a = 12, b = 5, n = 4
> ```
>
> **Output:**
>
> ```python
> 98
> ```
>
> **Explanation:**
>
> ```python
> For x = 2, (a XOR x) = 14 and (b XOR x) = 7. Hence, (a XOR x) * (b XOR x) = 98.
> It can be shown that 98 is the maximum value of (a XOR x) * (b XOR x) for all 0 <= x < 2^n.
> ```

### Hints:

> [!success]- Hint 1
> Iterate over bits from most significant to least significant.

> [!success]- Hint 2
> For the `i^th` bit, if both `a` and `b` have the same value, we can always make `x`’s `i^th` bit different from `a` and `b`, so `a ^ x` and `b ^ x` both have the i^th bit set.

> [!success]- Hint 3
> Otherwise, we can only set the `i^th` bit of one of `a ^ x` or `b ^ x`. Depending on the previous bits of  `a ^ x` or `b ^ x`, we should set the smaller value’s `i^th` bit.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.2 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def maximumXorProduct(self, a: int, b: int, n: int) -> int:
>         for bt in (2**i for i in range(n)):
>             if a * b < (a ^ bt) * (b ^ bt):
>                 a ^= bt
>                 b ^= bt
>         return a * b % (10**9 + 7)
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
