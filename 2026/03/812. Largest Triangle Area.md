### Problem Statement:

Given an array of points on the **X-Y** plane `points` where `points[i] = [x_i, y_i]`, return _the area of the largest triangle that can be formed by any three different points_. Answers within `10^-5` of the actual answer will be accepted.

> [!example]- Example 1
> **Input:**
>
> ```python
> points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
> ```
>
> **Output:**
>
> ```python
> 2.00000
> ```
>
> **Explanation:**
>
> ```python
> The five points are shown in the above figure. The red triangle is the largest.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> points = [[1,0],[0,0],[0,1]]
> ```
>
> **Output:**
>
> ```python
> 0.50000
> ```

> [!warning]- Constraints
> - `3 <= points.length <= 50`
>
> 	- `-50 <= x_i, y_i <= 50`
>
> 	- All the given points are **unique**.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `39 ms` | `19.4 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def largestTriangleArea(self, points: List[List[int]]) -> float:
>         max_area = 0
>         n = len(points)
>
>         for i in range(n):
>             for j in range(i + 1, n):
>                 for k in range(j + 1, n):
>                     x1, y1 = points[i]
>                     x2, y2 = points[j]
>                     x3, y3 = points[k]
>                     current_area = abs(0.5 * (x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2)))
>                     max_area = max(max_area, current_area)
>
>         return max_area
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
