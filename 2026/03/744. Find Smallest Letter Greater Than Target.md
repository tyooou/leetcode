### Problem Statement:

You are given an array of characters `letters` that is sorted in **non-decreasing order**, and a character `target`. There are **at least two different** characters in `letters`.

Return _the smallest character in _`letters`_ that is lexicographically greater than _`target`. If such a character does not exist, return the first character in `letters`.

> [!example]- Example 1
> **Input:**
>
> ```python
> letters = ["c","f","j"], target = "a"
> ```
>
> **Output:**
>
> ```python
> "c"
> ```
>
> **Explanation:**
>
> ```python
> The smallest character that is lexicographically greater than 'a' in letters is 'c'.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> letters = ["c","f","j"], target = "c"
> ```
>
> **Output:**
>
> ```python
> "f"
> ```
>
> **Explanation:**
>
> ```python
> The smallest character that is lexicographically greater than 'c' in letters is 'f'.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> letters = ["x","x","y","y"], target = "z"
> ```
>
> **Output:**
>
> ```python
> "x"
> ```
>
> **Explanation:**
>
> ```python
> There are no characters in letters that is lexicographically greater than 'z' so we return letters[0].
> ```

> [!warning]- Constraints
> - `2 <= letters.length <= 10^4`
>
> 	- `letters[i]` is a lowercase English letter.
>
> 	- `letters` is sorted in **non-decreasing** order.
>
> 	- `letters` contains at least two different characters.
>
> 	- `target` is a lowercase English letter.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `20.8 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def nextGreatestLetter(self, letters: List[str], target: str) -> str:
>         targetO = ord(target)
>
>         if target == "z":
>             return letters[0]
>
>         for e in letters:
>             if ord(e) > targetO:
>                 return e
>
>         return letters[0]
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
