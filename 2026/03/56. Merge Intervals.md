### Problem Statement:

Given an array of `intervals` where `intervals[i] = [start_i, end_i]`, merge all overlapping intervals, and return _an array of the non-overlapping intervals that cover all the intervals in the input_.

> [!example]- Example 1
> **Input:**
>
> ```python
> intervals = [[1,3],[2,6],[8,10],[15,18]]
> ```
>
> **Output:**
>
> ```python
> [[1,6],[8,10],[15,18]]
> ```
>
> **Explanation:**
>
> ```python
> Since intervals [1,3] and [2,6] overlap, merge them into [1,6].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> intervals = [[1,4],[4,5]]
> ```
>
> **Output:**
>
> ```python
> [[1,5]]
> ```
>
> **Explanation:**
>
> ```python
> Intervals [1,4] and [4,5] are considered overlapping.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> intervals = [[4,7],[1,4]]
> ```
>
> **Output:**
>
> ```python
> [[1,7]]
> ```
>
> **Explanation:**
>
> ```python
> Intervals [1,4] and [4,7] are considered overlapping.
> ```

> [!warning]- Constraints
> - `1 <= intervals.length <= 10^4`
>
> 	- `intervals[i].length == 2`
>
> 	- `0 <= start_i <= end_i <= 10^4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `21 ms` | `23.3 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def merge(self, intervals: List[List[int]]) -> List[List[int]]:
>         intervals.sort()
>         m = len(intervals)
>         print(intervals)
>         res = []
>
>         b, l, r = 0, 0, 1
>         while l < m and r < m:
>             bStart, bEnd = intervals[b]
>             lStart, lEnd = intervals[l]
>             rStart, rEnd = intervals[r]
>
>             print(rStart, rEnd)
>
>             if lEnd >= rStart or bEnd >= rEnd: # if l and right overlap
>                 intervals[r] = [rStart, max(rEnd, lEnd)]
>                 l, r = l + 1, r + 1
>
>             else:
>                 res.append([intervals[b][0], max(bEnd, lEnd)])
>                 b, l, r = r, r, r + 1
>
>         res.append([intervals[b][0], max(intervals[b][1], intervals[l][1])])
>         return res
>
>
>
>
> ```
