### Problem Statement:

Given two `n x n` binary matrices `mat` and `target`, return `true`_ if it is possible to make _`mat`_ equal to _`target`_ by **rotating** _`mat`_ in **90-degree increments**, or _`false`_ otherwise._

> [!example]- Example 1
> **Input:**
>
> ```python
> mat = [[0,1],[1,0]], target = [[1,0],[0,1]]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> We can rotate mat 90 degrees clockwise to make mat equal target.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> mat = [[0,1],[1,1]], target = [[1,0],[0,1]]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> It is impossible to make mat equal to target by rotating mat.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> mat = [[0,0,0],[0,1,0],[1,1,1]], target = [[1,1,1],[0,1,0],[0,0,0]]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> We can rotate mat 90 degrees clockwise two times to make mat equal target.
> ```

> [!warning]- Constraints
> - `n == mat.length == target.length`
>
> 	- `n == mat[i].length == target[i].length`
>
> 	- `1 <= n <= 10`
>
> 	- `mat[i][j]` and `target[i][j]` are either `0` or `1`.
