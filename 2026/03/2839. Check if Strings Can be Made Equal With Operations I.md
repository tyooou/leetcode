### Problem Statement:

You are given two strings `s1` and `s2`, both of length `4`, consisting of **lowercase** English letters.

You can apply the following operation on any of the two strings **any** number of times:

	- Choose any two indices `i` and `j` such that `j - i = 2`, then **swap** the two characters at those indices in the string.

Return `true`_ if you can make the strings _`s1`_ and _`s2`_ equal, and _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s1 = "abcd", s2 = "cdab"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> We can do the following operations on s1:
> - Choose the indices i = 0, j = 2. The resulting string is s1 = "cbad".
> - Choose the indices i = 1, j = 3. The resulting string is s1 = "cdab" = s2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s1 = "abcd", s2 = "dacb"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> It is not possible to make the two strings equal.
> ```

> [!warning]- Constraints
> - `s1.length == s2.length == 4`
>
> 	- `s1` and `s2` consist only of lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Since the strings are very small you can try a brute-force approach.

> [!success]- Hint 2
> There are only `2` different swaps that are possible in a string.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.2 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def canBeEqual(self, s1: str, s2: str) -> bool:
>         m, n = len(s1), len(s2)
>         if m != n:
>             return False
>
>         aE, bE, aO, bO = "", "", "", ""
>         for i in range(m):
>             if i % 2 != 0:
>                 aE += s1[i]
>                 bE += s2[i]
>             else:
>                 aO += s1[i]
>                 bO += s2[i]
>
>         return sorted(aE) == sorted(bE) and sorted(aO) == sorted(bO)
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
