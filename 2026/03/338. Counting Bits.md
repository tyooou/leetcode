### Problem Statement:

Given an integer `n`, return _an array _`ans`_ of length _`n + 1`_ such that for each _`i`_ _(`0 <= i <= n`)_, _`ans[i]`_ is the **number of **_`1`_**'s** in the binary representation of _`i`.

Do not solve it with built-in functions (i.e., like `__builtin_popcount` in C++).

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 2
> ```
>
> **Output:**
>
> ```python
> [0,1,1]
> ```
>
> **Explanation:**
>
> ```python
> 0 --> 0
> 1 --> 1
> 2 --> 10
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 5
> ```
>
> **Output:**
>
> ```python
> [0,1,1,2,1,2]
> ```
>
> **Explanation:**
>
> ```python
> 0 --> 0
> 1 --> 1
> 2 --> 10
> 3 --> 11
> 4 --> 100
> 5 --> 101
> ```

> [!warning]- Constraints
> - `0 <= n <= 10^5`

> [!info]- Follow up
> - It is very easy to come up with a solution with a runtime of `O(n log n)`. Can you do it in linear time `O(n)` and possibly in a single pass?

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `20.1 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def countBits(self, n: int) -> List[int]:
>         n += 1
>         res = [0] * n
>         for i in range(n):
>             res[i] = i.bit_count()
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
