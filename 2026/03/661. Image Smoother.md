### Problem Statement:

An **image smoother** is a filter of the size `3 x 3` that can be applied to each cell of an image by rounding down the average of the cell and the eight surrounding cells (i.e., the average of the nine cells in the blue smoother). If one or more of the surrounding cells of a cell is not present, we do not consider it in the average (i.e., the average of the four cells in the red smoother).

Given an `m x n` integer matrix `img` representing the grayscale of an image, return _the image after applying the smoother on each cell of it_.

> [!example]- Example 1
> **Input:**
>
> ```python
> img = [[1,1,1],[1,0,1],[1,1,1]]
> ```
>
> **Output:**
>
> ```python
> [[0,0,0],[0,0,0],[0,0,0]]
> ```
>
> **Explanation:**
>
> ```python
> For the points (0,0), (0,2), (2,0), (2,2): floor(3/4) = floor(0.75) = 0
> For the points (0,1), (1,0), (1,2), (2,1): floor(5/6) = floor(0.83333333) = 0
> For the point (1,1): floor(8/9) = floor(0.88888889) = 0
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> img = [[100,200,100],[200,50,200],[100,200,100]]
> ```
>
> **Output:**
>
> ```python
> [[137,141,137],[141,138,141],[137,141,137]]
> ```
>
> **Explanation:**
>
> ```python
> For the points (0,0), (0,2), (2,0), (2,2): floor((100+200+200+50)/4) = floor(137.5) = 137
> For the points (0,1), (1,0), (1,2), (2,1): floor((200+200+50+200+100+100)/6) = floor(141.666667) = 141
> For the point (1,1): floor((50+200+200+200+200+100+100+100+100)/9) = floor(138.888889) = 138
> ```

> [!warning]- Constraints
> - `m == img.length`
>
> 	- `n == img[i].length`
>
> 	- `1 <= m, n <= 200`
>
> 	- `0 <= img[i][j] <= 255`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `183 ms` | `20.1 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def imageSmoother(self, img: List[List[int]]) -> List[List[int]]:
>         m, n = len(img), len(img[0])
>
>         res = [[0] * n for _ in range(m)]
>
>         for i in range(m):
>             for j in range(n):
>                 sSum, sCount = 0, 0
>                 for ni in range(-1, 2):
>                     for nj in range(-1, 2):
>                         if (i + ni >= 0) and (i + ni < m) and (j + nj >= 0) and (j + nj < n):
>                             sSum += img[i + ni][j + nj]
>                             sCount += 1
>
>                 sAverage = sSum // sCount
>                 res[i][j] = sAverage
>         return res
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
