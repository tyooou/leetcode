### Problem Statement:

In MATLAB, there is a handy function called `reshape` which can reshape an `m x n` matrix into a new one with a different size `r x c` keeping its original data.

You are given an `m x n` matrix `mat` and two integers `r` and `c` representing the number of rows and the number of columns of the wanted reshaped matrix.

The reshaped matrix should be filled with all the elements of the original matrix in the same row-traversing order as they were.

If the `reshape` operation with given parameters is possible and legal, output the new reshaped matrix; Otherwise, output the original matrix.

> [!example]- Example 1
> **Input:**
>
> ```python
> mat = [[1,2],[3,4]], r = 1, c = 4
> ```
>
> **Output:**
>
> ```python
> [[1,2,3,4]]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> mat = [[1,2],[3,4]], r = 2, c = 4
> ```
>
> **Output:**
>
> ```python
> [[1,2],[3,4]]
> ```

> [!warning]- Constraints
> - `m == mat.length`
>
> 	- `n == mat[i].length`
>
> 	- `1 <= m, n <= 100`
>
> 	- `-1000 <= mat[i][j] <= 1000`
>
> 	- `1 <= r, c <= 300`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `19.7 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def matrixReshape(self, mat: List[List[int]], r: int, c: int) -> List[List[int]]:
>         n, m = len(mat), len(mat[0])
>
>         if (n * m) != (r * c): # reshape is not possible
>             return mat
>
>         res = [[] for _ in range(r)]
>
>         rIdx, cIdx = 0, 0
>         for i in range(n):
>             for j in range(m):
>                 if (cIdx == c):
>                     cIdx = 0
>                     rIdx += 1
>                 res[rIdx].append(mat[i][j])
>                 cIdx += 1
>
>         return res
>
>
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
