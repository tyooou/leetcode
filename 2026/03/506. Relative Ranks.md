### Problem Statement:

You are given an integer array `score` of size `n`, where `score[i]` is the score of the `i^th` athlete in a competition. All the scores are guaranteed to be **unique**.

The athletes are **placed** based on their scores, where the `1^st` place athlete has the highest score, the `2^nd` place athlete has the `2^nd` highest score, and so on. The placement of each athlete determines their rank:

	- The `1^st` place athlete's rank is `"Gold Medal"`.

	- The `2^nd` place athlete's rank is `"Silver Medal"`.

	- The `3^rd` place athlete's rank is `"Bronze Medal"`.

	- For the `4^th` place to the `n^th` place athlete, their rank is their placement number (i.e., the `x^th` place athlete's rank is `"x"`).

Return an array `answer` of size `n` where `answer[i]` is the **rank** of the `i^th` athlete.

> [!example]- Example 1
> **Input:**
>
> ```python
> score = [5,4,3,2,1]
> ```
>
> **Output:**
>
> ```python
> ["Gold Medal","Silver Medal","Bronze Medal","4","5"]
> ```
>
> **Explanation:**
>
> ```python
> The placements are [1^st, 2^nd, 3^rd, 4^th, 5^th].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> score = [10,3,8,9,4]
> ```
>
> **Output:**
>
> ```python
> ["Gold Medal","5","Bronze Medal","Silver Medal","4"]
> ```
>
> **Explanation:**
>
> ```python
> The placements are [1^st, 5^th, 3^rd, 2^nd, 4^th].
> ```

> [!warning]- Constraints
> - `n == score.length`
>
> 	- `1 <= n <= 10^4`
>
> 	- `0 <= score[i] <= 10^6`
>
> 	- All the values in `score` are **unique**.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `20.5 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def findRelativeRanks(self, score: List[int]) -> List[str]:
>         rankMap = {}
>         ranks = ["Gold Medal", "Silver Medal", "Bronze Medal"]
>         sortScore = sorted(score)
>
>         sLen = len(sortScore)
>         for i, s in enumerate(sortScore):
>             nIdx = sLen - i
>             if nIdx > 3:
>                 rankMap[s] = nIdx
>             else:
>                 rankMap[s] = ranks[nIdx - 1]
>
>         return [str(rankMap[i]) for i in score]
>
>
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
