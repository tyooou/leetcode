### Problem Statement:

Given an `m x n` binary matrix `mat`, return _the number of special positions in _`mat`_._

A position `(i, j)` is called **special** if `mat[i][j] == 1` and all other elements in row `i` and column `j` are `0` (rows and columns are **0-indexed**).

> [!example]- Example 1
> **Input:**
>
> ```python
> mat = [[1,0,0],[0,0,1],[1,0,0]]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> (1, 2) is a special position because mat[1][2] == 1 and all other elements in row 1 and column 2 are 0.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> mat = [[1,0,0],[0,1,0],[0,0,1]]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> (0, 0), (1, 1) and (2, 2) are special positions.
> ```

> [!warning]- Constraints
> - `m == mat.length`
>
> 	- `n == mat[i].length`
>
> 	- `1 <= m, n <= 100`
>
> 	- `mat[i][j]` is either `0` or `1`.

### Hints:

> [!success]- Hint 1
> Keep track of 1s in each row and in each column. Then while iterating over matrix, if the current position is 1 and current row as well as current column contains exactly one occurrence of 1.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `19.7 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def numSpecial(self, mat: List[List[int]]) -> int:
>         rLen, cLen = len(mat), len(mat[0])
>         cTotal = [sum(col) for col in zip(*mat)]
>         count = 0
>
>         for r in range(0, rLen):
>             total = sum(mat[r])
>             if (total == 1):
>                 idx = mat[r].index(1)
>                 if (cTotal[idx] == 1):
>                     count += 1
>         return count
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
