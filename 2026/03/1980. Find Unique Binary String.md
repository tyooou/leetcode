### Problem Statement:

Given an array of strings `nums` containing `n` **unique** binary strings each of length `n`, return _a binary string of length _`n`_ that **does not appear** in _`nums`_. If there are multiple answers, you may return **any** of them_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = ["01","10"]
> ```
>
> **Output:**
>
> ```python
> "11"
> ```
>
> **Explanation:**
>
> ```python
> "11" does not appear in nums. "00" would also be correct.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = ["00","01"]
> ```
>
> **Output:**
>
> ```python
> "11"
> ```
>
> **Explanation:**
>
> ```python
> "11" does not appear in nums. "10" would also be correct.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = ["111","011","001"]
> ```
>
> **Output:**
>
> ```python
> "101"
> ```
>
> **Explanation:**
>
> ```python
> "101" does not appear in nums. "000", "010", "100", and "110" would also be correct.
> ```

> [!warning]- Constraints
> - `n == nums.length`
>
> 	- `1 <= n <= 16`
>
> 	- `nums[i].length == n`
>
> 	- `nums[i] `is either `'0'` or `'1'`.
>
> 	- All the strings of `nums` are **unique**.
