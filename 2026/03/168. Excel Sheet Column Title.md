### Problem Statement:

Given an integer `columnNumber`, return _its corresponding column title as it appears in an Excel sheet_.

For example:

A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28
...

> [!example]- Example 1
> **Input:**
>
> ```python
> columnNumber = 1
> ```
>
> **Output:**
>
> ```python
> "A"
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> columnNumber = 28
> ```
>
> **Output:**
>
> ```python
> "AB"
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> columnNumber = 701
> ```
>
> **Output:**
>
> ```python
> "ZY"
> ```

> [!warning]- Constraints
> - `1 <= columnNumber <= 2^31 - 1`

> ```python
> class Solution:
>     def convertToTitle(self, columnNumber: int) -> str:
>         res = ""
>
>         while columnNumber > 0:
>             columnNumber -= 1
>             res = chr((columnNumber % 26) + ord("A")) + res
>             columnNumber //= 26
>
>         return res
> ```
