### Problem Statement:

You are given a **0-indexed** integer matrix `grid` and an integer `k`.

Return _the **number** of submatrices that contain the top-left element of the_ `grid`, _and have a sum less than or equal to _`k`.

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [[7,6,3],[6,6,1]], k = 18
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> There are only 4 submatrices, shown in the image above, that contain the top-left element of grid, and have a sum less than or equal to 18.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[7,2,9],[1,5,0],[2,6,6]], k = 20
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> There are only 6 submatrices, shown in the image above, that contain the top-left element of grid, and have a sum less than or equal to 20.
> ```

> [!warning]- Constraints
> - `m == grid.length `
>
> 	- `n == grid[i].length`
>
> 	- `1 <= n, m <= 1000 `
>
> 	- `0 <= grid[i][j] <= 1000`
>
> 	- `1 <= k <= 10^9`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `350 ms` | `64.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
>         row = len(grid)
>         col = len(grid[0])
>         res = 0
>
>         for i in range(row):
>             for j in range(col):
>                 if i > 0:
>                     grid[i][j] += grid[i - 1][j]
>                 if j > 0:
>                     grid[i][j] += grid[i][j - 1]
>                 if i > 0 and j > 0:
>                     grid[i][j] -= grid[i - 1][j - 1]
>
>                 if grid[i][j] <= k:
>                     res += 1
>                 else:
>                     break
>
>         return res
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
