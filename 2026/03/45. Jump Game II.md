### Problem Statement:

You are given a **0-indexed** array of integers `nums` of length `n`. You are initially positioned at index 0.

Each element `nums[i]` represents the maximum length of a forward jump from index `i`. In other words, if you are at index `i`, you can jump to any index `(i + j)` where:

	- `0 <= j <= nums[i]` and

	- `i + j < n`

Return _the minimum number of jumps to reach index _`n - 1`. The test cases are generated such that you can reach index `n - 1`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [2,3,1,1,4]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The minimum number of jumps to reach the last index is 2. Jump 1 step from index 0 to 1, then 3 steps to the last index.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [2,3,0,1,4]
> ```
>
> **Output:**
>
> ```python
> 2
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^4`
>
> 	- `0 <= nums[i] <= 1000`
>
> 	- It's guaranteed that you can reach `nums[n - 1]`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `1396 ms` | `20.1 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def jump(self, nums: List[int]) -> int:
>         cache = [-1] * len(nums)
>         cache[0] = 0
>         for idx, val in enumerate(nums):
>             for jdx in range(idx, idx + val + 1):
>                 if (jdx < len(nums)) and (cache[jdx] == -1):
>                     cache[jdx] = cache[idx] + 1
>         return cache[-1]
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
