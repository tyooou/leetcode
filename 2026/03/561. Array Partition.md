### Problem Statement:

Given an integer array `nums` of `2n` integers, group these integers into `n` pairs `(a_1, b_1), (a_2, b_2), ..., (a_n, b_n)` such that the sum of `min(a_i, b_i)` for all `i` is **maximized**. Return_ the maximized sum_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,4,3,2]
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> All possible pairings (ignoring the ordering of elements) are:
> 1. (1, 4), (2, 3) -> min(1, 4) + min(2, 3) = 1 + 2 = 3
> 2. (1, 3), (2, 4) -> min(1, 3) + min(2, 4) = 1 + 2 = 3
> 3. (1, 2), (3, 4) -> min(1, 2) + min(3, 4) = 1 + 3 = 4
> So the maximum possible sum is 4.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [6,2,6,5,1,2]
> ```
>
> **Output:**
>
> ```python
> 9
> ```
>
> **Explanation:**
>
> ```python
> The optimal pairing is (2, 1), (2, 5), (6, 6). min(2, 1) + min(2, 5) + min(6, 6) = 1 + 2 + 6 = 9.
> ```

> [!warning]- Constraints
> - `1 <= n <= 10^4`
>
> 	- `nums.length == 2 * n`
>
> 	- `-10^4 <= nums[i] <= 10^4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `27 ms` | `21.4 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def arrayPairSum(self, nums: List[int]) -> int:
>         nums.sort()
>         nLen = len(nums)
>         res = 0
>
>         for i in range(0, nLen, 2):
>             res += nums[i]
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
