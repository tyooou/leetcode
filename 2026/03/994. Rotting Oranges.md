### Problem Statement:

You are given an `m x n` `grid` where each cell can have one of three values:

	- `0` representing an empty cell,

	- `1` representing a fresh orange, or

	- `2` representing a rotten orange.

Every minute, any fresh orange that is **4-directionally adjacent** to a rotten orange becomes rotten.

Return _the minimum number of minutes that must elapse until no cell has a fresh orange_. If _this is impossible, return_ `-1`.

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [[2,1,1],[1,1,0],[0,1,1]]
> ```
>
> **Output:**
>
> ```python
> 4
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[2,1,1],[0,1,1],[1,0,1]]
> ```
>
> **Output:**
>
> ```python
> -1
> ```
>
> **Explanation:**
>
> ```python
> The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> grid = [[0,2]]
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> Since there are already no fresh oranges at minute 0, the answer is just 0.
> ```

> [!warning]- Constraints
> - `m == grid.length`
>
> 	- `n == grid[i].length`
>
> 	- `1 <= m, n <= 10`
>
> 	- `grid[i][j]` is `0`, `1`, or `2`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `9 ms` | `19.6 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def orangesRotting(self, grid: List[List[int]]) -> int:
>         d = [(0, 1), (1, 0), (0, -1), (-1, 0)]
>         m, n = len(grid), len(grid[0])
>         mxTime = 0
>
>         q = deque()
>         for i in range(m):
>             for j in range(n):
>                 if grid[i][j] == 2:
>                     q.append((i, j, 0))
>
>         while q:
>             r, c, time = q.popleft()
>             mxTime = max(mxTime, time)
>
>             for dr, dc in d:
>                 nr, nc = r + dr, c + dc
>                 if nr >= 0 and nr < m and nc >= 0 and nc < n and grid[nr][nc] == 1:
>                     grid[nr][nc] = 2
>                     q.append((nr, nc, time + 1))
>                     print(grid)
>
>         for i in range(m):
>             for j in range(n):
>                 if grid[i][j] == 1:
>                     return -1
>
>         return mxTime
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
