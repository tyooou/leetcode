### Problem Statement:

Given an array `arr`, replace every element in that array with the greatest element among the elements to its right, and replace the last element with `-1`.

After doing so, return the array.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [17,18,5,4,6,1]
> ```
>
> **Output:**
>
> ```python
> [18,6,6,6,1,-1]
> ```
>
> **Explanation:**
>
> ```python
> - index 0 --> the greatest element to the right of index 0 is index 1 (18).
> - index 1 --> the greatest element to the right of index 1 is index 4 (6).
> - index 2 --> the greatest element to the right of index 2 is index 4 (6).
> - index 3 --> the greatest element to the right of index 3 is index 4 (6).
> - index 4 --> the greatest element to the right of index 4 is index 5 (1).
> - index 5 --> there are no elements to the right of index 5, so we put -1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [400]
> ```
>
> **Output:**
>
> ```python
> [-1]
> ```
>
> **Explanation:**
>
> ```python
> There are no elements to the right of index 0.
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 10^4`
>
> 	- `1 <= arr[i] <= 10^5`

---

### Hints:

> [!success]- Hint 1
> Loop through the array starting from the end.

> [!success]- Hint 2
> Keep the maximum value seen so far.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `15 ms` | `20.5 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def replaceElements(self, arr: List[int]) -> List[int]:
>         a, nextMax, currMax = len(arr), -1, -1
>         for i in range(a - 1, -1, -1):
>             nextMax = max(currMax, arr[i])
>             arr[i] = currMax
>             currMax = nextMax
>         return arr
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
