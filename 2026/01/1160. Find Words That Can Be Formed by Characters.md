### Problem Statement:

You are given an array of strings `words` and a string `chars`.

A string is **good** if it can be formed by characters from `chars` (each character can only be used once for **each** word in `words`).

Return _the sum of lengths of all good strings in words_.

> [!example]- Example 1
> **Input:**
>
> ```python
> words = ["cat","bt","hat","tree"], chars = "atach"
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The strings that can be formed are "cat" and "hat" so the answer is 3 + 3 = 6.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> words = ["hello","world","leetcode"], chars = "welldonehoneyr"
> ```
>
> **Output:**
>
> ```python
> 10
> ```
>
> **Explanation:**
>
> ```python
> The strings that can be formed are "hello" and "world" so the answer is 5 + 5 = 10.
> ```

> [!warning]- Constraints
> - `1 <= words.length <= 1000`
>
> 	- `1 <= words[i].length, chars.length <= 100`
>
> 	- `words[i]` and `chars` consist of lowercase English letters.

### Hints:

> Solve the problem for each string in `words` independently.

> [!success]- Hint 2

> [!success]- Hint 4

> ```python
> class Solution:
>     def countCharacters(self, words: List[str], chars: str) -> int:
>         char_list = defaultdict(int)
>         res = 0
>
>         for c in chars:
>             char_list[c] = char_list.get(c, 0) + 1
>
>         for w in words:
>             word_list = defaultdict(int)
>             for c in w:
>                 word_list[c] = word_list.get(c, 0) + 1
>
>             is_match = True
>             for k, v in word_list.items():
>                 if char_list[k] < v:
>                     is_match = False
>                     break
>
>             if is_match:
>                 res += len(w)
>
>         return res
>
>
> ```
