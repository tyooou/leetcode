### Problem Statement:

Given an integer array `nums`, move all the even integers at the beginning of the array followed by all the odd integers.

Return _**any array** that satisfies this condition_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [3,1,2,4]
> ```
>
> **Output:**
>
> ```python
> [2,4,3,1]
> ```
>
> **Explanation:**
>
> ```python
> The outputs [4,2,3,1], [2,4,1,3], and [4,2,1,3] would also be accepted.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [0]
> ```
>
> **Output:**
>
> ```python
> [0]
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 5000`
>
> 	- `0 <= nums[i] <= 5000`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `19.9 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>     def sortArrayByParity(self, nums: List[int]) -> List[int]:
>         n, i = len(nums), 0
>         for j in range(0, n):
>             if (nums[j] % 2 == 0):
>                 k = nums[i]
>                 nums[i] = nums[j]
>                 nums[j] = k
>                 i += 1
>         return nums
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
