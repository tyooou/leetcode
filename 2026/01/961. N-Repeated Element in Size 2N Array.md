### Problem Statement:

You are given an integer array `nums` with the following properties:

	- `nums.length == 2 * n`.

	- `nums` contains `n + 1` **unique** values, `n` of which occur **exactly once** in the array.

	- Exactly one element of `nums` is repeated `n` times.

Return _the element that is repeated _`n`_ times_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,3]
> ```
>
> **Output:**
>
> ```python
> 3
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [2,1,2,5,3,2]
> ```
>
> **Output:**
>
> ```python
> 2
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [5,1,5,2,5,3,5,4]
> ```
>
> **Output:**
>
> ```python
> 5
> ```

> [!warning]- Constraints
> - `2 <= n <= 5000`
>
> 	- `nums.length == 2 * n`
>
> 	- `0 <= nums[i] <= 10^4`
>
> 	- `nums` contains `n + 1` **unique** elements and one of them is repeated exactly `n` times.

> ```python
> class Solution:
>     def repeatedNTimes(self, nums: List[int]) -> int:
>         count_list = defaultdict(int)
>         n = len(nums) // 2
>
>         for el in nums:
>             count_list[el] = count_list.get(el, 0) + 1
>             if count_list[el] == n:
>                 return el
>
>         return -1
>
>
> ```
