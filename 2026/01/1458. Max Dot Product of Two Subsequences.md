### Problem Statement:

Given two arrays `nums1` and `nums2`.

Return the maximum dot product between **non-empty** subsequences of nums1 and nums2 with the same length.

A subsequence of an array is a new array which is formed from the original array by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (ie, `[2,3,5]` is a subsequence of `[1,2,3,4,5]` while `[1,5,3]` is not).

> [!example]- Example 1
> **Input:**
>
> ```python
> nums1 = [2,1,-2,5], nums2 = [3,0,-6]
> ```
>
> **Output:**
>
> ```python
> 18
> ```
>
> **Explanation:**
>
> ```python
> Take subsequence [2,-2] from nums1 and subsequence [3,-6] from nums2.
> Their dot product is (2*3 + (-2)*(-6)) = 18.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums1 = [3,-2], nums2 = [2,-6,7]
> ```
>
> **Output:**
>
> ```python
> 21
> ```
>
> **Explanation:**
>
> ```python
> Take subsequence [3] from nums1 and subsequence [7] from nums2.
> Their dot product is (3*7) = 21.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums1 = [-1,-1], nums2 = [1,1]
> ```
>
> **Output:**
>
> ```python
> -1
> ```
>
> **Explanation:**
>
> ```python
> Take subsequence [-1] from nums1 and subsequence [1] from nums2.
> Their dot product is -1.
> ```

> [!warning]- Constraints
> - `1 <= nums1.length, nums2.length <= 500`
>
> 	- `-1000 <= nums1[i], nums2[i] <= 1000`

### Hints:

> [!success]- Hint 1
> Use dynamic programming, define DP[i][j] as the maximum dot product of two subsequences starting in the position i of nums1 and position j of nums2.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `179 ms` | `21.8 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
>         n, m = len(nums1), len(nums2)
>         dp = [[0] * m for i in range(n)]
>         for i in range(n):
>             for j in range(m):
>                 dp[i][j] = nums1[i] * nums2[j]
>                 if i and j:
>                     dp[i][j] += max(dp[i - 1][j - 1], 0)
>                 if i:
>                     dp[i][j] = max(dp[i][j], dp[i - 1][j])
>                 if j:
>                     dp[i][j] = max(dp[i][j], dp[i][j - 1])
>         return dp[-1][-1]
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
