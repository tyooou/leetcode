### Problem Statement:

Given the `head` of a singly linked list, return _the middle node of the linked list_.

If there are two middle nodes, return **the second middle** node.

> [!example]- Example 1
> **Input:**
>
> ```python
> head = [1,2,3,4,5]
> ```
>
> **Output:**
>
> ```python
> [3,4,5]
> ```
>
> **Explanation:**
>
> ```python
> The middle node of the list is node 3.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> head = [1,2,3,4,5,6]
> ```
>
> **Output:**
>
> ```python
> [4,5,6]
> ```
>
> **Explanation:**
>
> ```python
> Since the list has two middle nodes with values 3 and 4, we return the second one.
> ```

> [!warning]- Constraints
> - The number of nodes in the list is in the range `[1, 100]`.
>
> 	- `1 <= Node.val <= 100`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.5 MB` | `O(n)` | `O(1)` |
>
> ```python
> # Definition for singly-linked list.
> # class ListNode:
> #     def __init__(self, val=0, next=None):
> #         self.val = val
> #         self.next = next
> class Solution:
>     def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         curr, pivot = head, head
>         count = 0
>
>         while (curr):
>             if (count % 2 != 0):
>                 pivot = pivot.next
>             count += 1
>             curr = curr.next
>
>         return pivot
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
