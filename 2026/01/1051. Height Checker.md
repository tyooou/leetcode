### Problem Statement:

A school is trying to take an annual photo of all the students. The students are asked to stand in a single file line in **non-decreasing order** by height. Let this ordering be represented by the integer array `expected` where `expected[i]` is the expected height of the `i^th` student in line.

You are given an integer array `heights` representing the **current order** that the students are standing in. Each `heights[i]` is the height of the `i^th` student in line (**0-indexed**).

Return _the **number of indices** where _`heights[i] != expected[i]`.

> [!example]- Example 1
> **Input:**
>
> ```python
> heights = [1,1,4,2,1,3]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> heights:  [1,1,4,2,1,3]
> expected: [1,1,1,2,3,4]
> Indices 2, 4, and 5 do not match.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> heights = [5,1,2,3,4]
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> heights:  [5,1,2,3,4]
> expected: [1,2,3,4,5]
> All indices do not match.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> heights = [1,2,3,4,5]
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> heights:  [1,2,3,4,5]
> expected: [1,2,3,4,5]
> All indices match.
> ```

> [!warning]- Constraints
> - `1 <= heights.length <= 100`
>
> 	- `1 <= heights[i] <= 100`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `19.3 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def heightChecker(self, heights: List[int]) -> int:
>
>         def quicksort(arr: List[int]) -> List[int]:
>             if (len(arr) < 2):
>                 return arr
>
>             p = arr[0]
>             low = [i for i in arr[1:] if i < p]
>             high = [j for j in arr[1:] if j >= p]
>             return quicksort(low) + [p] + quicksort(high)
>
>         sortedArr = quicksort(heights)
>         count = 0
>
>         for h in range(0, len(heights)):
>             if sortedArr[h] != heights[h]:
>                 count += 1
>
>         return count
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
