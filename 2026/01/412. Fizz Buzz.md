### Problem Statement:

Given an integer `n`, return _a string array _`answer`_ (**1-indexed**) where_:

	- `answer[i] == "FizzBuzz"` if `i` is divisible by `3` and `5`.

	- `answer[i] == "Fizz"` if `i` is divisible by `3`.

	- `answer[i] == "Buzz"` if `i` is divisible by `5`.

	- `answer[i] == i` (as a string) if none of the above conditions are true.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 3
> ```
>
> **Output:**
>
> ```python
> ["1","2","Fizz"]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 5
> ```
>
> **Output:**
>
> ```python
> ["1","2","Fizz","4","Buzz"]
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 15
> ```
>
> **Output:**
>
> ```python
> ["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]
> ```

> [!warning]- Constraints
> - `1 <= n <= 10^4`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4 ms` | `19.7 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def fizzBuzz(self, n: int) -> List[str]:
>         arr = []
>         for i in range(1, n + 1):
>             res = ""
>             if (i % 3 == 0):
>                 res += "Fizz"
>             if (i % 5 == 0):
>                 res += "Buzz"
>             if (res == ""):
>                 res = f"{i}"
>             arr.append(res)
>
>         return arr
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
