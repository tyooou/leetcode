### Problem Statement:

Given the `root` of a binary tree, the level of its root is `1`, the level of its children is `2`, and so on.

Return the **smallest** level `x` such that the sum of all the values of nodes at level `x` is **maximal**.

> [!example]- Example 1
> **Input:**
>
> ```python
> root = [1,7,0,7,-8,null,null]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Level 1 sum = 1.
> Level 2 sum = 7 + 0 = 7.
> Level 3 sum = 7 + -8 = -1.
> So we return the level with the maximum sum which is level 2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> root = [989,null,10250,98693,-89388,null,null,null,-32127]
> ```
>
> **Output:**
>
> ```python
> 2
> ```

> [!warning]- Constraints
> - The number of nodes in the tree is in the range `[1, 10^4]`.
>
> 	- `-10^5 <= Node.val <= 10^5`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `15 ms` | `23 MB` | `O(n)` | `O(1)` |
>
> ```python
>
> from collections import deque
>
> class Solution:
>     def maxLevelSum(self, root: Optional[TreeNode]) -> int:
>         curr_lvl = 1
>         maxi = float('-inf')
>         ans = 1
>
>         queue = deque([root])
>
>         while queue:
>             curr_sum = 0
>             lvl_size = len(queue)
>
>             for _ in range(lvl_size):
>                 node = queue.popleft()
>                 curr_sum += node.val
>
>                 if node.left:
>                     queue.append(node.left)
>                 if node.right:
>                     queue.append(node.right)
>
>             if curr_sum > maxi:
>                 maxi = curr_sum
>                 ans = curr_lvl
>
>             curr_lvl += 1
>
>         return ans
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
