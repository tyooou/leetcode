### Problem Statement:

Given a fixed-length integer array `arr`, duplicate each occurrence of zero, shifting the remaining elements to the right.

**Note** that elements beyond the length of the original array are not written. Do the above modifications to the input array in place and do not return anything.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [1,0,2,3,0,4,5,0]
> ```
>
> **Output:**
>
> ```python
> [1,0,0,2,3,0,0,4]
> ```
>
> **Explanation:**
>
> ```python
> After calling your function, the input array is modified to: [1,0,0,2,3,0,0,4]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [1,2,3]
> ```
>
> **Output:**
>
> ```python
> [1,2,3]
> ```
>
> **Explanation:**
>
> ```python
> After calling your function, the input array is modified to: [1,2,3]
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 10^4`
>
> 	- `0 <= arr[i] <= 9`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `507 ms` | `19.4 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def duplicateZeros(self, arr: List[int]) -> None:
>         a = len(arr)
>         skip = False
>         for i in range(0, a):
>             if skip:
>                 skip = False
>                 continue
>             if (arr[i] == 0):
>                 for j in range(a - 1, i, -1):
>                     arr[j] = arr[j - 1]
>                 skip = True
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
