### Problem Statement:

Given an array `arr` of integers, check if there exist two indices `i` and `j` such that :

	- `i != j`

	- `0 <= i, j < arr.length`

	- `arr[i] == 2 * arr[j]`

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [10,2,5,3]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> For i = 0 and j = 2, arr[i] == 10 == 2 * 5 == 2 * arr[j]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [3,1,7,11]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> There is no i and j that satisfy the conditions.
> ```

> [!warning]- Constraints
> - `2 <= arr.length <= 500`
>
> 	- `-10^3 <= arr[i] <= 10^3`

---

### Hints:

> [!success]- Hint 1
> Loop from i = 0 to arr.length, maintaining in a hashTable the array elements from [0, i - 1].

> [!success]- Hint 2
> On each step of the loop check if we have seen the element `2 * arr[i]` so far.

> [!success]- Hint 3
> Also check if we have seen `arr[i] / 2` in case `arr[i] % 2 == 0`.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `2 ms` | `18.9 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def checkIfExist(self, arr: List[int]) -> bool:
>         exists = defaultdict(int)
>
>         for i in range(0, len(arr)):
>             if ((arr[i] * 2) in exists) or (arr[i] % 2 == 0 and arr[i] // 2 in exists):
>                 return True
>             exists[arr[i]] = i
>
>         return False
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
