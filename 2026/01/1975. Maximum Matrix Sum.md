### Problem Statement:

You are given an `n x n` integer `matrix`. You can do the following operation **any** number of times:

	- Choose any two **adjacent** elements of `matrix` and **multiply** each of them by `-1`.

Two elements are considered **adjacent** if and only if they share a **border**.

Your goal is to **maximize** the summation of the matrix's elements. Return _the **maximum** sum of the matrix's elements using the operation mentioned above._

> [!example]- Example 1
> **Input:**
>
> ```python
> matrix = [[1,-1],[-1,1]]
> ```
>
> **Output:**
>
> ```python
> 4
> **Explanation:** We can follow the following steps to reach sum equals 4:
> - Multiply the 2 elements in the first row by -1.
> - Multiply the 2 elements in the first column by -1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> matrix = [[1,2,3],[-1,-2,-3],[1,2,3]]
> ```
>
> **Output:**
>
> ```python
> 16
> **Explanation:** We can follow the following step to reach sum equals 16:
> - Multiply the 2 last elements in the second row by -1.
> ```

> [!warning]- Constraints
> - `n == matrix.length == matrix[i].length`
>
> 	- `2 <= n <= 250`
>
> 	- `-10^5 <= matrix[i][j] <= 10^5`

### Hints:

> [!success]- Hint 1
> Try to use the operation so that each row has only one negative number.

> [!success]- Hint 2
> If you have only one negative element you cannot convert it to positive.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `87 ms` | `26.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def maxMatrixSum(self, matrix: list[list[int]]) -> int:
>         totalSum = 0
>         neg = 0
>         minAbs = float('inf')
>
>         for row in matrix:
>             for v in row:
>                 if v < 0:
>                     neg += 1
>                 av = abs(v)
>                 totalSum += av
>                 minAbs = min(minAbs, av)
>
>         return totalSum if neg % 2 == 0 else totalSum - 2 * minAbs
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
