### Problem Statement:

Given two strings `s1` and `s2`, return _the lowest **ASCII** sum of deleted characters to make two strings equal_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s1 = "sea", s2 = "eat"
> ```
>
> **Output:**
>
> ```python
> 231
> ```
>
> **Explanation:**
>
> ```python
> Deleting "s" from "sea" adds the ASCII value of "s" (115) to the sum.
> Deleting "t" from "eat" adds 116 to the sum.
> At the end, both strings are equal, and 115 + 116 = 231 is the minimum sum possible to achieve this.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s1 = "delete", s2 = "leet"
> ```
>
> **Output:**
>
> ```python
> 403
> ```
>
> **Explanation:**
>
> ```python
> Deleting "dee" from "delete" to turn the string into "let",
> adds 100[d] + 101[e] + 101[e] to the sum.
> Deleting "e" from "leet" adds 101[e] to the sum.
> At the end, both strings are equal to "let", and the answer is 100+101+101+101 = 403.
> If instead we turned both strings into "lee" or "eet", we would get answers of 433 or 417, which are higher.
> ```

> [!warning]- Constraints
> - `1 <= s1.length, s2.length <= 1000`
>
> 	- `s1` and `s2` consist of lowercase English letters.

### Hints:

> [!success]- Hint 1
> Let dp(i, j) be the answer for inputs s1[i:] and s2[j:].

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `267 ms` | `23.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def minimumDeleteSum(self, a: str, b: str) -> int:
>         n, m = len(a), len(b)
>         dp = [[0] * (m + 1) for _ in range(n + 1)] # dp matrix
>
>         for i in range(1, n + 1):
>             dp[i][0] = dp[i - 1][0] + ord(a[i - 1]) # preset with ascii value
>
>         for j in range(1, m + 1):
>             dp[0][j] = dp[0][j - 1] + ord(b[j - 1]) # preset with ascii value
>
>         for i in range(1, n + 1):
>             for j in range(1, m + 1):
>                 if a[i - 1] == b[j - 1]: # match
>                     dp[i][j] = dp[i - 1][j - 1] # extend
>                 else:
>                     dp[i][j] = min(
>                         dp[i - 1][j] + ord(a[i - 1]), # minimum
>                         dp[i][j - 1] + ord(b[j - 1])
>                     )
>
>         return dp[n][m]
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
