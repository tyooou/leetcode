### Problem Statement:

Given an integer `n`, return _`true` if it is a power of four. Otherwise, return `false`_.

An integer `n` is a power of four, if there exists an integer `x` such that `n == 4x`.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 16
> ```
>
> **Output:**
>
> ```python
> true
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 5
> ```
>
> **Output:**
>
> ```python
> false
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 1
> ```
>
> **Output:**
>
> ```python
> true
> ```

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(log4 n)` | `O(1)` |
>
> ```python
> class Solution:
>
> 	def isPowerOfFour(self, n: int) -> bool:
> 		count = 1
> 		while count <= n:
> 			if count == n:
> 				return True
> 			count *= 4
>
> 		return False
> ```

> [!success]- Reasoning
> 1. We use `count` which increments in powers of 4 to compare with `n` to see if `n` is a power of 4.
> 2. Run loop and increment `count` in powers of 4.
> 3. If in loop and `count` is equal to `n`, `n` is a power of 4.
> 4. If still in loop, and `count` is greater than `n`, `n` cannot be a multiple of 4 and thus return `False`.
