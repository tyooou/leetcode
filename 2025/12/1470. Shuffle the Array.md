### Problem Statement:

Given the array `nums` consisting of `2n` elements in the form `[x_1,x_2,...,x_n,y_1,y_2,...,y_n]`.

_Return the array in the form_ `[x_1,y_1,x_2,y_2,...,x_n,y_n]`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [2,5,1,3,4,7], n = 3
> ```
>
> **Output:**
>
> ```python
> [2,3,5,4,1,7]
> ```
>
> **Explanation:**
>
> ```python
> Since x_1=2, x_2=5, x_3=1, y_1=3, y_2=4, y_3=7 then the answer is [2,3,5,4,1,7].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,2,3,4,4,3,2,1], n = 4
> ```
>
> **Output:**
>
> ```python
> [1,4,2,3,3,2,4,1]
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [1,1,2,2], n = 2
> ```
>
> **Output:**
>
> ```python
> [1,2,1,2]
> ```

> [!warning]- Constraints
> - `1 <= n <= 500`
>
> 	- `nums.length == 2n`
>
> 	- `1 <= nums[i] <= 10^3`

> class Solution:
>     def shuffle(self, nums: List[int], n: int) -> List[int]:
>         ans = []
>
>         for i in range(0, n):
>             ans.append(nums[i])
>             ans.append(nums[i + n])
>         return ans
> ```
