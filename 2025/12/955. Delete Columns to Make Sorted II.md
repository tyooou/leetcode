### Problem Statement:

You are given an array of `n` strings `strs`, all of the same length.

We may choose any deletion indices, and we delete all the characters in those indices for each string.

For example, if we have `strs = ["abcdef","uvwxyz"]` and deletion indices `{0, 2, 3}`, then the final array after deletions is `["bef", "vyz"]`.

Suppose we chose a set of deletion indices `answer` such that after deletions, the final array has its elements in **lexicographic** order (i.e., `strs[0] <= strs[1] <= strs[2] <= ... <= strs[n - 1]`). Return _the minimum possible value of_ `answer.length`.

> [!example]- Example 1
> **Input:**
>
> ```python
> strs = ["ca","bb","ac"]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> After deleting the first column, strs = ["a", "b", "c"].
> Now strs is in lexicographic order (ie. strs[0] <= strs[1] <= strs[2]).
> We require at least 1 deletion since initially strs was not in lexicographic order, so the answer is 1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> strs = ["xc","yb","za"]
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> strs is already in lexicographic order, so we do not need to delete anything.
> Note that the rows of strs are not necessarily in lexicographic order:
> i.e., it is NOT necessarily true that (strs[0][0] <= strs[0][1] <= ...)
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> strs = ["zyx","wvu","tsr"]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> We have to delete every column.
> ```

> [!warning]- Constraints
> - `n == strs.length`
>
> 	- `1 <= n <= 100`
>
> 	- `1 <= strs[i].length <= 100`
>
> 	- `strs[i]` consists of lowercase English letters.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `17.3 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def minDeletionSize(self, strs: List[str]) -> int:
>         n, m = len(strs), len(strs[0])
>         sorted_pairs = [False] * (n - 1)
>         deleted_count = 0
>
>         for col in range(m):
>             to_delete = False
>
>             for row in range(n - 1): # scan entire column if breaks order
>                 if not sorted_pairs[row] and \
>                     strs[row][col] > strs[row + 1][col]: # if row has not been marked and not lexigraphical order
>                     to_delete = True  # delete column
>                     break
>
>             if to_delete:
>                 deleted_count += 1
>                 continue
>
>             for row in range(n - 1):
>                 if not sorted_pairs[row] and \
>                     strs[row][col] < strs[row + 1][col]: # # if row has not been marked and lexigraphical order
>                     sorted_pairs[row] = True # order is decided
>
>             if all(sorted_pairs): # if columns are sorted
>                 break
>
>         return deleted_count
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
