### Problem Statement:

You are given an integer array `prices` representing the daily price history of a stock, where `prices[i]` is the stock price on the `i^th` day.

A **smooth descent period** of a stock consists of **one or more contiguous** days such that the price on each day is **lower** than the price on the **preceding day** by **exactly** `1`. The first day of the period is exempted from this rule.

Return _the number of **smooth descent periods**_.

> [!example]- Example 1
> **Input:**
>
> ```python
> prices = [3,2,1,4]
> ```
>
> **Output:**
>
> ```python
> 7
> ```
>
> **Explanation:**
>
> ```python
> There are 7 smooth descent periods:
> [3], [2], [1], [4], [3,2], [2,1], and [3,2,1]
> Note that a period with one day is a smooth descent period by the definition.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> prices = [8,6,7,7]
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> There are 4 smooth descent periods: [8], [6], [7], and [7]
> Note that [8,6] is not a smooth descent period as 8 - 6 ≠ 1.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> prices = [1]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> There is 1 smooth descent period: [1]
> ```

> [!warning]- Constraints
> - `1 <= prices.length <= 10^5`
>
> 	- `1 <= prices[i] <= 10^5`

### Hints:

> [!success]- Hint 1
> Any array is a series of adjacent longest possible smooth descent periods. For example, [5,3,2,1,7,6] is [5] + [3,2,1] + [7,6].

> [!success]- Hint 2
> Think of a 2-pointer approach to traverse the array and find each longest possible period.

> [!success]- Hint 3
> Suppose you found the longest possible period with a length of k. How many periods are within that period? How can you count them quickly? Think of the formula to calculate the sum of 1, 2, 3, ..., k.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |

> | `54 ms` | `30 MB` | `*(fill in)*` | `*(fill in)*` |
>
> ```python
> class Solution:
>     def getDescentPeriods(self, prices: List[int]) -> int:
>         p = len(prices)
>         continuous, descent = 0, 0
>         for i in range(0, p - 1):
>             if prices[i] - prices[i + 1] == 1:
>                 continuous += 1
>                 descent += continuous
>             else:
>                 continuous = 0
>         return descent + p
> ```
