### Problem Statement:

You are given an integer array `prices` where `prices[i]` is the price of a stock in dollars on the `i^th` day, and an integer `k`.

You are allowed to make at most `k` transactions, where each transaction can be either of the following:

	-

**Normal transaction**: Buy on day `i`, then sell on a later day `j` where `i < j`. You profit `prices[j] - prices[i]`.

	-

**Short selling transaction**: Sell on day `i`, then buy back on a later day `j` where `i < j`. You profit `prices[i] - prices[j]`.

**Note** that you must complete each transaction before starting another. Additionally, you can't buy or sell on the same day you are selling or buying back as part of a previous transaction.

Return the **maximum** total profit you can earn by making **at most** `k` transactions.

> [!example]- Example 1
> **Input:** prices = [1,7,9,8,2], k = 2
>
> **Output:** 14
>
> **Explanation:**
>
> We can make $14 of profit through 2 transactions:
>
> 	- A normal transaction: buy the stock on day 0 for $1 then sell it on day 2 for $9.
>
> 	- A short selling transaction: sell the stock on day 3 for $8 then buy back on day 4 for $2.

> [!example]- Example 2
> **Input:** prices = [12,16,19,19,8,1,19,13,9], k = 3
>
> **Output:** 36
>
> **Explanation:**
>
> We can make $36 of profit through 3 transactions:
>
> 	- A normal transaction: buy the stock on day 0 for $12 then sell it on day 2 for $19.
>
> 	- A short selling transaction: sell the stock on day 3 for $19 then buy back on day 4 for $8.
>
> 	- A normal transaction: buy the stock on day 5 for $1 then sell it on day 6 for $19.

> [!warning]- Constraints
> - `2 <= prices.length <= 10^3`
>
> 	- `1 <= prices[i] <= 10^9`
>
> 	- `1 <= k <= prices.length / 2`

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4031 ms` | `184.9 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def maximumProfit(self, prices: List[int], k: int) -> int:
>         n = len(prices)
>
>         """
>         Status: Did not complete without editorial.
>
>         States:
>
>         -   returns the maximum profit after day i if exactly j transactions have
>             been completed and the day ends with
>
>                 dfs(i, j, 0)    no stock held.
>                 dfs(i, j, 1)    long position.
>                 dfs(i, j, 2)    short position.
>
>         Outcomes:
>
>         -   Nothing happens on the day, then all state carry on from the previous day (i - 1).
>
>         -   Buy on day i.
>
>             -   Holding stock from previous day (i - 1), buying starts the jth (long) transaction:
>                     -> dfs(i - 1, j - 1, 0) -> profit decreases by prices[i]
>                     -> dfs(i, j, 1) = dfs(i - 1, j - 1, 0) + prices[i]
>
>             -   Holding no stock from previous day (i - 1), buying ends the jth (short) transaction:
>                     -> dfs(i - 1, j, 2) -> profit decreases by prices[i]
>                     -> dfs(i, j, 0) = dfs(i - 1, j, 2) + prices[i]
>
>         -   Sell on day i.
>
>             -   Holding stock from previous day (i - 1), selling ends the jth (long) transaction:
>                     -> dfs(i - 1, j, 1) -> profit increases by prices[i]
>                     -> dfs(i, j, 0) = dfs(i - 1, j, 1) + prices[i]
>
>             -   Holding no stock from previous day (i - 1), selling starts the jth (short)
>                 transaction:
>                     -> dfs(i - 1, j - 1, 0) -> profit increases by prices[i]
>                     -> dfs(i, j, 2) = dfs(i - 1, j - 1, 0) + prices[i]
>
>         Boundary conditions:
>
>         -   on day 0, only one price exists.
>
>             -   if no action -> profit = 0
>             -   if long -> profit = -prices[0]
>             -   if short -> profit = prices[0] (cannot occur, no stock held at day 0)
>
>         -   if j = 0, profit is zero.
>
>         Final answer must be: dfs(n - 1, k, 0)
>             -   At most k total transactions.
>             -   Must end with no stock or in short position.
>         """
>
>         @cache
>         def dfs(i, j, state):
>
>             """
>             i       current day index (0 to n - 1)
>             j       number of transactions left (0 <= j <= k)
>             state   current transaction status
>                     0   no position
>                     1   long
>                     2   short
>             """
>
>             # base case: if no transactions left, no profit can be made.
>             if j == 0:
>                 return 0
>
>             # base case: if day 0, set profit based on state.
>             if i == 0:
>                 return (
>                     0 if state == 0 else -prices[0] if state == 1 else prices[0]
>                 )
>
>             # get current price of stock
>             p = prices[i]
>
>             # the day ends with no position
>             if state == 0:
>                 res = max(
>                     dfs(i - 1, j, 0),  # flat yesterday, did nothing today
>                     dfs(i - 1, j, 1) + p, # long yesterday, sold today
>                     dfs(i - 1, j, 2) - p  # short yesterday, and covered today
>                 )
>
>             # the day ends with long position
>             elif state == 1:
>                 res = max(
>                     dfs(i - 1, j, 1), # long yesterday, held stock
>                     dfs(i - 1, j - 1, 0) - p # flat yesterday, bought stock
>                 )
>
>             # the day ends with short position
>             else:
>                 res = max(
>                     dfs(i - 1, j, 2), # short yesterday, held stock.
>                     dfs(i - 1, j - 1, 0) + p #  flat yesterday, shorted today.
>                 )
>
>             return res
>
>         # start recursion, end in flat state so all positions are closed
>         ans = dfs(n - 1, k, 0)
>
>         # clear cache
>         dfs.cache_clear()
>
>         return ans
> ```

> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
