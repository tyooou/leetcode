### Problem Statement:

Given two non-negative integers `low` and `high`. Return the _count of odd numbers between _`low`_ and _`high`_ (inclusive)_.

> [!example]- Example 1
> **Input:**
>
> ```python
> low = 3, high = 7
> ```
>
> **Output:**
>
> ```python
> 3
> **Explanation: **The odd numbers between 3 and 7 are [3,5,7].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> low = 8, high = 10
> ```
>
> **Output:**
>
> ```python
> 1
> **Explanation: **The odd numbers between 8 and 10 are [9].
> ```

> [!warning]- Constraints
> - `0 <= low <= high <= 10^9`

---

### Hints:

> [!success]- Hint 1
> If the range (high - low + 1) is even, the number of even and odd numbers in this range will be the same.

> [!success]- Hint 2
> If the range (high - low + 1) is odd, the solution will depend on the parity of high and low.

> ```python
> class Solution:
>     def countOdds(self, low: int, high: int) -> int:
>
>         def isOdd(val) -> bool:
>             return val % 2 == 1
>
>         diff = high - low
>         result = ceil(diff / 2)
>         if isOdd(high) and isOdd(low) and (diff != 1):
>             result += 1
>         return result
> ```
