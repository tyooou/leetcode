### Problem Statement:

You are given a **0-indexed** 2D integer array of `events` where `events[i] = [startTime_i, endTime_i, value_i]`. The `i^th` event starts at `startTime_i`_ and ends at `endTime_i`, and if you attend this event, you will receive a value of `value_i`. You can choose **at most** **two** **non-overlapping** events to attend such that the sum of their values is **maximized**.

Return _this **maximum** sum._

Note that the start time and end time is **inclusive**: that is, you cannot attend two events where one of them starts and the other ends at the same time. More specifically, if you attend an event with end time `t`, the next event must start at or after `t + 1`.

> [!example]- Example 1
> **Input:**
>
> ```python
> events = [[1,3,2],[4,5,2],[2,4,3]]
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> Choose the green events, 0 and 1 for a sum of 2 + 2 = 4.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> events = [[1,3,2],[4,5,2],[1,5,5]]
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> Choose event 2 for a sum of 5.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> events = [[1,5,3],[1,5,1],[6,6,5]]
> ```
>
> **Output:**
>
> ```python
> 8
> ```
>
> **Explanation:**
>
> ```python
> Choose events 0 and 2 for a sum of 3 + 5 = 8.
> ```

> [!warning]- Constraints
> - `2 <= events.length <= 10^5`
>
> 	- `events[i].length == 3`
>
> 	- `1 <= startTime_i <= endTime_i <= 10^9`
>
> 	- `1 <= value_i <= 10^6`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `122 ms` | `55.8 MB` | `O(n log n)` | `O(1)` |
>
> ```python
> class Solution:
>
>     # can only be two events
>
>     def maxTwoEvents(self, events: List[List[int]]) -> int:
>
>         start_sorted = sorted(events, key=lambda x: x[0]) # sort by start time.
>         end_sorted = deque(sorted(events, key=lambda x: x[1])) # sort by end times.
>
>         ans = 0
>         end_max = 0
>
>         for start, end, val in start_sorted:
>             while end_sorted and end_sorted[0][1] < start:
>                 _, _, v = end_sorted.popleft()
>                 end_max = max(end_max, v)
>             ans = max(ans, val + end_max)
>
>         return ans
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
