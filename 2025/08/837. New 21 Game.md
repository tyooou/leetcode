### Problem Statement:

Alice plays the following game, loosely based on the card game **"21"**.

Alice starts with `0` points and draws numbers while she has less than `k` points. During each draw, she gains an integer number of points randomly from the range `[1, maxPts]`, where `maxPts` is an integer. Each draw is independent and the outcomes have equal probabilities.

Alice stops drawing numbers when she gets `k` **or more points**.

Return the probability that Alice has `n` or fewer points.

Answers within `10^-5` of the actual answer are considered accepted.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 10, k = 1, maxPts = 10
> ```
>
> **Output:**
>
> ```python
> 1.00000
> ```
>
> **Explanation:**
>
> ```python
> Alice gets a single card, then stops.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 6, k = 1, maxPts = 10
> ```
>
> **Output:**
>
> ```python
> 0.60000
> ```
>
> **Explanation:**
>
> ```python
> Alice gets a single card, then stops.
> In 6 out of 10 possibilities, she is at or below 6 points.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = 21, k = 17, maxPts = 10
> ```
>
> **Output:**
>
> ```python
> 0.73278
> ```

> [!warning]- Constraints
> - `0 <= k <= n <= 10^4`
>
> 	- `1 <= maxPts <= 10^4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `24 ms` | `18.2 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def new21Game(self, n: int, k: int, maxPts: int) -> float:
>         dp = [0] * (k + maxPts)
>         for s in range(k, k + maxPts):
>             dp[s] = 1 if s <= n else 0
>
>         window_sum = sum(dp[k : k + maxPts])
>
>         for s in range(k - 1, -1, -1):
>             dp[s] = window_sum / maxPts
>             window_sum = dp[s] + window_sum - dp[s + maxPts]
>
>         return dp[0]
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
