### Problem Statement:

You are given a string `num` representing a large integer. An integer is **good** if it meets the following conditions:
- It is a **substring** of `num` with length `3`.
- It consists of only one unique digit.
Return _the **maximum good** integer as a **string** or an empty string_ `""` _if no such integer exists_.
Note:
- A **substring** is a contiguous sequence of characters within a string.
- There may be **leading zeroes** in `num` or a good integer.

> [!example]- Example 1
> **Input:**
>
> ```python
> num = `"6777133339"`
> ```
>
> **Output:**
>
> ```python
> `"777"`
> ```
>
> **Explanation:**
>
> ```python
> There are two distinct good integers: `"777"` and `"333"`.
> `"777"` is the largest, so we return `"777"`.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> `num = "2300019"`
> ```
>
> **Output:**
>
> ```python
> `"000"`
> ```
>
> **Explanation:**
>
> ```python
> `"000"` is the only good integer.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> `num = "42352338"`
> ```
>
> **Output:**
>
> ```python
> `""`
> ```
>
> **Explanation:**
>
> ```python
> No substring of length 3 consists of only one unique digit. Therefore, there are no good integers.
> ```

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
> def largestGoodInteger(self, num: str) -> str:
> 	if not num or len(num) < 3:
> 		return ""
>
> 	n = len(num)
> 	uNum, count = -1, 1
> 	for i in range(1, n):
> 		if num[i - 1] == num[i]:
> 			count += 1
> 			if count == 3:
> 				uNum = max(int(num[i]), uNum)
> 		else:
> 			count = 1
> 	return str(uNum) * 3 if uNum >= 0 else ""
> ```

> [!success]- Reasoning
> 1. We exclude `num` that cannot make a substring with a fixed-width of three.
> 2. We find the a substrings of `num` with a fixed-width of three and consists of only one unique digit.
> 3. We return the one with the largest unique digit.
