### Problem Statement:

Given an integer `n`, return _`true` if it is a power of three. Otherwise, return `false`_.

An integer `n` is a power of three, if there exists an integer `x` such that `n == 3^x`.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 27
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> 27 = 3^3
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 0
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> There is no x where 3^x = 0.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> n = -1
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> There is no x where 3^x = (-1).
> ```

> [!warning]- Constraints
> - `-2^31 <= n <= 2^31 - 1`
>
>
>
> **Follow up:** Could you solve it without loops/recursion?

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4 ms` | `17.8 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def isPowerOfThree(self, n: int) -> bool:
>         count = 1
>         while count <= n:
>             if count == n:
>                 return True
>             count *= 3
>
>         return False
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
