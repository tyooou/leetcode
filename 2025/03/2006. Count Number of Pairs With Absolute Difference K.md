### Problem Statement:

Given an integer array `nums` and an integer `k`, return _the number of pairs_ `(i, j)` _where_ `i < j` _such that_ `|nums[i] - nums[j]| == k`.

The value of `|x|` is defined as:

	- `x` if `x >= 0`.

	- `-x` if `x < 0`.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,2,1], k = 1
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> The pairs with an absolute difference of 1 are:
> - [**1**,**2**,2,1]
> - [**1**,2,**2**,1]
> - [1,**2**,2,**1**]
> - [1,2,**2**,**1**]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,3], k = 3
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> There are no pairs with an absolute difference of 3.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [3,2,1,5,4], k = 2
> ```
>
> **Output:**
>
> ```python
> 3
> **Explanation:** The pairs with an absolute difference of 2 are:
> - [**3**,2,**1**,5,4]
> - [**3**,2,1,**5**,4]
> - [3,**2**,1,5,**4**]
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 200`
>
> 	- `1 <= nums[i] <= 100`
>
> 	- `1 <= k <= 99`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `18 MB` | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>     def countKDifference(self, nums: List[int], k: int) -> int:
>         myList = defaultdict(int)
>         count = 0
>
>         for num in nums:
>             count += myList[num - k] + myList[num + k]
>             myList[num] += 1
>
>         return count
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
