### Problem Statement:

Given a string `s`, find the length of the **longest** **substring** without duplicate characters.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "abcabcbb"
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The answer is "abc", with the length of 3. Note that `"bca"` and `"cab"` are also correct answers.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "bbbbb"
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> The answer is "b", with the length of 1.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "pwwkew"
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The answer is "wke", with the length of 3.
> Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.
> ```

> [!warning]- Constraints
> - `0 <= s.length <= 10^5`
>
> 	- `s` consists of English letters, digits, symbols and spaces.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `15 ms` | `17.8 MB` | `*(fill in)*` | `*(fill in)*` |
>
> ```python
> class Solution:
>     def lengthOfLongestSubstring(self, s: str) -> int:
>         left = 0
>         seen = {}
>         output = 0
>
>         for right, curr in enumerate(s):
>             if curr in seen:
>                 left = max(left, seen[curr] + 1)
>             output = max(output, right - left + 1)
>             seen[curr] = right
>
>         return output
> ```
