### Problem Statement:

A bus has `n` stops numbered from `0` to `n - 1` that form a circle. We know the distance between all pairs of neighboring stops where `distance[i]` is the distance between the stops number `i` and `(i + 1) % n`.

The bus goes along both directions i.e. clockwise and counterclockwise.

Return the shortest distance between the given `start` and `destination` stops.

> [!example]- Example 1
> **Input:**
>
> ```python
> distance = [1,2,3,4], start = 0, destination = 1
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> Distance between 0 and 1 is 1 or 9, minimum is 1.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> distance = [1,2,3,4], start = 0, destination = 2
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> Distance between 0 and 2 is 3 or 7, minimum is 3.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> distance = [1,2,3,4], start = 0, destination = 3
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> Distance between 0 and 3 is 6 or 4, minimum is 4.
> ```

> [!warning]- Constraints
> - `1 <= n <= 10^4`
>
> 	- `distance.length == n`
>
> 	- `0 <= start, destination < n`
>
> 	- `0 <= distance[i] <= 10^4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `56 ms` | `18.6 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def distanceBetweenBusStops(self, distance: List[int], start: int, destination: int) -> int:
>         a = min(start, destination)
>         b = max(start, destination)
>
>         return min(sum(distance[a:b]), sum(distance) - sum(distance[a:b]))
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
