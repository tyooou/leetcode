### Problem Statement:

Given a string `s`, return `true`_ if _`s`_ is a **good** string, or _`false`_ otherwise_.

A string `s` is **good** if **all** the characters that appear in `s` have the **same** number of occurrences (i.e., the same frequency).

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "abacbc"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The characters that appear in s are 'a', 'b', and 'c'. All characters occur 2 times in s.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "aaabb"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The characters that appear in s are 'a' and 'b'.
> 'a' occurs 3 times while 'b' occurs 2 times, which is not the same number of times.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 1000`
>
> 	- `s` consists of lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Build a dictionary containing the frequency of each character appearing in s

> [!success]- Hint 2
> Check if all values in the dictionary are the same.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `17.7 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def areOccurrencesEqual(self, s: str) -> bool:
>         myList = {}
>
>         for i in range(len(s)):
>             myList[s[i]] = 1 + myList.get(s[i], 0)
>
>         for key in myList:
>             if myList[key] != myList[s[0]]:
>                 return False
>
>         return True
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
