### Problem Statement:

Given two **0-indexed** integer arrays `nums1` and `nums2`, return _a list_ `answer` _of size_ `2` _where:_

	- `answer[0]` _is a list of all **distinct** integers in_ `nums1` _which are **not** present in_ `nums2`_._

	- `answer[1]` _is a list of all **distinct** integers in_ `nums2` _which are **not** present in_ `nums1`.

**Note** that the integers in the lists may be returned in **any** order.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums1 = [1,2,3], nums2 = [2,4,6]
> ```
>
> **Output:**
>
> ```python
> [[1,3],[4,6]]
> ```
>
> **Explanation:**
>
> ```python
> For nums1, nums1[1] = 2 is present at index 0 of nums2, whereas nums1[0] = 1 and nums1[2] = 3 are not present in nums2. Therefore, answer[0] = [1,3].
> For nums2, nums2[0] = 2 is present at index 1 of nums1, whereas nums2[1] = 4 and nums2[2] = 6 are not present in nums1. Therefore, answer[1] = [4,6].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums1 = [1,2,3,3], nums2 = [1,1,2,2]
> ```
>
> **Output:**
>
> ```python
> [[3],[]]
> ```
>
> **Explanation:**
>
> ```python
> For nums1, nums1[2] and nums1[3] are not present in nums2. Since nums1[2] == nums1[3], their value is only included once and answer[0] = [3].
> Every integer in nums2 is present in nums1. Therefore, answer[1] = [].
> ```

> [!warning]- Constraints
> - `1 <= nums1.length, nums2.length <= 1000`
>
> 	- `-1000 <= nums1[i], nums2[i] <= 1000`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `330 ms` | `18.1 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
>         myList1 = [i for i in nums1 if i not in nums2]
>         myList2 = [j for j in nums2 if j not in nums1]
>
>         return [list(set(myList1)), list(set(myList2))]
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
