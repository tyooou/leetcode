### Problem Statement:

Two strings are considered **close** if you can attain one from the other using the following operations:

	- Operation 1: Swap any two **existing** characters.

		For example, `abcde -> aecdb`

	- Operation 2: Transform **every** occurrence of one **existing** character into another **existing** character, and do the same with the other character.

		For example, `aacabb -> bbcbaa` (all `a`'s turn into `b`'s, and all `b`'s turn into `a`'s)

You can use the operations on either string as many times as necessary.

Given two strings, `word1` and `word2`, return `true`_ if _`word1`_ and _`word2`_ are **close**, and _`false`_ otherwise._

> [!example]- Example 1
> **Input:**
>
> ```python
> word1 = "abc", word2 = "bca"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> You can attain word2 from word1 in 2 operations.
> Apply Operation 1: "abc" -> "acb"
> Apply Operation 1: "acb" -> "bca"
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> word1 = "a", word2 = "aa"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> It is impossible to attain word2 from word1, or vice versa, in any number of operations.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> word1 = "cabbba", word2 = "abbccc"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> You can attain word2 from word1 in 3 operations.
> Apply Operation 1: "cabbba" -> "caabbb"
> Apply Operation 2: "caabbb" -> "baaccc"
> Apply Operation 2: "baaccc" -> "abbccc"
> ```

> [!warning]- Constraints
> - `1 <= word1.length, word2.length <= 10^5`
>
> 	- `word1` and `word2` contain only lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Operation 1 allows you to freely reorder the string.

> [!success]- Hint 2
> Operation 2 allows you to freely reassign the letters' frequencies.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `211 ms` | `18.2 MB` | `O(n log n)` | `O(n)` |
>
> ```python
> class Solution:
>     def closeStrings(self, word1: str, word2: str) -> bool:
>         n, m = len(word1), len(word2)
>         dict1, dict2 = defaultdict(int), defaultdict(int)
>
>         if n != m:
>             return False
>
>         for i in range(n):
>             c1, c2 = word1[i], word2[i]
>             dict1[c1] = dict1.get(c1, 0) + 1
>             dict2[c2] = dict2.get(c2, 0) + 1
>
>         if set(dict1.keys()) == set(dict2.keys()):
>             if sorted(dict1.values()) == sorted(dict2.values()):
>                 return True
>         return False
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
