### Problem Statement:

You are given an array of strings `words` and a string `pref`.

Return _the number of strings in _`words`_ that contain _`pref`_ as a **prefix**_.

A **prefix** of a string `s` is any leading contiguous substring of `s`.

> [!example]- Example 1
> **Input:**
>
> ```python
> words = ["pay","**at**tention","practice","**at**tend"], `pref `= "at"
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The 2 strings that contain "at" as a prefix are: "**at**tention" and "**at**tend".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> words = ["leetcode","win","loops","success"], `pref `= "code"
> ```
>
> **Output:**
>
> ```python
> 0
> ```
>
> **Explanation:**
>
> ```python
> There are no strings that contain "code" as a prefix.
> ```

> [!warning]- Constraints
> - `1 <= words.length <= 100`
>
> 	- `1 <= words[i].length, pref.length <= 100`
>
> 	- `words[i]` and `pref` consist of lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Go through each word in words and increment the answer if pref is a prefix of the word.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `1 ms` | `17.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def prefixCount(self, words: List[str], pref: str) -> int:
>         p = len(pref); res = 0
>         for word in words:
>             if len(word) < p:
>                 continue
>
>             count = 0
>             for i in range(p):
>                 if word[i] != pref[i]:
>                     break
>                 count += 1
>             if count == p:
>                 res += 1
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
