### Problem Statement:

You are given a string `s`, which contains stars `*`.

In one operation, you can:

	- Choose a star in `s`.

	- Remove the closest **non-star** character to its **left**, as well as remove the star itself.

Return _the string after **all** stars have been removed_.

**Note:**

	- The input will be generated such that the operation is always possible.

	- It can be shown that the resulting string will always be unique.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "leet**cod*e"
> ```
>
> **Output:**
>
> ```python
> "lecoe"
> ```
>
> **Explanation:**
>
> ```python
> Performing the removals from left to right:
> - The closest character to the 1^st star is 't' in "lee**t****cod*e". s becomes "lee*cod*e".
> - The closest character to the 2^nd star is 'e' in "le**e***cod*e". s becomes "lecod*e".
> - The closest character to the 3^rd star is 'd' in "leco**d***e". s becomes "lecoe".
> There are no more stars, so we return "lecoe".
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "erase*****"
> ```
>
> **Output:**
>
> ```python
> ""
> ```
>
> **Explanation:**
>
> ```python
> The entire string is removed, so we return an empty string.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 10^5`
>
> 	- `s` consists of lowercase English letters and stars `*`.
>
> 	- The operation above can be performed on `s`.

> class Solution:
>     def removeStars(self, s: str) -> str:
>         n, skip = len(s), 0
>         res = ""
>         for i in range(n - 1, -1, -1):
>             e = s[i]
>             if e == "*":
>                 skip += 1
>             elif (skip):
>                 skip -= 1
>             else:
>                 res += e
>
>         return res[::-1]
