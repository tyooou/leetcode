### Problem Statement:

Given an integer `n`, return all the numbers in the range `[1, n]` sorted in lexicographical order.

You must write an algorithm that runs in `O(n)` time and uses `O(1)` extra space.

> [!example]- Example 1
> **Input:**
>
> ```python
> n = 13
> ```
>
> **Output:**
>
> ```python
> [1,10,11,12,13,2,3,4,5,6,7,8,9]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> n = 2
> ```
>
> **Output:**
>
> ```python
> [1,2]
> ```

> [!warning]- Constraints
> - `1 <= n <= 5 * 10^4`
