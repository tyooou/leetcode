### Problem Statement:

Given a **0-indexed** `n x n` integer matrix `grid`, _return the number of pairs _`(r_i, c_j)`_ such that row _`r_i`_ and column _`c_j`_ are equal_.

A row and column pair is considered equal if they contain the same elements in the same order (i.e., an equal array).

> [!example]- Example 1
> **Input:**
>
> ```python
> grid = [[3,2,1],[1,7,6],[2,7,7]]
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> There is 1 equal row and column pair:
> - (Row 2, Column 1): [2,7,7]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> There are 3 equal row and column pairs:
> - (Row 0, Column 0): [3,1,2,2]
> - (Row 2, Column 2): [2,4,2,2]
> - (Row 3, Column 2): [2,4,2,2]
> ```

> [!warning]- Constraints
> - `n == grid.length == grid[i].length`
>
> 	- `1 <= n <= 200`
>
> 	- `1 <= grid[i][j] <= 10^5`

### Hints:

> [!success]- Hint 1
> We can use nested loops to compare every row against every column.

> [!success]- Hint 2
> Another loop is necessary to compare the row and column element by element.

> [!success]- Hint 3
> It is also possible to hash the arrays and compare the hashed values instead.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `19 ms` | `21.8 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def equalPairs(self, grid: List[List[int]]) -> int:
>         n, res = len(grid), 0
>         count = defaultdict(int)
>         for g in grid:
>             t = tuple(g)
>             count[t] = count.get(t, 0) + 1
>
>         for col in range(n):
>             target = tuple([row[col] for row in grid])
>             if count[target]:
>                 res += count[target]
>
>         return res
>
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
