### Problem Statement:

You are given an integer array `nums` consisting of `n` elements, and an integer `k`.

Find a contiguous subarray whose **length is equal to** `k` that has the maximum average value and return _this value_. Any answer with a calculation error less than `10^-5` will be accepted.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,12,-5,-6,50,3], k = 4
> ```
>
> **Output:**
>
> ```python
> 12.75000
> ```
>
> **Explanation:**
>
> ```python
> Maximum average is (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [5], k = 1
> ```
>
> **Output:**
>
> ```python
> 5.00000
> ```

> [!warning]- Constraints
> - `n == nums.length`
>
> 	- `1 <= k <= n <= 10^5`
>
> 	- `-10^4 <= nums[i] <= 10^4`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `91 ms` | `27.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def findMaxAverage(self, nums: List[int], k: int) -> float:
>         n = len(nums)
>         l, r = 0, k - 1
>         currRes = sum(nums[l:r + 1])
>         maxRes = currRes
>
>
>
>         while r < n - 1:
>             currRes = currRes - nums[l] + nums[r + 1]
>             maxRes = max(maxRes, currRes)
>             l += 1
>             r = l + k - 1
>
>         print(l, r)
>         return maxRes / k
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
