### Problem Statement:

Given a string `s` and an integer `k`, return _the maximum number of vowel letters in any substring of _`s`_ with length _`k`.

**Vowel letters** in English are `'a'`, `'e'`, `'i'`, `'o'`, and `'u'`.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "abciiidef", k = 3
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> The substring "iii" contains 3 vowel letters.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "aeiou", k = 2
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Any substring of length 2 contains 2 vowels.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = "leetcode", k = 3
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> "lee", "eet" and "ode" contain 2 vowels.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 10^5`
>
> 	- `s` consists of lowercase English letters.
>
> 	- `1 <= k <= s.length`

### Hints:

> [!success]- Hint 1
> Keep a window of size k and maintain the number of vowels in it.

> [!success]- Hint 2
> Keep moving the window and update the number of vowels while moving. Answer is max number of vowels of any window.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `73 ms` | `18 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxVowels(self, s: str, k: int) -> int:
>         vowels = {'a', 'e', 'i', 'o', 'u'}
>         n = len(s)
>         l, r = 0, k
>         maxCount, count = 0, 0
>         for e in s[l:r]:
>             if e in vowels:
>                 count += 1
>
>         maxCount = count
>         while r < n:
>             if s[l] in vowels:
>                 count -= 1
>             if s[r] in vowels:
>                 count += 1
>             maxCount = max(maxCount, count)
>             l += 1
>             r += 1
>         return maxCount
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
