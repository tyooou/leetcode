### Problem Statement:

Given a binary array `nums`, you should delete one element from it.

Return _the size of the longest non-empty subarray containing only _`1`_'s in the resulting array_. Return `0` if there is no such subarray.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,1,0,1]
> ```
>
> **Output:**
>
> ```python
> 3
> ```
>
> **Explanation:**
>
> ```python
> After deleting the number in position 2, [1,1,1] contains 3 numbers with value of 1's.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [0,1,1,1,0,1,1,0,1]
> ```
>
> **Output:**
>
> ```python
> 5
> ```
>
> **Explanation:**
>
> ```python
> After deleting the number in position 4, [0,1,1,1,1,1,0,1] longest subarray with value of 1's is [1,1,1,1,1].
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> nums = [1,1,1]
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> You must delete one element.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `nums[i]` is either `0` or `1`.

> ```python
> class Solution:
>     def longestSubarray(self, nums: List[int]) -> int:
>         n = len(nums)
>         zeros, maxRes = 0, 0
>         l, r = 0, 0
>
>         while r < n:
>             if not nums[r]:
>                 zeros += 1
>
>             while zeros > 1:
>                 if not nums[l]:
>                     zeros -= 1
>                 l += 1
>
>             maxRes = max(maxRes, r - l)
>             r += 1
>         return maxRes
>
>

> ```
