### Problem Statement:

Given an array of integers `arr`, return `true` _if the number of occurrences of each value in the array is **unique** or _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> arr = [1,2,2,1,1,3]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The value 1 has 3 occurrences, 2 has 2 and 3 has 1. No two values have the same number of occurrences.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> arr = [1,2]
> ```
>
> **Output:**
>
> ```python
> false
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> arr = [-3,0,1,-3,1,1,1,-3,10,0]
> ```
>
> **Output:**
>
> ```python
> true
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 1000`
>
> 	- `-1000 <= arr[i] <= 1000`

> [!example]+ Submission

>
> ```python
> class Solution:
>     def uniqueOccurrences(self, arr: List[int]) -> bool:
>         myList = defaultdict(int)
>         for a in arr:
>             myList[a] = myList.get(a, 0) + 1
>
>         return len(set(myList.values())) == len(myList.values())
>
> ```
