### Problem Statement:

You are given an integer array `nums` and an integer `k`.

In one operation, you can pick two numbers from the array whose sum equals `k` and remove them from the array.

Return _the maximum number of operations you can perform on the array_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,4], k = 5
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> Starting with nums = [1,2,3,4]:
> - Remove numbers 1 and 4, then nums = [2,3]
> - Remove numbers 2 and 3, then nums = []
> There are no more pairs that sum up to 5, hence a total of 2 operations.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [3,1,3,4,3], k = 6
> ```
>
> **Output:**
>
> ```python
> 1
> ```
>
> **Explanation:**
>
> ```python
> Starting with nums = [3,1,3,4,3]:
> - Remove the first two 3's, then nums = [1,4,3]
> There are no more pairs that sum up to 6, hence a total of 1 operation.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 10^5`
>
> 	- `1 <= nums[i] <= 10^9`
>
> 	- `1 <= k <= 10^9`

### Hints:

> [!success]- Hint 1
> The abstract problem asks to count the number of disjoint pairs with a given sum k.

> [!success]- Hint 2
> For each possible value x, it can be paired up with k - x.

> [!success]- Hint 3
> The number of such pairs equals to  min(count(x), count(k-x)), unless that x = k / 2, where the number of such pairs will be floor(count(x) / 2).

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `513 ms` | `29.8 MB` | `O(n²)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxOperations(self, nums: List[int], k: int) -> int:
>         n = len(nums)
>         l, r = 0, n - 1
>         count = 0
>
>         nums.sort()
>
>         while l < r:
>             while (l < r and nums[l] + nums[r] != k):
>                 while (l < r and nums[l] + nums[r] > k):
>                     r -= 1
>                 while (l < r and nums[l] + nums[r] < k):
>                     l += 1
>
>             if (l >= r):
>                 break
>             count += 1
>             l += 1
>             r -= 1
>
>         return count
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Sorting enables efficient processing
