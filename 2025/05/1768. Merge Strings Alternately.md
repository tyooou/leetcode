### Problem Statement:

You are given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with `word1`. If a string is longer than the other, append the additional letters onto the end of the merged string.

Return _the merged string._

> [!example]- Example 1
> **Input:**
>
> ```python
> word1 = "abc", word2 = "pqr"
> ```
>
> **Output:**
>
> ```python
> "apbqcr"
> ```
>
> **Explanation:**
>
> ```python
> The merged string will be merged as so:
> word1:  a   b   c
> word2:    p   q   r
> merged: a p b q c r
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> word1 = "ab", word2 = "pqrs"
> ```
>
> **Output:**
>
> ```python
> "apbqrs"
> ```
>
> **Explanation:**
>
> ```python
> Notice that as word2 is longer, "rs" is appended to the end.
> word1:  a   b
> word2:    p   q   r   s
> merged: a p b q   r   s
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> word1 = "abcd", word2 = "pq"
> ```
>
> **Output:**
>
> ```python
> "apbqcd"
> ```
>
> **Explanation:**
>
> ```python
> Notice that as word1 is longer, "cd" is appended to the end.
> word1:  a   b   c   d
> word2:    p   q
> merged: a p b q c   d
> ```

> [!warning]- Constraints
> - `1 <= word1.length, word2.length <= 100`
>
> 	- `word1` and `word2` consist of lowercase English letters.

---

### Hints:

> [!success]- Hint 1
> Use two pointers, one pointer for each string. Alternately choose the character from each pointer, and move the pointer upwards.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `35 ms` | `17.9 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def mergeAlternately(self, word1: str, word2: str) -> str:
>         res, count = "", 0
>         n, m = len(word1), len(word2)
>         while (count < n and count < m):
>             res += word1[count]
>             res += word2[count]
>             count += 1
>
>         if (count >= n and count < m):
>             res += word2[count:]
>         elif (count < n and count >= m):
>             res += word1[count:]
>         return res
>
>
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
