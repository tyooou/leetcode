### Problem Statement:

Given a string `s`, reverse only all the vowels in the string and return it.

The vowels are `'a'`, `'e'`, `'i'`, `'o'`, and `'u'`, and they can appear in both lower and upper cases, more than once.

> [!example]- Example 1
> **Input:** s = "IceCreAm"
>
> **Output:** "AceCreIm"
>
> **Explanation:**
>
> The vowels in `s` are `['I', 'e', 'e', 'A']`. On reversing the vowels, s becomes `"AceCreIm"`.

> [!example]- Example 2
> **Input:** s = "leetcode"
>
> **Output:** "leotcede"

> [!warning]- Constraints
> - `1 <= s.length <= 3 * 10^5`
>
> 	- `s` consist of **printable ASCII** characters.

> class Solution:
>     def reverseVowels(self, s: str) -> str:
>         vowels = ['a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U',]
>         mut = list(s)
>         l, r = 0, len(mut) - 1
>         while (l < r):
>             while (l < r and mut[l] not in vowels):
>                 l += 1
>             while (l < r and mut[r] not in vowels):
>                 r -= 1
>
>             if (l < r):
>                 temp = mut[l]
>                 mut[l] = mut[r]
>                 mut[r] = temp
>                 r -= 1
>                 l += 1
>
>         return "".join(mut)
>
