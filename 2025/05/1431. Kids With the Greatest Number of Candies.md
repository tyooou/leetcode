### Problem Statement:

There are `n` kids with candies. You are given an integer array `candies`, where each `candies[i]` represents the number of candies the `i^th` kid has, and an integer `extraCandies`, denoting the number of extra candies that you have.

Return _a boolean array _`result`_ of length _`n`_, where _`result[i]`_ is _`true`_ if, after giving the _`i^th`_ kid all the _`extraCandies`_, they will have the **greatest** number of candies among all the kids__, or _`false`_ otherwise_.

Note that **multiple** kids can have the **greatest** number of candies.

> [!example]- Example 1
> **Input:**
>
> ```python
> candies = [2,3,5,1,3], extraCandies = 3
> ```
>
> **Output:**
>
> ```python
> [true,true,true,false,true]
> ```
>
> **Explanation:**
>
> ```python
> If you give all extraCandies to:
> - Kid 1, they will have 2 + 3 = 5 candies, which is the greatest among the kids.
> - Kid 2, they will have 3 + 3 = 6 candies, which is the greatest among the kids.
> - Kid 3, they will have 5 + 3 = 8 candies, which is the greatest among the kids.
> - Kid 4, they will have 1 + 3 = 4 candies, which is not the greatest among the kids.
> - Kid 5, they will have 3 + 3 = 6 candies, which is the greatest among the kids.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> candies = [4,2,1,1,2], extraCandies = 1
> ```
>
> **Output:**
>
> ```python
> [true,false,false,false,false]
> ```
>
> **Explanation:**
>
> ```python
> There is only 1 extra candy.
> Kid 1 will always have the greatest number of candies, even if a different kid is given the extra candy.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> candies = [12,1,12], extraCandies = 10
> ```
>
> **Output:**
>
> ```python
> [true,false,true]
> ```

> [!warning]- Constraints
> - `n == candies.length`
>
> 	- `2 <= n <= 100`
>
> 	- `1 <= candies[i] <= 100`
>
> 	- `1 <= extraCandies <= 50`

>
> ```python
> class Solution:
>     def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
>         res = [False] * len(candies)
>         maxCandies = sorted(candies)[-1]
>
>         for kid, candy in enumerate(candies):
>             if (candy + extraCandies) >= maxCandies:
>                 res[kid] = True
>         return res
>
> ```
