### Problem Statement:

Given an integer array `nums`, return `true` _if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,5,11,5]
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> The array can be partitioned as [1, 5, 5] and [11].
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [1,2,3,5]
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The array cannot be partitioned into equal sum subsets.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 200`
>
> 	- `1 <= nums[i] <= 100`

> ```python
> class Solution:
>     def canPartition(self, nums: List[int]) -> bool:
>         total = sum(nums)
>         if total % 2:
>             return False
>         target = total // 2
>
>         stack = [0]
>         for ele in nums:
>             new = set()
>             for ele2 in stack:
>                 res = ele + ele2
>                 if res == target:
>                     return True
>                 elif res < target:
>                     new.add(res)
>                 new.add(ele2)
>             stack = list(new)
>         return False
> ```
