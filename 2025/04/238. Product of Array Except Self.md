### Problem Statement:

Given an integer array `nums`, return _an array_ `answer` _such that_ `answer[i]` _is equal to the product of all the elements of_ `nums` _except_ `nums[i]`.

The product of any prefix or suffix of `nums` is **guaranteed** to fit in a **32-bit** integer.

You must write an algorithm that runs in `O(n)` time and without using the division operation.

> [!example]- Example 1
> **Input:**
>
> ```python
> nums = [1,2,3,4]
> ```
>
> **Output:**
>
> ```python
> [24,12,8,6]
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> nums = [-1,1,0,-3,3]
> ```
>
> **Output:**
>
> ```python
> [0,0,9,0,0]
> ```

> [!warning]- Constraints
> - `2 <= nums.length <= 10^5`
>
> 	- `-30 <= nums[i] <= 30`
>
> 	- The input is generated such that `answer[i]` is **guaranteed** to fit in a **32-bit** integer.
>
>
>
> **Follow up:** Can you solve the problem in `O(1)` extra space complexity? (The output array **does not** count as extra space for space complexity analysis.)

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `23 ms` | `23.9 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution:
>     def productExceptSelf(self, nums: List[int]) -> List[int]:
>         res = 1
>         catch = 1
>         for num in nums:
>             if (num == 0 and catch == 1):
>                 catch = 0
>             else:
>                 res *= num
>
>         myList = [res] * len(nums)
>         for idx, num in enumerate(nums):
>             myList[idx] = (res // num) * catch if (num != 0) else res
>
>
>         return myList
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
