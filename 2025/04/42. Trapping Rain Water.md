### Problem Statement:

Given `n` non-negative integers representing an elevation map where the width of each bar is `1`, compute how much water it can trap after raining.

> [!example]- Example 1
> **Input:**
>
> ```python
> height = [0,1,0,2,1,0,1,3,2,1,2,1]
> ```
>
> **Output:**
>
> ```python
> 6
> ```
>
> **Explanation:**
>
> ```python
> The above elevation map (black section) is represented by array [0,1,0,2,1,0,1,3,2,1,2,1]. In this case, 6 units of rain water (blue section) are being trapped.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> height = [4,2,0,3,2,5]
> ```
>
> **Output:**
>
> ```python
> 9
> ```

> [!warning]- Constraints
> - `n == height.length`
>
> 	- `1 <= n <= 2 * 10^4`
>
> 	- `0 <= height[i] <= 10^5`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `17 ms` | `19.3 MB` | `O(n²)` | `O(1)` |
>
> ```python
> class Solution:
>     def trap(self, height: List[int]) -> int:
>         l, r = 0, len(height) - 1
>         level, res = 0, 0
>
>         while (l < r):
>             while (l < len(height) and l < r and height[l] <= level):
>                 if (height[l] < level):
>                     res += (level - height[l])
>                 l += 1
>
>             while (r > 0 and l < r and height[r] <= level):
>                 if (height[r] < level):
>                     res += (level - height[r])
>                 r -= 1
>
>             level += 1
>         return res
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
