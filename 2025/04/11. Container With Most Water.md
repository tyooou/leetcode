### Problem Statement:

You are given an integer array `height` of length `n`. There are `n` vertical lines drawn such that the two endpoints of the `i^th` line are `(i, 0)` and `(i, height[i])`.

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return _the maximum amount of water a container can store_.

**Notice** that you may not slant the container.

> [!example]- Example 1
> **Input:**
>
> ```python
> height = [1,8,6,2,5,4,8,3,7]
> ```
>
> **Output:**
>
> ```python
> 49
> ```
>
> **Explanation:**
>
> ```python
> The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water (blue section) the container can contain is 49.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> height = [1,1]
> ```
>
> **Output:**
>
> ```python
> 1
> ```

> [!warning]- Constraints
> - `n == height.length`
>
> 	- `2 <= n <= 10^5`
>
> 	- `0 <= height[i] <= 10^4`

### Hints:

> [!success]- Hint 1
> If you simulate the problem, it will be O(n^2) which is not efficient.

> [!success]- Hint 2
> Try to use two-pointers. Set one pointer to the left and one to the right of the array. Always move the pointer that points to the lower line.

> [!success]- Hint 3
> How can you calculate the amount of water at each step?

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `65 ms` | `28.5 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def maxArea(self, height: List[int]) -> int:
>         l, r = 0, len(height) - 1 # indexes of the left and right sides
>         maxA = 0
>
>         while l < r:
>             currH = min(height[l], height[r])
>             currA = currH * (r - l)
>             if maxA < currA:
>                 maxA = currA
>
>             if height[l] > height[r]:
>                 r -= 1
>             else:
>                 l += 1
>         return maxA
>
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
