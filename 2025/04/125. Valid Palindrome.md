### Problem Statement:

A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

Given a string `s`, return `true`_ if it is a **palindrome**, or _`false`_ otherwise_.

> [!example]- Example 1
> **Input:**
>
> ```python
> s = "A man, a plan, a canal: Panama"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> "amanaplanacanalpanama" is a palindrome.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> s = "race a car"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> "raceacar" is not a palindrome.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> s = " "
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> s is an empty string "" after removing non-alphanumeric characters.
> Since an empty string reads the same forward and backward, it is a palindrome.
> ```

> [!warning]- Constraints
> - `1 <= s.length <= 2 * 10^5`
>
> 	- `s` consists only of printable ASCII characters.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `4 ms` | `18.3 MB` | `O(n)` | `O(1)` |
>
> ```python
> class Solution:
>     def isPalindrome(self, s: str) -> bool:
>         s = "".join(char for char in s if char.isalnum()).lower()
>         if (len(s) <= 1):
>             return True
>         l, r, count = 0, len(s) - 1, 0
>         while (s[l] == s[r] and l < r):
>             count += 1
>             l += 1
>             r -= 1
>         return len(s) // 2 == count
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
