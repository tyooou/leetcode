### Problem Statement:

You are given a positive integer `num` consisting only of digits `6` and `9`.
Return _the maximum number you can get by changing **at most** one digit (_`6` _becomes_ `9`_, and_ `9` _becomes_ `6`_)_.

> [!example]- Example 1
> **Input:**
>
> ```python
> num = 9669
> ```
>
> **Output:**
>
> ```python
> 9969
> ```
>
> **Explanation:**
>
> ```python
> Changing the first digit results in 6669.
> Changing the second digit results in 9969.
> Changing the third digit results in 9699.
> Changing the fourth digit results in 9666.
> The maximum number is 9969.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> num = 9996
> ```
>
> **Output:**
>
> ```python
> 9999
> ```
>
> **Explanation:**
>
> ```python
> Changing the last digit 6 to 9 results in the maximum number.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> num = 9999
> ```
>
> **Output:**
>
> ```python
> 9999
> ```
>
> **Explanation:**
>
> ```python
> It is better not to apply any change.
> ```

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | — | — | `O(n)` | `O(n)` |
>
> ```python
> class Solution:
>
> def maximum69Number (self, num: int) -> int:
> 	sNum = str(num)
> 	idx = sNum.index("6") if "6" in sNum else -1
>
> 	if idx >= 0:
> 		sNum = sNum[:idx] + "9" + sNum[idx + 1:]
>
> 	return int(sNum)
> ```

> [!success]- Reasoning
> 1. Convert `num` to string to allow indexing.
> 2. Find the first occurrence of six (if any), and replace it with 9.
