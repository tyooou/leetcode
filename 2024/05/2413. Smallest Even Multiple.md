### Problem Statement:

Given a **positive** integer `n`, return _the smallest positive integer that is a multiple of **both** _`2`_ and _`n`.

> [!example]- Example 1
> **Input:**
>
> ```scala
> n = 5
> ```
>
> **Output:**
>
> ```scala
> 10
> ```
>
> **Explanation:**
>
> ```scala
> The smallest multiple of both 5 and 2 is 10.
> ```

> [!example]- Example 2
> **Input:**
>
> ```scala
> n = 6
> ```
>
> **Output:**
>
> ```scala
> 6
> ```
>
> **Explanation:**
>
> ```scala
> The smallest multiple of both 6 and 2 is 6. Note that a number is a multiple of itself.
> ```

> [!warning]- Constraints
> - `1 <= n <= 150`

---

### Hints:

> [!success]- Hint 1
> A guaranteed way to find a multiple of 2 and n is to multiply them together. When is this the answer, and when is there a smaller answer?

> [!success]- Hint 2
> There is a smaller answer when n is even.

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `509 ms` | `53.7 MB` | `O(n)` | `O(1)` |
>
> ```scala
> object Solution {
>     def smallestEvenMultiple(n: Int): Int = {
>             if (n % 2 == 0) {
>                 return n
>             }
>             return n * 2
>         }
>     }
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
