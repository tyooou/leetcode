### Problem Statement:

Given two integers `num1` and `num2`, return _the **sum** of the two integers_.

> [!example]- Example 1
> **Input:**
>
> ```racket
> num1 = 12, num2 = 5
> ```
>
> **Output:**
>
> ```racket
> 17
> ```
>
> **Explanation:**
>
> ```racket
> num1 is 12, num2 is 5, and their sum is 12 + 5 = 17, so 17 is returned.
> ```

> [!example]- Example 2
> **Input:**
>
> ```racket
> num1 = -10, num2 = 4
> ```
>
> **Output:**
>
> ```racket
> -6
> ```
>
> **Explanation:**
>
> ```racket
> num1 + num2 = -6, so -6 is returned.
> ```

> [!warning]- Constraints
> - `-100 <= num1, num2 <= 100`

---

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `208 ms` | `100.1 MB` | `O(n)` | `O(1)` |
>
> ```racket
> (define/contract (sum num1 num2)
>   (-> exact-integer? exact-integer? exact-integer?)
>   (+ (+ num1) num2)
>   )
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
