### Problem Statement:

You are given an integer array `nums`. You need to create a 2D array from `nums` satisfying the following conditions:

	- The 2D array should contain **only** the elements of the array `nums`.

	- Each row in the 2D array contains **distinct** integers.

	- The number of rows in the 2D array should be **minimal**.

Return _the resulting array_. If there are multiple answers, return any of them.

**Note** that the 2D array can have a different number of elements on each row.

> [!example]- Example 1
> **Input:**
>
> ```java
> nums = [1,3,4,1,2,3,1]
> ```
>
> **Output:**
>
> ```java
> [[1,3,4,2],[1,3],[1]]
> ```
>
> **Explanation:**
>
> ```java
> We can create a 2D array that contains the following rows:
> - 1,3,4,2
> - 1,3
> - 1
> All elements of nums were used, and each row of the 2D array contains distinct integers, so it is a valid answer.
> It can be shown that we cannot have less than 3 rows in a valid array.
> ```

> [!example]- Example 2
> **Input:**
>
> ```java
> nums = [1,2,3,4]
> ```
>
> **Output:**
>
> ```java
> [[4,3,2,1]]
> ```
>
> **Explanation:**
>
> ```java
> All elements of the array are distinct, so we can keep all of them in the first row of the 2D array.
> ```

> [!warning]- Constraints
> - `1 <= nums.length <= 200`
>
> 	- `1 <= nums[i] <= nums.length`

### Hints:

> [!success]- Hint 1
> Process the elements in the array one by one in any order and only create a new row in the matrix when we cannot put it into the existing rows

> [!success]- Hint 2
> We can simply iterate over the existing rows of the matrix to see if we can place each element.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `3 ms` | `45.1 MB` | `O(n²)` | `O(n)` |
>
> ```java
> class Solution {
>     public List<List<Integer>> findMatrix(int[] nums) {
>         List<List<Integer>> poop = new ArrayList<>();
>         for (int num : nums) {
>             boolean done = false;
>             for (List<Integer> array : poop) {
>                 if (!array.contains(num) && !done) {
>                     array.add(num);
>                     done = true;
>                 }
>             }
>
>             if (!done) {
>                 List<Integer> poopy = new ArrayList<Integer>();
>                 poopy.add(num);
>                 poop.add(poopy);
>             }
>         }
>         return poop;
>     }
> }
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
