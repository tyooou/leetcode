### Problem Statement:

Given an integer array `arr`, return `true` if there are three consecutive odd numbers in the array. Otherwise, return `false`.

> [!example]- Example 1
> **Input:**
>
> ```java
> arr = [2,6,4,1]
> ```
>
> **Output:**
>
> ```java
> false
> **Explanation:** There are no three consecutive odds.
> ```

> [!example]- Example 2
> **Input:**
>
> ```java
> arr = [1,2,34,3,4,5,7,23,12]
> ```
>
> **Output:**
>
> ```java
> true
> **Explanation:** [5,7,23] are three consecutive odds.
> ```

> [!warning]- Constraints
> - `1 <= arr.length <= 1000`
>
> 	- `1 <= arr[i] <= 1000`

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `42.1 MB` | `O(n)` | `O(1)` |
>
> ```java
> class Solution {
>     public boolean threeConsecutiveOdds(int[] arr) {
>         int count = 0;
>         for (int i = 0; i < arr.length; i++) {
>             if (arr[i] % 2 != 0) {
>                 count++;
>             } else {
>                 count = 0;
>             }
>
>             if (count == 3) {
>                 return true;
>             }
>         }
>         return false;
>     }
> }
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
