### Problem Statement:

Given a `sentence` that consists of some words separated by a **single space**, and a `searchWord`, check if `searchWord` is a prefix of any word in `sentence`.

Return _the index of the word in _`sentence`_ (**1-indexed**) where _`searchWord`_ is a prefix of this word_. If `searchWord` is a prefix of more than one word, return the index of the first word **(minimum index)**. If there is no such word return `-1`.

A **prefix** of a string `s` is any leading contiguous substring of `s`.

> [!example]- Example 1
> **Input:**
>
> ```python
> sentence = "i love eating burger", searchWord = "burg"
> ```
>
> **Output:**
>
> ```python
> 4
> ```
>
> **Explanation:**
>
> ```python
> "burg" is prefix of "burger" which is the 4th word in the sentence.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> sentence = "this problem is an easy problem", searchWord = "pro"
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> "pro" is prefix of "problem" which is the 2nd and the 6th word in the sentence, but we return 2 as it's the minimal index.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> sentence = "i am tired", searchWord = "you"
> ```
>
> **Output:**
>
> ```python
> -1
> ```
>
> **Explanation:**
>
> ```python
> "you" is not a prefix of any word in the sentence.
> ```

> [!warning]- Constraints
> - `1 <= sentence.length <= 100`
>
> 	- `1 <= searchWord.length <= 10`
>
> 	- `sentence` consists of lowercase English letters and spaces.
>
> 	- `searchWord` consists of lowercase English letters.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `0 ms` | `12.3 MB` | `O(n²)` | `O(n)` |
>
> ```python
> class Solution(object):
>     def isPrefixOfWord(self, sentence, searchWord):
>         count = 1
>         sentence = " " + sentence
>         searchWord = " " + searchWord
>
>         first = 1
>         for i in range(len(sentence) - len(searchWord) + 1):
>             currentWord = ""
>             if (sentence[i] == ' ' and not first):
>                 count = count + 1
>             for j in range(len(searchWord)):
>                 currentWord = currentWord + sentence[i + j]
>             first = 0
>             if (currentWord == searchWord):
>                 return count
>
>         return -1
>
>
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Nested iteration finds pairs or combinations
