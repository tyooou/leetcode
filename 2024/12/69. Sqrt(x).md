### Problem Statement:

Given a non-negative integer `x`, return _the square root of _`x`_ rounded down to the nearest integer_. The returned integer should be **non-negative** as well.

You **must not use** any built-in exponent function or operator.

	- For example, do not use `pow(x, 0.5)` in c++ or `x ** 0.5` in python.

> [!example]- Example 1
> **Input:**
>
> ```python
> x = 4
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The square root of 4 is 2, so we return 2.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> x = 8
> ```
>
> **Output:**
>
> ```python
> 2
> ```
>
> **Explanation:**
>
> ```python
> The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.
> ```

> [!warning]- Constraints
> - `0 <= x <= 2^31 - 1`
