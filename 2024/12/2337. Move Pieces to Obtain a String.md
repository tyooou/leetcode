### Problem Statement:

You are given two strings `start` and `target`, both of length `n`. Each string consists **only** of the characters `'L'`, `'R'`, and `'_'` where:

	- The characters `'L'` and `'R'` represent pieces, where a piece `'L'` can move to the **left** only if there is a **blank** space directly to its left, and a piece `'R'` can move to the **right** only if there is a **blank** space directly to its right.

	- The character `'_'` represents a blank space that can be occupied by **any** of the `'L'` or `'R'` pieces.

Return `true` _if it is possible to obtain the string_ `target`_ by moving the pieces of the string _`start`_ **any** number of times_. Otherwise, return `false`.

> [!example]- Example 1
> **Input:**
>
> ```python
> start = "_L__R__R_", target = "L______RR"
> ```
>
> **Output:**
>
> ```python
> true
> ```
>
> **Explanation:**
>
> ```python
> We can obtain the string target from start by doing the following moves:
> - Move the first piece one step to the left, start becomes equal to "**L**___R__R_".
> - Move the last piece one step to the right, start becomes equal to "L___R___**R**".
> - Move the second piece three steps to the right, start becomes equal to "L______**R**R".
> Since it is possible to get the string target from start, we return true.
> ```

> [!example]- Example 2
> **Input:**
>
> ```python
> start = "R_L_", target = "__LR"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The 'R' piece in the string start can move one step to the right to obtain "_**R**L_".
> After that, no pieces can move anymore, so it is impossible to obtain the string target from start.
> ```

> [!example]- Example 3
> **Input:**
>
> ```python
> start = "_R", target = "R_"
> ```
>
> **Output:**
>
> ```python
> false
> ```
>
> **Explanation:**
>
> ```python
> The piece in the string start can move only to the right, so it is impossible to obtain the string target from start.
> ```

> [!warning]- Constraints
> - `n == start.length == target.length`
>
> 	- `1 <= n <= 10^5`
>
> 	- `start` and `target` consist of the characters `'L'`, `'R'`, and `'_'`.

### Submission:

> [!example]+ Submission
> | Runtime | Memory | Time | Space |
> |---|---|---|---|
> | `183 ms` | `12.8 MB` | `O(n²)` | `O(1)` |
>
> ```python
> class Solution(object):
>     def canChange(self, start, target):
>         i, j, n = 0, 0, len(start)
>
>         while i < n or j < n:
>             while i < n and start[i] == '_':
>                 i += 1
>             while j < n and target[j] == '_':
>                 j += 1
>
>             if i == n or j == n:
>                 break
>             if start[i] != target[j]:
>                 return False
>             if start[i] == 'L' and i < j:
>                 return False
>             if start[i] == 'R' and i > j:
>                 return False
>
>             i += 1
>             j += 1
>         return i == n and j == n
> ```

> [!success]- Reasoning
> 1. Initialize data structures
> 2. Process input according to algorithm
> 3. Return computed result
>
> **Key insight:** Single pass through input solves problem
